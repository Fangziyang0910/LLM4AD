# BehaveSim 算法行为语义景观分析

## 1. 实验目标与图构造协议

本实验对比算法的**代码生成谱系图**与**行为近邻图（BehaveSim）**的几何拓扑差异，检验适应度在行为空间的局部平滑性与宏观结构。

- **图构造规范（同一节点集，不同边关系）**：
  - **压缩谱系图 $G_L$**：沿真实 `parent_id` 生成链上溯连接最近祖先；
  - **行为 kNN 图 $G_B$**：每个候选连接 BehaveSim 距离最近的 $k$ 个近邻（$k = \max(2, \lceil0.05(n-1)\rceil)$）；
  - **语义区域**：以该 run 距离矩阵的 25% 分位数为阈值，连通分量即为行为区域。
- **数据来源**：V9.16 五任务 × 3 独立重复（共 15 个 run），构造式任务每 run 128 个分层抽样节点，ACO 任务每 run 32 个节点。

## 2. 核心实验数据

### 2.1 谱系拓扑与行为表型的深度解耦

生成相邻的算法，在行为几何上几乎完全不是近邻：边 Jaccard 均值仅为 0.016–0.037，邻域 Jaccard 仅为 0.010–0.029。

| 任务 | 谱系分量数（3 重复） | 语义区域数 | 多谱系区域候选占比 |
| --- | --- | --- | --- |
| TSP | 8 / 34 / 8 | 15 / 8 / 16 | 0.00 / 0.95 / 0.88 |
| OBP | 31 / 105 / 5 | 17 / 12 / 6 | 0.87 / 0.91 / 0.85 |
| VRPTW | 28 / 40 / 13 | 1 / 6 / 4 | 1.00 / 0.96 / 0.98 |
| OP | 27 / 31 / 27 | 9 / 6 / 9 | 0.00 / 0.00 / 0.00 |
| CVRP | 12 / 31 / 23 | 2 / 1 / 10 | 0.97 / 1.00 / 0.00 |

- **VRPTW、OBP 与 TSP**：代码谱系持续高度分支，但大量谱系汇聚到少数共享的行为区域中（85%–100% 的候选属于多谱系共享区域）。
- **OP**：谱系与行为区域高度对应，各自保持独立的搜索流。

### 2.2 适应度在行为空间的平滑性与 Funnel 结构

- **局部平滑性（$\Delta L =$ 随机对平均适应度差 $-$ kNN 邻居平均差）**：
  - VRPTW：`0.62 / 0.62 / 0.53`（三重复同向，平滑性最强）
  - OBP：`0.47 / 0.47 / 0.60`（三重复同向）
  - TSP：`0.34 / 0.63 / 0.34`（三重复同向）
  - CVRP 与 OP：因 ACO 随机流与样本规模限制，方向不一致。
- **全局平滑性与 Funnel**：
  - 全局行为距离与适应度差的 Spearman 相关在 15/15 个 run 中全部为正（0.27–0.72）；
  - 到当前最优解的行为距离与适应度 gap 的 Spearman 在 15/15 个 run 中全部为正（0.13–0.89），存在明显的漏斗（Funnel）特征。
- **高质量区域分布**：高质量算法（前 10%）形成 1–4 个孤立的行为岛，区域间最小距离接近全距上限（0.42–0.81），呈现多峰分布。

### 2.3 搜索在行为空间的穿透动态

- **停滞步幅分析**：停滞转移中，小步无改善（局部重访）占比高达 45%–90%；大步无改善（盲目漂移）在大部分任务中 $\le 6\%$。
- **突破时刻的步幅**：实现适应度突破时的中位行为新颖度系统性高于无突破时刻（如 TSP 0.28–0.47 vs 0.10–0.21，OBP 0.17–0.26 vs 0.04–0.11）。

## 3. 机制分析与决策

1. **核心科学发现**：
   $$\boxed{\text{代码生成谱系 (Lineage)} \quad\text{与}\quad \text{执行表型几何 (Phenotype)} \quad\text{严重分离}}$$
   代码树看似蓬勃分叉，往往只是在相同的狭小行为区域内进行冗余重访。
2. **适应度空间规律**：TSP、OBP、VRPTW 的解题行为空间具有明显的局部平滑性与指向最优的宏观漏斗结构；算法行为相近时，其性能在统计学上显著更接近。
3. **职责边界**：BehaveSim 作为宏观表型坐标有效，可用于离线判定多样性与重访，但不能直接假定“沿行为梯度可以平滑生成代码”，更不应直接在线用于单节点潜力打分。
