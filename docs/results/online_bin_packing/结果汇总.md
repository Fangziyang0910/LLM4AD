## 简单分析

- **C=100（与训练同容量）**：v4 在 5k/10k 上取得当前最好均值（2026.3 / 4044.0），三次运行的方差也很小；1k 上与 MCTS/v3 接近。
- **C=500（旧协议中的容量外推）**：v4 rep2/rep3 保持稳定并接近 PathWise，但 rep1 在三个规模上都退化为每件物品使用一个新箱（1000/5000/10000），使 v4 聚合均值和方差失去竞争力。定向消融确认直接原因是 rep1 heuristic 的 `age_bonus` 按剩余容量奖励更空的箱子：原程序在固定 1k_500 实例上使用 1000 个箱子，关闭该项后降至 82；只关闭退化为常数的 `harmony_bonus` 仍使用 1000 个箱子。
- v4 的训练集搜索结果明显高于此前方法，且三次工件分数高度一致；结合 C=500 的单 run 崩溃，后续应把跨容量行为作为独立机制证据检查，而不能只依据训练 best 判断泛化。
