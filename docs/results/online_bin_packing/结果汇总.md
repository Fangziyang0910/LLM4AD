## 简单分析

- **C=100（与训练同容量）**：MCTS-AHD 在 1k/5k/10k 上平均箱数最低且最稳；TraceAAD v2 次之但方差更大（尤其 5k/10k）；PathWise（预算 500）明显更弱。
- **C=500（容量外推）**：PathWise 三规模均值反而最好且几乎无跨 run 波动；MCTS / TraceAAD 在部分 run（如 MCTS rep3、TraceAAD rep1）上明显变差。与仅在 5k_100 上训练、未覆盖大容量分布的设定一致。
- TraceAAD v2 在同容量上仍有单次最好（rep1，5k_100=2028.0），但均值与方差均不及 MCTS-AHD。
