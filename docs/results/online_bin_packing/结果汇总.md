# Online Bin Packing 实验结果

## 实验设置与比较口径

本页比较 Online Bin Packing 方法在固定搜索协议下的 held-out 平均箱数。比较单位是某方法在一个 `n_items` 与 `capacity` 组合上的一次完整搜索运行。Qwen3.6-27B 在 `1k/5k × capacity=100/500` 的四个固定实例上用于搜索，在 `1k/5k/10k × capacity=100/500` 各 5 个实例上用于测试。每种方法独立运行 3 次，所有方法搜索预算均为 1000。指标为平均箱数，越低越好。

`1k/5k` 是 ID 配置，只有 `10k` 是 OOD 配置。表中每个数值为 3 次运行的 held-out 均值 ± 样本标准差；± 仅描述运行间变异，不是置信区间，也不支持统计显著性判断。加粗表示该列的最佳均值。

### 结果解释与限制

TraceAAD V4 在 `1k/100`、`5k/100` 和 `10k/100` 的报告均值最低；在 `1k/500` 中，TraceAAD V6 与 ReEvo 的报告均值相同且最低；MCTS-AHD 在 `5k/500` 和 `10k/500` 的报告均值最低。上述并列和排序均为均值描述，不代表统计显著性。结论限于给定 item 序列、capacity、ID/OOD 配置、搜索预算和 3 次独立运行，不能据此推断对其他序列或容量的普遍优势。
