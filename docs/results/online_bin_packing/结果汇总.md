# Online Bin Packing 实验结果

## 实验参数

| 项目 | 配置 |
|---|---|
| 模型 | `Qwen3.6-27B`（rep1 zhong / rep2 server1 / rep3 Fang_lab） |
| 训练集 | Weibull，`n_instances=5`，`n_items=5000`，`capacity=100`，`seed=2024` |
| 测试集 | 同规模 Weibull，`seed=2025` |
| 重复次数 | 每种方法 3 次独立运行 |
| 搜索预算 | MCTS-AHD：1000；PathWise：500；TraceAAD v2：1000 |
| 指标 | `score = -mean(bins used)`，越高越好；下表同时给出平均箱数（越低越好） |
| 测试方式 | 取每次搜索训练集 best heuristic，在 held-out `seed=2025` 上完整评估 |
| TraceAAD 版本 | version2：`experiments/online_bin_packing/traceaad/version2/` |

## 简单分析

- 同预算 1000 下，MCTS-AHD 测试平均箱数最低且跨 run 最稳；TraceAAD v2 单次最好（rep1，2028.0 箱）但 rep2 明显偏弱，均值与方差均劣于 MCTS-AHD。
- PathWise 仅 500 次评估，训练与测试箱数均明显更高（约多 60+ 箱），且 rep3 最优解出现在 sample 1，后续几乎无提升。
- 训练与测试分数方向一致：训练集领先的方法在 held-out `seed=2025` 上仍领先，未见明显过拟合反转。
