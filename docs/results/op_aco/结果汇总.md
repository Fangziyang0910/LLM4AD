# OP-ACO 实验结果

## 实验设置

Qwen3.6-27B；OP50 × 5（`seed=1234`）用于搜索，OP50/100/200 各 64 个
实例（`seed=4567`）用于测试；20 ants、50 iterations。每种方法独立运行
3 次。MCTS-AHD 与 TraceAAD 的搜索预算为 1000，PathWise 为 500。下表
报告平均 collected prize，越高越好。

## 三次运行平均

| 方法 | OP50 | OP100 | OP200 |
| --- | ---: | ---: | ---: |

| PathWise | 14.624141 ± 0.332651 | 28.934265 ± 1.357038 | 49.912917 ± 3.533559 |
| TraceAAD V4 | 15.069351 ± 0.090613 | 30.216914 ± 0.673457 | 53.509375 ± 2.611692 |
| TraceAAD V5 | 15.111948 ± 0.115030 | **30.710591 ± 0.245109** | **55.792500 ± 0.613045** |
