## 简单分析

- v4 三次训练更齐（std 0.066），v5 训练均值低约 0.15，且更早触及平台（最优 sample 多在前 350 次内）。
- held-out 上，v5 的 OP50 与 v4 接近但略低、方差更大；OP100 / OP200 的均值高于 v4，且 OP200 的跨 run 波动明显小于 v4（1.317 vs 2.612）。
- 这说明本轮 v5 在 OP 上出现“训练分数略低、大规模测试并不更差”的现象；最终方法比较仍需结合后续基线（如 MCTS-AHD）与机制审计结论一起看。
