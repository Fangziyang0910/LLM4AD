# OP-ACO 实验结果

TraceAAD v4 已完成三次独立训练和 OP50/100/200 held-out 测试。

## 实验参数

| 项目 | 配置 |
|---|---|
| 模型 | `Qwen3.6-27B-NVFP4`（Zhong） |
| 训练集 | OP50 × 5，`seed=1234` |
| 测试集 | OP50/100/200 各 64 个实例，`seed=4567` |
| 路程预算 | OP50/100/200：`maxlen=3/4/5` |
| ACO | 20 ants × 50 iterations，`aco_seed=1234` |
| 重复次数 | 3 次独立运行 |
| 搜索预算 | 每次 1000 次评估 |
| 指标 | 平均 collected prize，越高越好 |
| 测试方式 | 取每次搜索训练集全局 best heuristic，在固定测试集上完整评估 |

## 简单分析

- 三次训练均达到接近的最终水平，训练 best 的标准差仅 0.066；主要提升集中在前 500 次评估，后半程趋于平台。
- OP50 测试表现稳定，三次运行标准差为 0.091。
- 随问题规模扩大，跨 run 差异增加，OP200 的标准差达到 2.612；其中 rep3 的 OP200 表现较低，是大规模测试波动的主要来源。
