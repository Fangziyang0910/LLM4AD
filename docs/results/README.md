# 结果记录

结果按 task 组织，不按 method 或 model 拆目录：

```text
docs/results/<task>/
  结果汇总.md
  搜索曲线.png
```

训练 / 测试与搜索配置见 [`docs/实验配置.md`](../实验配置.md)。

`结果汇总.md` 只保留实验设置、正式方法的三次运行平均、搜索曲线和工件入口。
TraceAAD 只记录 V4 与正式 V5；开发快照不进入权威结果页。只有重复实验和测试
评估全部完成后，才更新结果。

原始 run、`run_config.json`、日志、checkpoint、单次评估 JSON 和生成程序只保留
在实验机器本地，不进入 Git。Git 中只保存这里的聚合结果、必要曲线、评估口径和
本地工件路径，避免将某一个 run 的零散文件误当成权威结果。
