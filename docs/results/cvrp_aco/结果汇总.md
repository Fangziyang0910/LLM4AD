# CVRP-ACO 实验结果

## 实验设置

Qwen3.6-27B；10 个 CVRP50 实例用于搜索，CVRP50/100 各 64 个实例用于
测试；30 ants、100 iterations、`aco_seed=1234`。每种方法独立运行 3 次。
搜索预算均为 1000。下表报告平均最优路径长度，越低越好。
