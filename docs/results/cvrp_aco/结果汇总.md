## 实验参数

| 项目 | 配置 |
|---|---|
| 模型 | `Qwen3.6-27B` |
| 训练集 | `train`：10 个 CVRP50 实例，车辆容量 50 |
| 测试集 | `test_50`、`test_100`：每个 64 个实例 |
| ACO 参数 | 30 ants，100 iterations，`aco_seed=1234` |
| LLM 参数 | `temperature=1.0`，`max_tokens=16384` |
| 重复次数 | 每种方法目标 3 次独立运行；TraceAAD v4 当前完成 2 次测试 |
| 搜索预算 | MCTS-AHD：1000；PathWise：500；TraceAAD v2/v3/v4/v5：1000 |
| 方法配置 | MCTS-AHD / PathWise 使用 4 个 evaluators；TraceAAD 使用 `trajectory_ucb` |
| 指标 | `objective` 为平均最优路径长度，越低越好；`score=-objective` |
| TraceAAD 版本 | version2：`20260718_193305_cvrp_rep{1,2,3}`；version3：`20260720_233339_cvrp_v3_rep{1,2,3}`；version4：`20260723_204526_cvrp_v4_rep{1,2,3}`；version5：`20260724_220827_cvrp_v5_rep{1,2,3}` |

## 简单分析

- TraceAAD v3（`20260720_233339`）三次 held-out 平均：test_50 **9.0424±0.029**，test_100 **15.3989±0.041**；跨 run 波动明显小于 v2，并优于 v2/PathWise。
- MCTS-AHD 在两个测试 split 上平均 objective 仍略低于 v3（test_50 8.9617、test_100 15.1144），但 v3 稳定性更好。
- TraceAAD v5（`20260724_220827`）三次 held-out 均值：test_50 **9.3430±0.307**，test_100 **15.8588±0.483**，弱于 v3、MCTS 以及当前两重复的 v4；rep3 训练与测试同时最差，是拉低均值和放大方差的主因。
- PathWise 只使用 500 次 evaluation；与 1000 次预算的方法比较时需同时考虑预算差异。
- TraceAAD v4 当前两个完成测试 run 的 test_50/test_100 objective 均值为 **9.1812/15.5180**。待 rep2 测试写入后再形成最终三重复判断。
