# CVRP-ACO 实验结果

## 实验参数

| 项目 | 配置 |
|---|---|
| 模型 | `Qwen3.6-27B` |
| 训练集 | `train`：10 个 CVRP50 实例，车辆容量 50 |
| 测试集 | `test_50`、`test_100`：每个 64 个实例 |
| ACO 参数 | 30 ants，100 iterations，`aco_seed=1234` |
| 重复次数 | 每种方法 3 次独立运行 |
| 搜索预算 | MCTS-AHD / TraceAAD：1000；PathWise：500 |
| 指标 | `objective` 为平均最优路径长度，越低越好；`score=-objective` |
