# CVRP-ACO 实验结果

## 实验设置

Qwen3.6-27B；10 个 CVRP50 实例用于搜索，CVRP50/100 各 64 个实例用于
测试；30 ants、100 iterations、`aco_seed=1234`。每种方法独立运行 3 次。
MCTS-AHD 与 TraceAAD 的搜索预算为 1000，PathWise 为 500。下表报告平均
最优路径长度，越低越好。

## 三次运行平均

| 方法 | CVRP50 | CVRP100 |
| --- | ---: | ---: |
| MCTS-AHD | **8.961703 ± 0.179934** | **15.114426 ± 0.316653** |
| PathWise | 9.794713 ± 0.271561 | 16.873145 ± 0.448812 |
| TraceAAD V4 | 9.129223 ± 0.129956 | 15.413780 ± 0.294039 |
| TraceAAD V5 | 9.038972 ± 0.091240 | 15.428279 ± 0.229195 |
