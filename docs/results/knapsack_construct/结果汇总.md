### 简单分析

- TraceAAD v3 三重复最稳：训练集几乎顶齐（562.09–562.28），KP50/100/200 测试均值均优于 MCTS 与 PathWise，且标准差明显更小。
- MCTS 与 PathWise 各有一路明显掉队（MCTS rep1、PathWise rep2），拉低均值并放大方差；最好单次仍可接近 TraceAAD。
- PathWise 预算仅 500，均值与 MCTS（预算 1000）接近，但稳定性弱于 TraceAAD。
- TraceAAD v4 当前两个完成 run 得到了相同的训练与 held-out 分数，均命中训练天花板；该现象进一步说明 KP 的改进空间很小，最终三重复结论仍等待 rep1。
