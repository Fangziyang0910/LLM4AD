# TSP Construct 实验结果

## 实验参数

| 项目 | 配置 |
|---|---|
| 模型 | `Qwen3.6-27B` |
| 训练集 | TSP50，16 个实例，`seed=2024` |
| 测试集 | TSP50、TSP100、TSP200，各 16 个实例，`seed=2025` |
| 重复次数 | 每种方法 3 次独立运行 |
| 搜索预算 | MCTS-AHD：1000；PathWise：500；TraceAAD v1/v2：1000 |
| 方法配置 | MCTS-AHD 4 evaluators；PathWise 4 evaluators；TraceAAD 使用 `trajectory_ucb` |
| 指标 | `objective` 为平均 tour length，越低越好；`score=-objective` |
| 测试方式 | 取每次搜索得到的训练集 best heuristic，在同一 held-out 测试集上完整评估 |
| TraceAAD 版本 | version1：`experiments/tsp_construct/traceaad/version1/`；version2：`experiments/tsp_construct/traceaad/version2/`（`20260718_174552_tsp_rep{1,2,3}`） |

## 简单分析

- TraceAAD version1 在 TSP50 和 TSP100 上仍是最低平均 objective；MCTS-AHD 在 TSP200 上最好。
- TraceAAD version2 三次重复的训练集 best 与 version1 接近，但 held-out 三个规模的平均 objective 均高于 version1，TSP200 跨 run 波动也更大（尤其 `rep1`）。
- PathWise 只使用 500 次 evaluation，与另外三种方法的 1000 次预算不可直接等同比较。
