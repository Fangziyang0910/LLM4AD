# TSP Construct 实验结果

## 实验设置

Qwen3.6-27B；TSP50 × 16（`seed=2024`）用于搜索，TSP50/100/200 各
16 个实例（`seed=2025`）用于测试。每种方法独立运行 3 次。搜索预算均为
1000。
