## 简单分析

- PathWise 只使用 500 次 evaluation，与另外三种方法的 1000 次预算不可直接等同比较。
- TraceAAD version3（`20260720_233339`）三次 held-out 平均 objective：TSP50 **6.0948±0.023**，TSP100 **8.6217±0.183**，TSP200 **12.1275±0.212**；跨 run 波动明显更小。
- TraceAAD v5（`20260724_220827`）三次 held-out 均值：TSP50 **6.1649±0.255**，TSP100 **8.4839±0.274**，TSP200 **12.1466±0.376**。rep1 单次测试全面优于同表多数方法，但 rep2/rep3 明显掉队，使均值与方差均弱于 v3；相对当前仅两重复的 v4 测试均值也未超过。
- TraceAAD v4 当前两个完成测试 run 的 held-out 均值为 TSP50 **5.9926**、TSP100 **8.4319**、TSP200 **11.8674**。待 rep2 测试写入后再形成最终三重复判断。
