# V10.7 同期质量退化追踪

2026-09-08 08:25 左右快照；补充[运行核查](结论.md)。本次只读历史实验，重放数值子表达式，没有调用模型或正式 evaluator，也没有修改在线实验。

**V10.7 在 TSP、CVRP 的同期落后已经得到确认，TSP 尤其明显。更具体的问题是：多条最佳路线保留了失效的主打分，只在精确尾部上继续开发；同时，新的参考采样系统性降低了 Fuse donor 的质量。** 这解释了部分退化过程，但尚不能把全部差距唯一归因于某一个设计变化。

## 2. TSP 的主打分失效，并被连续继承

读取实际 Code 后发现，V10.7 三路当前最佳均存在以下一种数值错误：

1. 为求最小出边，将未访问节点距离矩阵的对角设为 `inf`。
2. 随后复用该矩阵求整行均值或总和，导致各行统计都为 `inf`。
3. 归一化产生 `inf/inf`，或 regret 计算产生 `inf-inf`，最后各候选分数都是 `NaN`。
4. `np.argmin` 返回首位置；本任务评估器已按距当前节点排序候选，所以实际选择最近邻。

这不是只看代码注释得出的推测：用 4/9/11 个候选的小矩阵分别重放两种分数表达式，所有位置均为 NaN，argmin 均为 0。没有执行正式评价。候选最终仍返回合法节点，所以 evaluator 能给出有限 fitness，普通有效率统计不会暴露这个内部退化。

| V10.7 TSP | 当前 best 节点 / 评价 | 实际行为 |
| --- | --- | --- |
| rep1 | n279 / e290，−6.533894 | 大规模主打分 NaN，≤12 个节点时缓存 DP 有效 |
| rep2 | n67 / e68，−6.823969 | 主打分 NaN，无精确尾部，实质近邻 |
| rep3 | n391 / e398，−6.685091 | 主打分经 regret 变成 NaN，≤8 个节点时穷举有效 |

它们得到过后续开发。rep1 的真实父链 `169→196→201→203→205→215→220` 跨 Refine/Fuse 持续保留 `inf/inf`，主要把精确尾部阈值从 3 提高到 10，最后换成 DP；当前 best 又扩到 12。rep3 的 n383 已有均值 inf，n391 保留问题而把精确尾部从 6 扩到 8。

因此，部分分数改善来自更强的尾部求解，而 Idea 中声称的 cohesion、结构感知、regret 主决策并未兑现。扩大穷举到 9、扩大 DP 到 15 的一些后续候选又发生 timeout，继续沿这条路线增加开销有明确限制。

**V10.6 也曾出现同类坏程序。** rep1 n26/e36 是 NaN 主打分加 ≤14 节点 DP；关键区别是 n29/e42 的 Pivot 转向了真正执行的“每个候选首步 → 近邻补全整条尾路径 → 2-opt → 比较完整代价”，达到 −5.93337，随后 n63/e95、n64/e96 继续开发到 −5.83911。V10.6 当前最佳三路也检查到真实补全搜索或局部改进。

这条对照说明：不能把 NaN 说成 V10.7 独有错误，也不能说只是没有给新节点机会。V10.7 的代表路线在不断开发退化行为，V10.6 的代表路线成功转向了更有效的主决策。修正 NaN 后的算法是否提分尚未评价，不能预先保证。

## 3. Fuse 的材料规则发生了实质改变

以每路前 250 次评价为窗口，三重复汇总。top10% 按当时档案的 90% 分位阈值定义，同分全部包含；父代分位使用中秩。

| 指标 | TSP V10.6 → V10.7 | VRPTW V10.6 → V10.7 |
| --- | --- | --- |
| 父代平均分位 | 89.1% → 87.3% | 88.8% → 90.2% |
| 完整代码材料含当时最好分数 | 26.0% → 57.8% | 25.3% → 29.4% |
| Fuse donor 属于 top10% | 79.4% → 38.9% | 79.8% → 20.2% |
| Fuse donor 比父代差 | 47.1% → 66.8% | 44.8% → 88.5% |
| 有效 Fuse 子代超父代 | 30.5% → 6.2% | 27.3% → 12.8% |
| 有效 Fuse 子代超最好上下文程序 | 12.7% → 2.5% | 12.7% → 9.6% |

强父代仍在，强分数在上下文中也没有普遍消失。变化集中在第二份主材料：V10.6 在可用跨血缘程序的 top5 中选 donor；V10.7 从抽到的两份跨质量参考里取最好者，往往仍然明显弱于已被质量分配选中的父代。

这是当前设计的可预期结果。在三个层各占约三分之一、无并列的近似条件下，两份参考来自两个不同层：抽到 high 的概率为 2/3；high 中落在全档案 top10% 的比例约为 30%。因此 donor 来自 top10% 的概率约为 **(2/3)×30%=20%**，与 VRPTW 实测接近。保证跨质量覆盖，并不同时保证有强融合对象。

数据支持“相同采样规则未必适合所有算子”的判断。它不能单独证明 donor 弱化造成了全部退化，因为上下文、提示、档案分布和候选筛选同时变化。

## 4. OBP：同分平台上的上下文自我重复

V10.7 rep2/3 每轮上下文都有当前最高分 −744.5；不存在强程序从材料中消失的问题。问题是大量不同 Code 仍对应 Best-Fit，分位数边界重合后，两份参考几乎都从同一平台抽取。上轮静态代码检查已确认若干 Pivot/Fuse 只是 Best-Fit 的单调变形。

值得保留的反例是 V10.7 rep1：八个根也全为 −744.5，却在 e196 的 Pivot 首次引入有效的小残余惩罚，达到 −744.0；e198 的 Refine 继承该行为后达到 −728.5。说明新方案并非不能突破，但三路中只有一路发现并开发了有效偏离。

V10.6 三路首次超最佳根分别在 e105/e155/e77，之后继续改进；V10.5 也有一路最终未突破。因此“同分程序大量出现”是跨版本已有风险，V10.7 的全档案抽样没有解决它。

## 5. 现在应如何判断

可以确认的是：

- 运行实现与设计一致，不能据此认定设计实现了有效探索。
- TSP 有明确的行为退化与继承链证据，低失败率掩盖了主决策失效。
- 用跨质量参考直接担当 Fuse 主输入，系统性降低了 donor 质量。
- 仅按分数分层和完全相同 Code 去重，无法保证提供不同算法行为。

尚不能确认的是：取消独立校准、去掉真实祖先变化记录、三代码展示、算子指令与 100-word Idea 要求，哪一项对整体差距贡献最大。不能因为 V10.6 当前更强就重新给第二调用记上未经证实的收益。

最小定位应优先比较两条已有或简单的对照：**保留单调用，恢复原祖先上下文机制；保留新上下文，只恢复 Fuse 的强 donor 选择。** 前者检验整套上下文改动，后者检验算子与材料分配是否匹配。OBP/TSP 的行为抽查应同时观察主决策是否真正改变、改进路线是否被继续开发，而不只统计新节点或格式成功率。本次尚未启动这些对照。
