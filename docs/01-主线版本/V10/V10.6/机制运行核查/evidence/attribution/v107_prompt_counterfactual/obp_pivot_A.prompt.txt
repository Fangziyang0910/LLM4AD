Idea: Build a composite online 1-D bin-packing priority that blends Best-Fit tightness with capacity-aware balance and robust handling of infeasible bins. Convert the remaining-capacity array to float to safely add bonuses/penalties. For each bin, compute leftover = capacity - item. Use a primary tightness reward that grows as leftover shrinks (1/(1+leftover) for feasible bins), a secondary balance penalty proportional to leftover to avoid leaving very empty bins, and a small capacity bonus to prefer more flexible bins on ties. Mark infeasible bins with a very low finite score so they are never selected. Add a tiny deterministic tie-breaker derived from the bin’s original capacity to avoid random dependence and keep outputs finite.

```python
import numpy as np

def priority(item: float, bins: np.ndarray) -> np.ndarray:
    """Returns priority with which we want to add item to each bin.
    Args:
        item: Size of item to be added to the bin.
        bins: Array of capacities for each bin.
    Return:
        Array of same size as bins with priority score of each bin.
    """
    # Cast to float to allow adding bonuses/penalties without integer overflow/underflow issues
    b = np.asarray(bins, dtype=float)
    item_f = float(item)

    # Feasible bins are those with remaining capacity at least the item size
    feasible = b >= item_f

    # Start with a very low finite priority for infeasible bins so they are never chosen
    # (using a large negative finite value instead of -inf to satisfy "finite floating-point" requirement)
    scores = np.full(b.shape, -1e9, dtype=float)

    if np.any(feasible):
        cap = b[feasible]       # original remaining capacity of feasible bins
        leftover = cap - item_f # space left after placing the item (>= 0)

        # Primary: tightness reward — strongly favors minimal leftover
        # 1/(1+leftover) is high when leftover is small, low when leftover is large
        tightness = 1.0 / (1.0 + leftover)

        # Secondary: balance penalty — discourages creating very empty bins
        # Scale small relative to tightness to not override the main fit objective
        balance_penalty = 0.1 * leftover

        # Tertiary: small capacity bonus to prefer more flexible bins when fits are similar
        # This helps preserve options for future larger items without dominating tightness
        capacity_bonus = 1e-6 * cap

        # Deterministic tiny tie-breaker based on capacity (no randomness)
        # Ensures reproducible outputs and breaks exact ties consistently
        tie_breaker = 1e-12 * (cap / (1.0 + np.max(cap) if np.max(cap) > 0 else 1.0))

        local_scores = tightness - balance_penalty + capacity_bonus + tie_breaker
        scores[feasible] = local_scores

    # Ensure finiteness (should already be finite, but guard against any numerical surprises)
    scores = np.where(np.isfinite(scores), scores, -1e9)

    return scores
```

```python
    Args:

        bins: Array of capacities for each bin.
    Return:
        Array of same size as bins with priority score of each bin.
```
