Algorithm 1
Fitness: -8.208833389475853
Idea: The algorithm employs a dynamic composite scoring function that adaptively balances immediate travel cost, return feasibility, and tour connectivity. The weight for the return-to-destination penalty increases quadratically with tour progress to prevent late-stage detours, while the weight for the connectivity term decreases linearly to shift focus from global structure to local optimization. The connectivity term itself blends node isolation (average distance to other unvisited nodes) with a 2-step lookahead (minimum distance to next potential node or destination), ensuring the selected node maintains low future travel costs. A 10% lookahead window strictly prioritizes return cost to guarantee a feasible final leg.
Code:
```python
import numpy as np

def select_next_node(current_node: int, destination_node: int, unvisited_nodes: np.ndarray, distance_matrix: np.ndarray) -> int:
    """
    Selects the next node using a dynamic composite score that balances immediate cost,
    return feasibility, and connectivity (isolation + lookahead).
    """
    if len(unvisited_nodes) == 0:
        return destination_node
        
    n_remaining = len(unvisited_nodes)
    
    if n_remaining == 1:
        return int(unvisited_nodes[0])
        
    n_total = distance_matrix.shape[0]
    
    # Progress: 0 at start, 1 at end
    if n_total > 1:
        progress = (n_total - n_remaining) / (n_total - 1)
    else:
        progress = 1.0
        
    # Extract relevant distance sub-vectors
    d_cur_u = distance_matrix[current_node, unvisited_nodes]
    d_u_dest = distance_matrix[unvisited_nodes, destination_node]
    
    # Compute connectivity metrics
    # Isolation: Average distance to other unvisited nodes
    submatrix = distance_matrix[np.ix_(unvisited_nodes, unvisited_nodes)].copy()
    np.fill_diagonal(submatrix, 0)
    isolation = np.sum(submatrix, axis=1) / (n_remaining - 1)
    
    # Lookahead: Minimum distance to any other unvisited node or destination
    submatrix_inf = distance_matrix[np.ix_(unvisited_nodes, unvisited_nodes)].copy()
    np.fill_diagonal(submatrix_inf, np.inf)
    min_to_other_unvisited = np.min(submatrix_inf, axis=1)
    min_lookahead = np.minimum(min_to_other_unvisited, d_u_dest)
    
    # Dynamic Weights
    # Alpha: Return penalty weight, increases quadratically
    alpha = 0.1 + 0.9 * (progress ** 2)
    
    # Gamma: Connectivity weight, decreases linearly
    gamma = 0.5 * (1.0 - progress)
    
    # Blended connectivity term
    # Early: Emphasize isolation (compactness)
    # Late: Emphasize lookahead (feasibility)
    # Use a smooth blend based on progress
    w_iso = 1.0 - progress
    w_look = progress
    connectivity_term = w_iso * isolation + w_look * min_lookahead
    
    # Base Score
    scores = d_cur_u + alpha * d_u_dest + gamma * connectivity_term
    
    # Safe Return Guard: In the final 10% of the tour, strictly prioritize return cost
    if progress > 0.9:
        # Overwrite score to prioritize destination distance heavily
        scores = 0.1 * d_cur_u + 0.9 * d_u_dest
        
    # Handle numerical issues
    if np.any(np.isnan(scores)) or np.any(np.isinf(scores)):
        scores = d_cur_u + 0.5 * d_u_dest
        
    # Select minimum score
    best_idx = np.argmin(scores)
    return int(unvisited_nodes[best_idx])
```

Idea: I extend Algorithm 3's normalized composite cost by adding an "Orphan Penalty" (distance to the second nearest unvisited neighbor) to prevent isolating the last few nodes, which Algorithm 3's average-based cohesion misses. I replace the regret term with a dynamic tie-breaker that prioritizes nodes with higher "exit flexibility" (more nearby options) when scores are close. The return bias uses a smooth step function for a softer but decisive pull at the end. All components are scale-invariant.
Code:
```python
import numpy as np

def select_next_node(current_node: int, destination_node: int, unvisited_nodes: np.ndarray, distance_matrix: np.ndarray) -> int:
    if len(unvisited_nodes) == 0:
        return destination_node
        
    n_remaining = len(unvisited_nodes)
    
    if n_remaining == 1:
        return int(unvisited_nodes[0])

    n_total = distance_matrix.shape[0]
    if n_total <= 1:
        return destination_node

    # Distances from current and to destination
    d_curr = distance_matrix[current_node, unvisited_nodes]
    d_dest = distance_matrix[unvisited_nodes, destination_node]

    # Sub-matrix of unvisited nodes
    sub = distance_matrix[np.ix_(unvisited_nodes, unvisited_nodes)]
    np.fill_diagonal(sub, np.inf)
    
    # Cohesion: Average distance to other unvisited nodes
    avg_cohesion = np.sum(sub, axis=1) / (n_remaining - 1)
    
    # Exit flexibility: Min distance to other unvisited or destination
    min_exit = np.minimum(np.min(sub, axis=1), d_dest)
    
    # Orphan Penalty: Distance to the 2nd nearest unvisited neighbor.
    # This penalizes nodes that are close to one node but far from the rest,
    # which Algorithm 3's average might under-penalize if the cluster is large.
    if n_remaining > 2:
        sorted_dists = np.sort(sub, axis=1)
        second_nearest = sorted_dists[:, 1]
    else:
        second_nearest = np.full(n_remaining, np.inf)
    
    # Scale factor for invariance
    scale = np.mean(d_curr)
    if scale < 1e-9:
        scale = 1.0

    # Progress: 0 at start, 1 at end
    progress = (n_total - n_remaining) / (n_total - 1)
    
    # Smooth step function for return bias: stays low until late, then rises sharply
    # t is progress, smoothstep is t*t*(3-2t)
    return_weight = 0.1 + 0.6 * (progress * progress * (3 - 2 * progress))
    
    # Weights decay as progress increases
    cohesion_weight = 0.4 * (1 - progress)
    exit_weight = 0.2 * (1 - progress)
    orphan_weight = 0.15 * (1 - progress)
    
    # Normalized components
    d_curr_n = d_curr / scale
    d_dest_n = d_dest / scale
    cohesion_n = avg_cohesion / scale
    exit_n = min_exit / scale
    orphan_n = second_nearest / scale
    
    # Composite score
    scores = d_curr_n + return_weight * d_dest_n + cohesion_weight * cohesion_n + exit_weight * exit_n + orphan_weight * orphan_n
    
    # Tie-breaking: Prefer nodes with higher "flexibility" (more nearby options) 
    # to avoid dead ends if scores are very close.
    # We use the sum of the k-smallest distances as a proxy for local density/flexibility.
    k = min(3, n_remaining - 1)
    flexibility = np.sum(np.sort(sub, axis=1)[:, :k], axis=1)
    # Lower flexibility sum = higher density = better
    tie_breaker = 1e-6 * flexibility / scale
    
    final_scores = scores + tie_breaker
    
    # Handle potential numerical issues
    if np.any(np.isnan(final_scores)) or np.any(np.isinf(final_scores)):
        final_scores = d_curr_n + 1e-6 * np.arange(n_remaining)
        
    idx = int(np.argmin(final_scores))
    return int(unvisited_nodes[idx])
```

Algorithm 3
Fitness: -6.8239686184057184
Idea: Refine Algorithm 3 by replacing the weak regret amplification with a "regret-gap" term that penalizes second-best candidates more aggressively to avoid premature convergence to suboptimal paths. We improve the 2-step lookahead by explicitly including the return-to-destination cost of the *next* node, not just the candidate. The isolation penalty is smoothed by averaging with nearest-neighbor distance to balance local compactness against global connectivity. We use a convex progress-dependent weight for return bias, ensuring strong attraction to the destination only in the final 20% of the tour, while early steps prioritize local cluster formation.
Code:
```python
import numpy as np

def select_next_node(current_node: int, destination_node: int, unvisited_nodes: np.ndarray, distance_matrix: np.ndarray) -> int:
    """
    Design a novel algorithm to select the next node in each step.

    Args:
    current_node: ID of the current node.
    destination_node: ID of the destination node.
    unvisited_nodes: Array of IDs of unvisited nodes.
    distance_matrix: Distance matrix of nodes.

    Return:
    ID of the next node to visit.
    """
    if len(unvisited_nodes) == 0:
        return destination_node

    if len(unvisited_nodes) == 1:
        return int(unvisited_nodes[0])

    n_remaining = len(unvisited_nodes)
    n_total = distance_matrix.shape[0]

    # 1. Extract basic distances
    d_curr = distance_matrix[current_node, unvisited_nodes]
    d_dest = distance_matrix[unvisited_nodes, destination_node]

    # 2. Compute submatrix among unvisited nodes
    sub = distance_matrix[np.ix_(unvisited_nodes, unvisited_nodes)].copy()
    np.fill_diagonal(sub, np.inf)

    # Isolation metrics
    # Average distance to other unvisited nodes
    avg_iso = np.sum(sub, axis=1) / (n_remaining - 1)
    # Nearest neighbor distance
    min_neighbor = np.min(sub, axis=1)
    
    # Combined isolation score: balance between local compactness (min) and global spread (avg)
    # Weight min neighbor higher early to keep cluster tight, shift to avg later to ensure no node is left far
    iso_weight_min = 0.5 + 0.5 * (1.0 - (n_total - n_remaining) / (n_total - 1)) if n_total > 1 else 0.5
    iso_score = iso_weight_min * min_neighbor + (1 - iso_weight_min) * avg_iso

    # 3. Improved 2-step Lookahead
    # For each candidate i:
    # Cost = d(curr, i) + min_{j != i} ( d(i, j) + d(j, dest) )
    # This approximates the cost of visiting i, then the best possible next node j, then returning to dest.
    
    # Matrix of (d(i, j) + d(j, dest)) for all i, j
    # d(i, j) is sub[i, j]
    # d(j, dest) is d_dest[j]
    # We need min over j != i
    
    # Construct cost matrix: C[i, j] = sub[i, j] + d_dest[j]
    # But sub[i, i] is inf, so min will naturally skip i if we take min over all j
    # Wait, sub[i, j] is inf when i==j.
    # So min_j (sub[i, j] + d_dest[j]) will effectively find the best next hop.
    
    # However, this assumes we must visit another unvisited node next.
    # If n_remaining == 2, and we pick i, the next must be the other node k, then dest.
    # The formula handles this correctly: min over j != i.
    
    # Calculate lookahead cost
    lookahead_cost = np.min(sub + d_dest[np.newaxis, :], axis=1)
    
    # 4. Dynamic Weights
    if n_total > 1:
        progress = (n_total - n_remaining) / (n_total - 1)
    else:
        progress = 1.0

    # Weights
    w_return = 0.05 + 0.45 * (progress ** 2)  # Stronger return bias in late tour
    w_iso = 0.1 * (1.0 - progress)           # Fade isolation penalty as tour completes
    w_lookahead = 0.25                       # Constant weight for lookahead
    
    # Base score
    scores = d_curr + w_return * d_dest + w_iso * iso_score + w_lookahead * lookahead_cost

    # 5. Regret-Gap Amplification
    # Instead of linear regret, use a sharper penalty for being "second best"
    # This helps avoid oscillating between close choices by strongly preferring the global min
    min_score = np.min(scores)
    # Regret gap: (scores - min_score) ** 1.5 is sharper than linear
    regret_penalty = 0.05 * (scores - min_score) ** 1.5
    final_scores = scores + regret_penalty

    idx = int(np.argmin(final_scores))
    return int(unvisited_nodes[idx])
```
