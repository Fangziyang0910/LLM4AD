# 科研周报｜2026 年第 37 周

## 1. 当前卡点与核心挑战

本周我们继续围绕 TraceAAD 冲击跨任务整体 SOTA 展开高强度攻坚。此前 V10.1~V10.6 虽然在局部任务（如 OBP、VRPTW）表现突出，但在五任务综合排名上仍难以稳定压制顶尖基线（MCTS-AHD）。通过对历史搜索轨迹与运行日志的深度诊断，我们锁定了三大关键瓶颈：

1. **上下文冗余与语义泄漏**：提示词中堆砌了大量防御性约束（“不要做 X”）、历史角色陈述以及未经验证的 AST 结构偏好，不仅挤占了有效上下文，反而干扰了模型对核心算法机制的注意力；
2. **错误损耗过大**：V10.9 阶段诊断暴露出高达 144 次候选解析失败与 203 次评价运行崩溃，宝贵的 1000 次评估预算有近 20% 被无效耗散，且失败样本未转化为有益的自省信号；
3. **评测基准契约的绝对刚性**：历史迭代中因模板微调或种子差异带来的潜在评估漂移，对学术结论的自洽性构成了潜在威胁，亟需在全仓确立不可撼动的冻结契约。

## 2. 主要尝试与版本演进

围绕上述问题，我们在算法设计、机制验证、契约规范与工程架构上推进了一整套系统性攻坚：

1. **深层机制验证与理论证伪**：
   - **Refine E1**：通过行为置换检验明确了质量条件行为增量无显著增益，果断叫停低信噪比的复杂实验分支；
   - **Pivot E2**：通过固定锚点成对干预实验证实当前数据不支持一步 horizon 下的 Pivot stepping-stone 增量假说，指引算子回归纯粹的机制探索；
   - **BehaveSim 全 Archive 验证**：消除了采样偏差，在全群体尺度上确认了行为几何在 TSP、OBP、VRPTW 上的普遍有效性。
2. **纯减法机制演化（V10.7R -> V10.10）**：
   - **V10.7R** 精简至单机制并严封 Prompt 语义泄漏；
   - **V10.8** 建立可核验形成轨迹并在评价前硬拦截父代/donor 复制；
   - **V10.10 大版本收敛**：移除试错注入，算子指令重构为“设计动作三要素”（设计对象 + 认知操作 + 结果目标），初始化收缩为有序知情初始化（sequential informed initialization），并引入代码优先解析与最多一次有界错误修复（bounded repair，以 `stage=repair` 关联 `repair_of`）。
3. **五任务公共实验信息冻结契约（2026-09-12 契约）**：
   - 在全仓确立最高级别硬约束：哈希冻结五任务说明、模板代码与种子数据集，编写 17 项冻结自动化测试（`tests/task/test_frozen_task_contract.py`）；
   - 启动外部基线定点重跑批 rerun2（Qwen3.6 int4 同源量化栈），确保主实验数据的绝对公正。
4. **科研文档体系现代化与 V10.11 双模型实验体系上线**：
   - 彻底重构全库文档为科研主体垂直闭环六大支柱，清理 14 万余行历史废弃代码、草稿与中间数据；
   - 独立研发函数级模块化 TraceAAD V10.11，支持 Qwen3.8 与 Qwen3.6 双模型并发调度、全量训练可视化与持久监控。

## 3. 新的研究认识与理论洞察

1. **有界错误修复（Bounded Repair）远胜于前置防御性约束**：
   将规则从“生成前叮嘱模型不要写错”转变为“宽容解析 + 真实报错反馈下的最多一次有界修复”，成功将原本丢弃的语法和浅层运行时错误转化为高质量算法，极大地提高了 1000 预算的有效探索深度。
2. **极简动作三要素与短形成路径激发更强创新能力**：
   V10.10 首批 15/15 完赛取得了历史性突破：**TSP 三规模六方法全列第一，15 列平均名次达到 2.133（2/6，距第 1 名 MCTS-AHD 仅差 0.067）**，验证了去冗余、强修复、重语义正向引导的技术路线的正确性。
3. **算法几何的领域边界被清晰标定**：
   BehaveSim 全 Archive 验证表明，行为空间距离与表现差异的正相关性在构造类启发式（TSP、OBP、VRPTW）上坚如磐石，但在元启发式/局部搜索主导的任务（CVRP、OP）上需谨慎迁移，不能盲目泛化几何引导。

## 4. 下一阶段安排

2. **收尾基线定点重跑批 rerun2**：完成 EoH 与 MCTS-AHD 在关键优势组合上的严格重测，固化不可撼动的基准对比线。
