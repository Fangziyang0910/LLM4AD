### ACO 任务补充

- **CVRP-ACO**：另有 `aco_seed=1234`，ACO：30 ants × 100 iterations。
- **OP-ACO**（对齐 ReEvo / HSEvo / PathWise / CALM）：
  - 验证 split：OP50/100/200 × 64，seed **3456**（`val_50`/`val_100`/`val_200`）
  - 路程预算：OP50/100/200 → maxlen **3 / 4 / 5**
  - Prize：Kool 式（相对 depot 距离离散化后归一化）；depot 为实例第 0 点（单位正方形随机）
  - ACO：**20 ants × 50 iterations**，`aco_seed=1234`
  - 指标：平均 collected prize，越高越好

KP 当前仍用 LLM4AD 整数重量/价值生成（`capacity=100`）；规模已与论文一致（训 100、测 50/100/200）。OBP 物品尺寸按 Weibull(3,45) 采样并裁剪到 100，与箱容量无关。
