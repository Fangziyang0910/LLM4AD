# V10.1 预算流向—算子产出—后续兑现联合分析（批次 20260902）

口径：批次 20260902 共 15 路（5 任务 × 3 重复，1000 评价预算）。截至分析时 10 路完成，5 路仍在跑（cvrp r2 @768、cvrp r3 @542、tsp r2 @638、vrptw r2 @660，表中 budget 列即各路实际消耗）。fitness 为训练集口径、越大越好，直接用原值（负数）报告。数据源：各 run 的 `batches.jsonl`（每批一次父节点选择 + R/P/F 三个子代结果）、`tree_state.json`（最终树）、`events.jsonl`（每次生成尝试）。

## 核心判断

1. **节点层的父节点分配健康**（方向族粒度的分配是另一回事，见[方向族预算流与Fuse角色分解](方向族预算流与Fuse角色分解.md)）。Top-1 节点只拿 2–6% 的父节点机会，Top-5 拿 6–17%，每个 run 实际复用 99–230 个不同父节点；ESS 实际/目标全程约 1.0。好坏 run 的分配形状没有稳定差异。
2. **单步产出差异极大且按算子—父节点状态高度结构化**：Fuse 在 top5% 父节点上改进率 10–28%、在 5–20% 父节点上 28–60%；Refine 次之；Pivot 在 top5% 父节点上改进率仅 0–2.1%、中位相对退化 −1.8% 至 −76%。1:1:1 固定算子预算把约 1/3 评价花在了最不适配其作用对象的算子上。
3. **后续兑现几乎只走"出生即好"这条路**。全批次 12552 个 R/P/F 子代中，出生时 Δq<0 的 8764 个里后来子树出现新全局最优的仅约 96 例（1.1%）；其中 Pivot 只有 4 例，且相对退化全部 ≤ 1.3%（近平手），没有一例大倒退 Pivot（中位相对 −28% ~ −76%）被复选后兑现。
4. **run 间差异由"结构跳变是否出现"主导，且赢家起点反而更差**：三组同任务对照（CVRP、TSP、VRPTW）全部是赢家 run 的 best-lineage 根节点质量低于输家，赢家靠早期（budget < 220）的一次结构性跳变（多为 Pivot，VRPTW r2 为两次大步 Refine）进入新想法族，输家全程困在 init 想法族内打磨。
5. **突破后不缺复选压力，缺的是对该节点的有效提案**：最终 best 出生后多数 run 只再复选 0–3 次，但 OP r1（11 次复选、656 预算无改进）与 VRPTW r1（best 家族被复选 15/14/10/9/9 次、805 预算仅 +0.01）说明压力给足也磨不动。

对四个候选情况的判定：**A（算子预算错配）成立，集中于"Pivot 无差别上 top 父节点"；B（quality-only 不支持 delayed realization）结构性成立但观测上未被需要——所有兑现走近平手通道；C（ESS 过散）不是主瓶颈；D（提案/初始化多样性）是 run 间差异的主导来源。**

## 4 最终 best 的 lineage（三组同任务对照）

### Case C：CVRP r2（−8.1408，@768）——结构由两次 Pivot 决定

```text
b0    #3   Init    −20.20   （8 个 init root 中最差；init 最好是 −16.07）
b13   #9   Pivot   −11.60   Δq +8.60，父节点分位 0.12 ← 批次唯一来自弱父节点的 Pivot 突破
b25   #19  Refine  −11.04
b28   #24  Fuse    −10.95   donor #16
b37   #32  Pivot   −11.09   Δq −0.14 ← 近平手 Pivot，存活于 lineage
b43   #38  Fuse    −10.13   donor #23
b52   #45  Pivot   −10.22   Δq −0.08 ← 近平手 Pivot，存活于 lineage
b78   #69  Fuse     −9.94   donor #55
b102  #86  Refine   −9.59
b136  #118 Pivot    −8.32   Δq +1.27 ← Clarke-Wright savings，第二次结构跳变
b184~#653  Fuse/Refine 链 ×17，−8.28 → −8.14
```

b200 时 best 已达 −8.249（距最终 0.11）；b290 之后的 478 预算只换来 +0.10。这个 run 的全部优势在 budget 200 之前建立，其中两次决定性跳变都是 Pivot：一次来自最差的 init root（早期 ESS 分散给了弱节点机会），一次是对 top 父节点的 Clarke-Wright 换构。对照 r1：lineage 根即 init 最好（−10.25），其余 18 个 lineage 节点全部是同一"Gaussian 径向相干"族内的 Fuse/Refine 打磨（13 F + 5 R，无 Pivot），终值 −9.01；r3 同样困在 init 的 demand-affinity 族（根 −15.90，终值 −9.30）。Clarke-Wright 想法只出现在 r2。

### Case A：TSP r1（−6.0928）vs r3（−5.8375）

- r3 的 lineage 含 4 次成功 Pivot：b17 纯最近邻（从分位 0.64 的父节点，+1.08）、b86 两步前瞻、b148 组合前瞻（+0.18）、b623 最小生成路径（+0.03），加上多起点构造的 Refine（b800 +0.11），从 init −7.77 一路跳到 −5.84。b400 时 best −6.022。
- r1 的 lineage 只有一次 Pivot（b146，potential-field，+0.37），此后到 b1000 全是同族 Fuse/Refine：b259 达 −6.204 后，剩余 741 预算仅 +0.11。b400 时 best −6.204，差距已拉开。
- 两者的分配形状接近（r1 反而略更集中），差异在于 r3 反复换构成功、r1 只换构成功一次。

### Case B：VRPTW r1（−20.6261）vs r3（−18.9840），r2（−19.3136，@660）

- r1 起点是三者中最好的 init（lineage 根 = init 最好，−21.49），但 lineage 没有任何成功 Pivot：b23–b90 的 8 个子代全部停在 −21.239，b195 达 −20.636 后 **805 预算只换来 +0.01**（breakthrough 间隔最大 466）。它是全批次分配最集中的 run（最高两节点被选 15/14 次），best 家族被反复复选也没有产出改进。
- r3 起点是自己的 8 个 root 中最差的（−24.02，init 最好 −22.70）：Refine 链先把 regret-插入想法修到 −21.0（b16 +3.00），b37 一次 UCB 选择机制的 Pivot 跳到 −20.12（+1.59），之后 Fuse 链持续兑现，改进一直持续到 b999（−18.984）。
- r2 已在 660 预算内到 −19.314：没有 Pivot，但两次大步 Refine（b180 指数松弛映射 +0.59、b218 冗余项裁剪 +0.55）起到了换构作用。
- 三组对照的公共结论：**赢家 run 的 best-lineage 根节点全部比输家差**（CVRP −20.20 vs −10.25；TSP −7.77 vs −6.82；VRPTW −24.02 vs −21.49），决定终局的是结构跳变（Pivot 或等效的大步 Refine）是否在早期出现并被后续 Fuse/Refine 链兑现，不是起点的绝对质量。

## 5 突破之后发生了什么

- 好 run 的突破持续到预算末端：final best 出生预算 tsp r3 972、vrptw r3 999、cvrp r1 971、obp r2 988、tsp r1 1000——搜索没有在后期失去改进能力，也没有出现"好节点被 ESS 稀释后彻底饿死"的形态（ESS 达标、best 家族持续被选）。
- 反例检验"复选压力不足"：OP r1 的 best 在 b344 出生，之后获得 11 次复选、消耗 656 预算，无任何改进（全 run 8 次突破，最后两次间隔 207）；VRPTW r1 的 best 家族被复选 15/14/10/9/9 次仍只有 +0.01。压力给足也磨不动——突破后的瓶颈是"对该节点还能提出什么"，不是"它还有没有被选到"。
- 失败 run 的特征是突破旱段而非分配旱段：VRPTW r1 最大突破间隔 466；OBP r2 在 b254 达 −731.25 后 668 预算无突破；OBP r3 前 711 预算零突破（init 平台上 664 个并列节点把选择稀释成近似均匀，改进率 ~0，最终 4 路突破全部来自 b711 之后）。OBP 的弱势是量化平台景观 + 并列稀释的分配，与 R/P/F 配比无关。

## 归因结论

**搜索控制层（给哪个节点、给多少次）在 V10.1 中工作正常**：分配覆盖 61–82% top5% + 16–33% 5–20% 父节点、ESS 达标、好坏 run 分配形状无稳定差异、复选压力给足时提案跟不上。

**真正的差距在两层**：

1. **算子—上下文错配（情况 A，成立）**：1/3 预算的 Pivot 被无差别用在 top 父节点上，那里它的单步改进率 0–2.1%、中位退化 −28% ~ −76%、还贡献了最高的 invalid/评价失败率。Pivot 的观测价值集中在少数大跳变（16/23 的 Pivot 突破仍来自 top5% 父节点），其中最有价值的一次（CVRP r2 #9）发生在弱父节点上——恰是后期分配（父节点分位恒在 0.93+）不再提供的位置。算子预算按父节点状态差异化，比全局 1:1:1 更接近观测到的价值分布；但层数据见[方向族预算流与Fuse角色分解](方向族预算流与Fuse角色分解.md)——更深的错配在方向层，不在算子层。
2. **提案端多样性主导 run 间差异（情况 D，主导）**：三组对照中赢家起点全更差、全部靠早期结构跳变翻盘；输家不缺机会（复选充分）而缺想法（lineage 困在 init 想法族）。CVRP 的 Clarke-Wright、VRPTW 的 UCB 选择、TSP 的最近邻+前瞻，都是单次生成事件决定了整个 run 的上限。

**两个排除项**：delayed realization 通道（情况 B）在数据上只被近平手子代使用过，它们没有被饿死；大倒退 Pivot 子代每子代仅 0.01 次复选，其 delayed value 基本未被观测——数据只能支持"当前 policy 下成功路径不依赖它"，不构成普遍结论。ESS 扩散（情况 C）不是约束——ESS 达标，且复选压力充足时瓶颈转移到提案。
