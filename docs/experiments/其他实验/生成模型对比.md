## deepseek-v4-flash

| 项 | 值 |
| --- | --- |
| 模型 | `deepseek-v4-flash` |
| 搜索预算 | 1000 次评估 |
| 重复 | 2（seed 0、1） |
| 方法 | MCTS-AHD、PathWise、EoH、ReEvo、CALM |
| 任务 | TSP、CVRP、OP、OBP |
