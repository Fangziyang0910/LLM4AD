# 500 次评价预算对照

与[主实验](../主实验/结果.md)相同的运行与任务：每路取前 500 次真实评价内训练集最优的样本（`sample_order <= 500`），在 held-out 测试集重新评估。数值为 3 次运行均值 ± 样本标准差；加粗为该列最佳均值。搜索列为该 500 预算 best 的训练集分数。

方法集与主表一致，差异只有：TraceAAD V9 的中途 best 工件未留存，无法重评；V9.21 仅 OBP 有完整 1000 预算批次（其余任务是约 674 评的测试快照）；VRPTW 无 V9。评估超时 TSP 3000 / CVRP 120 / OP 60 / OBP 30 / VRPTW 1000 秒。入口 `experiments/analysis/run_budget500_eval.py`，逐组工件在各 `eval_best_budget500_20260830/`，汇总数据在本文同目录 `budget500-heldout-summary.json`。

## 与 1000 预算的对比

- 500 预算的 15 列平均名次上 MCTS-AHD 最好（2.000），CALM 2.400、EoH 2.667，四个 TraceAAD 版本 2.733–3.000 均落后于 MCTS-AHD；1000 预算时 V9.17 以 2.100 居首。TraceAAD 的相对优势随预算增长。
- TSP 与 VRPTW 在 500 预算已由 TraceAAD 领先：V9.20 在两个任务的搜索列与全部 held-out 列均为最佳（1000 预算时 V9.20 在 TSP 四列均非第一）。
- CVRP 与 OP 的 held-out 在 500 预算多数列由基线领先：MCTS-AHD 占 CVRP100/200 与 OP200，EoH 占 OP50/100；TraceAAD 在这两任务的其余列（CVRP 搜索列、CVRP50）由 V9.19 领先。1000 预算时 V9.17 在 CVRP100 反超 MCTS-AHD，MCTS-AHD 在 OP 三列全占。
- 搜索列 500→1000 的变化：TSP 上五个基线改进 0.02–0.12（CALM 不变），TraceAAD 各版本改进 0.02–0.10 且两个预算点都低于全部基线；OBP 上 CALM 与 ReEvo 的 best 在 500 前已定，EoH 改进 2.3 箱，TraceAAD 各版本改进 0.1–1.7 箱。
