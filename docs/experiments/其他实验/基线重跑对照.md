# 基线五方法重跑对照

批次 `20260824_rerun`：EoH / ReEvo / MCTS-AHD / PathWise / CALM × TSP / CVRP / OP / OBP × 3 重复，1000 次真实评价。本页对照重跑 held-out 与原批次；[主实验](../主实验/结果.md)基线行保持原批次数字。TSP timeout 3000 秒。
