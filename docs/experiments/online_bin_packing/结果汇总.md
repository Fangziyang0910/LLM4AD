# Online Bin Packing 实验结果

## 实验设置与比较口径

本页比较 Online Bin Packing 方法在固定搜索协议下的测试平均箱数。Qwen3.6-27B 使用 `1k/5k × capacity=100/500` 的四个固定实例作为搜索集；测试集为新的 `1k/5k/10k × capacity=100/500` item 序列，各 5 个实例。前两档是同分布独立测试集，最后一档是不同规模测试集。每种方法独立运行 3 次，所有方法搜索预算均为 1000。指标为平均箱数，越低越好。

表中每个数值为 3 次运行的测试均值 ± 样本标准差；± 仅描述运行间变异，不是置信区间，也不支持统计显著性判断。加粗表示该列的最佳均值。

### 结果解释与限制

TraceAAD V4 在 `1k/100`、`5k/100` 和 `10k/100` 的报告均值最低；在 `1k/500` 中，TraceAAD V6、V8 与 ReEvo 并列最低；TraceAAD V8 在 `5k/500` 和 `10k/500` 的报告均值最低。V8.2 在 capacity=100 上相对 V8 更好，在 capacity=500 上弱于 V8。V8.3 在 capacity=100 三规模均值介于 V4 与多数方法之间，但未取得列最佳；capacity=500 弱于 V8。上述并列和排序均为均值描述，不代表统计显著性。结论限于给定 item 序列、capacity、测试设置、搜索预算和 3 次独立运行，不能据此推断对其他序列或容量的普遍优势。
