# Online Bin Packing 实验结果

## 实验设置与比较口径

本页比较 Online Bin Packing 方法在固定搜索协议下的测试平均箱数。Qwen3.6-27B 使用 `1k/5k × capacity=100/500` 的四个固定实例作为搜索集；测试集为新的 `1k/5k/10k × capacity=100/500` item 序列，各 5 个实例。前两档是同分布独立测试集，最后一档是不同规模测试集。每种方法独立运行 3 次，所有方法搜索预算均为 1000。指标为平均箱数，越低越好。

表中每个数值为 3 次运行的测试均值 ± 样本标准差；± 仅描述运行间变异，不是置信区间，也不支持统计显著性判断。加粗表示该列的最佳均值。

版本边界：表中的 **TraceAAD V9.7** 是仅父代来时路的完整协议（批次 `20260814_150927`），四任务三重复已齐，跨任务排名使用本列。**TraceAAD V9.8** 为 `q_u_c_m` 正式批次（`20260815_225000`），已纳入跨任务总体和单独排名。**TraceAAD V9.9** 为批次 `20260816_154200`；TSP、OP、OBP 已完成三重复 held-out，CVRP 仍在搜索，因此暂不进入跨任务排名。**TraceAAD V9.10** 为批次 `20260817_222517`（折扣 Thompson 联合分配）；TSP 与 OBP 三重复已完成 held-out，CVRP 与 OP 仍在搜索，因此暂不进入跨任务排名。**TraceAAD V9.7-batch** 使用 V9.6 的 `formation + direct attempts` 历史上下文，只作同页对照。另有本地 Qwen3.8 批次 `v9_7_qwen38_20260815_010107`，本页仅将已完成的 OBP held-out 作为诊断行，不纳入跨任务排名。

### 结果解释与限制

TraceAAD V9.6 在 `1k/100` 的报告均值最低，并在 `1k/500` 与 V6、V8、V9.2、V9.3、ReEvo、V9.7-batch 并列最低（80.800）；TraceAAD V9.7 在 `5k/100` 最低；CALM (w/o GRPO) 在 `10k/100` 最低；TraceAAD V9.7-batch 在 `5k/500`、`10k/500` 最低。V9.7 相对 V9.6 的六档差为 +0.4%/−0.1%/−0.2%/+0.5%/+0.1%/+0.1%，方向不完全一致。V9.7 与 V9.7-batch 的差距同样在该量级。六档没有形成同向的统一改善。

其余版本间的六档均值差多在 0.02%–1.3%，方向不完全一致，不逐对展开（V9.1 两协议、V9.2、V9.3、V9.4 均未取得列最佳；V8.2 相对 V8 在 capacity=100 更好、capacity=500 更弱；V8.3 未取得列最佳）。

上述并列和排序均为均值描述，不代表统计显著性。结论限于给定 item 序列、capacity、测试设置、搜索预算和 3 次独立运行，不能据此推断对其他序列或容量的普遍优势。
