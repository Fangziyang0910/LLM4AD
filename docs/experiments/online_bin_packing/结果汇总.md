# Online Bin Packing 实验结果

## 实验设置与比较口径

本页比较 Online Bin Packing 方法在固定搜索协议下的测试平均箱数。Qwen3.6-27B 使用 `1k/5k × capacity=100/500` 的四个固定实例作为搜索集；测试集为新的 `1k/5k/10k × capacity=100/500` item 序列，各 5 个实例。前两档是同分布独立测试集，最后一档是不同规模测试集。每种方法独立运行 3 次，所有方法搜索预算均为 1000。指标为平均箱数，越低越好。

表中每个数值为 3 次运行的测试均值 ± 样本标准差；± 仅描述运行间变异，不是置信区间，也不支持统计显著性判断。加粗表示该列的最佳均值。

### 结果解释与限制

TraceAAD V9 在 `1k/100`、`5k/100` 的报告均值最低；CALM 在 `10k/100` 的报告均值最低（略低于 V9）；在 `1k/500` 中，TraceAAD V6、V8 与 ReEvo 并列最低；TraceAAD V8 在 `5k/500` 和 `10k/500` 的报告均值最低，V9 在 capacity=500 三档均弱于 V8，CALM 弱于 V9。V9.1 两个协议六档均值均弱于 V9（Trajectory 协议在 `5k/500` 与 `10k/500` 上为 V9.1 最佳但未超过 V8/V9），两协议互有胜负：MCTS-Aligned 在 `5k/100`、`10k/100`、`1k/500` 更低，Trajectory 在 `1k/100`、`5k/500`、`10k/500` 更低，差距均在 1% 以内。V9.2 六档均值介于 V9.1 两协议附近且整体弱于 V9（`1k/100` 与 MCTS-Aligned 持平、`1k/500` 与 V6/V8/ReEvo 并列列最佳 80.800，其余四档差于 V9.1 Trajectory 约 0.1%–1.3%）。V9.3 六档均值相对 V9 互有胜负：`1k/100`、`5k/100` 差于 V9（高约 1.2%/0.1%），`10k/100` 与 capacity=500 三档略优于 V9（低约 0.02%–0.08%），其中 `1k/500` 与 V6/V8/V9.2/ReEvo 并列列最佳 80.800，其余各档均未取得列最佳。V9.4 六档均值差于 V9.3（仅 `1k/100` 低约 0.1%，其余五档高约 0.1%–1.3%），相对 V9.2 在 capacity=100 三档更好（低约 0.8%–1.0%）、capacity=500 略差，未取得列最佳。V8.2 在 capacity=100 上相对 V8 更好，在 capacity=500 上弱于 V8。V8.3 在 capacity=100 三规模均值介于 V4 与多数方法之间，但未取得列最佳；capacity=500 弱于 V8。上述并列和排序均为均值描述，不代表统计显著性。结论限于给定 item 序列、capacity、测试设置、搜索预算和 3 次独立运行，不能据此推断对其他序列或容量的普遍优势。
