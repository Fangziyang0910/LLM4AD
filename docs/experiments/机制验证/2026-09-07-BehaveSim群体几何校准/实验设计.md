# BehaveSim 群体几何校准实验设计

## 1. 研究纠偏

E1-A 与 E1-A.1 没有否定 BehaveSim 对算法群体的描述价值。它们否定的是更强的个体外推：即使行为近的算法在群体中往往具有更接近的 fitness，也不能据此判断某个节点下一次 Refine 更容易成功。单次 LLM 生成方差很大，突破事件又稀疏，用群体相关性承担个体反事实预测会混淆两个命题。

本轮将 BehaveSim 的职责限定为 **population-level search geometry sensor**。它描述搜索是否拥挤、收缩或扩散，是否存在多个高质量行为区域，Explore/Pivot 是否产生了实际行为跨度，以及 Fuse 两个输入是否来自不同区域。它提供调整碰撞分布的观测量，不为具体节点给出潜力分数。

## 2. 前置实现判断

当前 v3 距离实现保留：中间解采用归一化编辑距离，PSTraj 用 DTW 对齐并除以较短轨迹长度，最后对相同 probe 配对求平均。TSP 与 VRPTW 的状态及执行过程保持现状；OBP 的 decision prefix 表示保持现状，仅校准 probe 规模；OP/CVRP 的 ACO 主循环保持现状，仅扩展随机流采样。

## 3. 校准问题

### 3.1 OBP 规模匹配

对同一批候选分别计算两套两面板几何：

- compact：每个 panel 为 2 个 256-item 序列 × capacity 100/500；
- scale-matched：每个 panel 为 1 个 1000-item 序列和 1 个 5000-item 序列，各自配 capacity 100/500。

两套协议都完整执行 item stream，再均匀抽取 12 个 decision-prefix 状态。若三个 run 的距离矩阵 Spearman 均不低于 0.90，且 kNN 重合率均不低于 0.70，后续保留便宜的 256-item probe；否则切换到 scale-matched 版本。

### 3.2 OP/CVRP 随机流

每个 panel 保留 4 个实例，每实例使用 4 个固定 ACO seed offset：`0, 10000, 20000, 30000`。算法 A/B 在相同实例上始终使用相同 seed，距离对 16 条 `instance × seed` PSTraj 平均。

稳定性同时检查：

1. 单随机流与四随机流距离矩阵的一致性；
2. panel A/B 的四随机流距离矩阵一致性；
3. 前两个与后两个随机流组成的两个不相交子集的一致性。

只有当三个 run 的 panel Spearman 和不相交 seed-half Spearman 都不低于 0.80，才把对应 ACO 任务称为已经得到稳定的行为几何。无论是否过门槛，都完整报告结果，不用跨任务平均掩盖失败。

## 4. 冻结样本

数据来自 V10.6 的 15 个冻结 run，不生成新算法，也不调用正式 evaluator。每个 run 只从已有有效双面板画像覆盖的节点中取样：按 fitness 分成四层，再在每层按 evaluation order 均匀取点。TSP 取 48 个节点，OBP、VRPTW 各取 64 个节点；计算更贵的 OP/CVRP 各取 12 个节点。TSP 第一重复在冻结时只有 57 个有效双面板画像节点，因此没有为了凑 64 个而改变画像覆盖条件。本轮是度量校准与群体 sanity check，不估计动作响应。

事后覆盖审计表明，旧 E1 画像主要来自曾被选作 Refine parent 的节点。因此本轮 landscape 只代表覆盖多个 fitness 层级的历史 Refine-parent 子群体；校准结论仍成立，完整 archive 的群体外推由后续[全 Archive 群体验证](../2026-09-07-BehaveSim全Archive群体验证/实验设计.md)单独处理。

## 5. 群体景观 sanity check

校准完成后，每个 run 只计算三项预先固定的统计量：

1. 全部无序节点对的 BehaveSim 距离与标准化 fitness 绝对差的 Spearman；
2. 行为 kNN 的平均 fitness 差与均匀随机节点对期望的差，其中 $k=\max(2,\lceil0.05(n-1)\rceil)$；
3. 按行为距离排序后等数量划分近、中、远三档，比较三档平均 fitness 差。

某任务只有在三个 run 中同时满足 Spearman 为正、kNN gap 小于随机 pair、远档 gap 大于近档，才记为复现群体几何命题。这个门槛不要求严格单调的近—中—远关系，也不产生任何节点级 Refine 决策。

## 6. 结果解释边界

- 正结果只支持固定任务和 probe 分布下“行为近的算法在群体统计上 fitness 往往也更近”。
- 它不支持行为梯度可沿、不支持近邻共享 LLM 变异响应，也不支持挑选某个节点继续 Refine。
- ACO 若未通过随机流稳定性门槛，其景观统计只能作为探索性结果。
- 后续若把几何用于搜索，目标应是改变区域覆盖、深广比例或 Fuse 配对分布，并用等预算策略实验验证，而不是把距离直接当收益。
