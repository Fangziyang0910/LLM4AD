# BehaveSim 群体几何校准结果

## 核心结论

这轮结果支持把 BehaveSim 用作 **历史 Refine-parent 子群体层面的搜索几何传感器**，但支持范围有清楚的任务边界。由于样本先要求存在旧 E1 画像，本页不能单独代表完整 archive；这一覆盖限制已由后续[全 Archive 群体验证](../2026-09-07-BehaveSim全Archive群体验证/结果.md)补齐。

- TSP、scale-matched OBP、VRPTW 在 V10.6 三个重复中都复现了“行为越近，fitness 在群体统计上也越近”；
- OP 的四随机流画像比单流稳定得多，群体关系三个重复全部同向，但 panel 稳定性有一个重复以 0.776 略低于预注册的 0.80，暂不标记为完全校准；
- CVRP 的四随机流画像仍不稳定，并出现一个重复的全体 pair 负相关和 kNN 劣于随机，当前不能用它描述可靠的局部几何；
- OBP 的 256-item probe 没有通过 scale-match 门槛，后续新分析改用 1000/5000-item probe。

这些结论不恢复任何个体潜力预测。它们说明算法群体不是完全无结构的，不说明某个行为邻居下一次 Refine 更可能成功。

## 1. 执行与数据

实验复用了 V10.6 的 15 个冻结 run 和 E1 的旧双面板画像。本轮新增 264 份两面板画像：OBP 192 份、OP 36 份、CVRP 36 份，全部成功；没有生成新算法，也没有增加正式搜索评价预算。节点—run 样本共 600 个，TSP 每 run 48 个，OBP/VRPTW 每 run 64 个，OP/CVRP 每 run 12 个。

OBP scale-match 完整执行 1000/5000 个 item，只在预先确定的 12 个位置流式保存 decision prefix；该实现已在 256-item probe 上与旧版逐状态、逐分数完全对齐。OP/CVRP 每个 panel 使用 4 个实例和 4 个固定随机流，即每候选 16 条 PSTraj；其中 offset=0 的四条轨迹在两个 panel 上都与旧单流产物逐项相同，排除了主循环改写造成的协议漂移。

完整数值见[汇总 JSON](BehaveSim群体几何校准汇总.json)，预注册口径见[实验设计](实验设计.md)。

## 2. OBP：必须切换到 scale-matched probe

| 重复 | compact–matched 距离 Spearman | kNN 重合率 | matched panel A/B Spearman |
| ---: | ---: | ---: | ---: |
| 1 | 0.897 | 0.574 | 0.870 |
| 2 | 0.991 | 0.871 | 0.994 |
| 3 | 0.843 | 0.586 | 0.955 |

预注册门槛要求三个重复的距离 Spearman 均不低于 0.90，且 kNN 重合率均不低于 0.70。重复 1 和 3 都没有满足，因此不能把 256-item probe 当成正式训练规模几何的廉价替代。

这不是 OBP 状态表示错误。两套协议记录的都是每个 item 最终进入哪个 bin 的 decision prefix；差异来自短序列没有充分暴露长期装箱策略。后续新画像默认采用 1000/5000-item scale-match，旧 E1/E2 产物继续按其历史 compact 协议解释，不做静默覆盖。

## 3. ACO：OP 改善明显，CVRP 仍不可靠

下表依次给出三个重复的距离矩阵 Spearman。

| 任务 | 旧单流 panel A/B | 单流–四流 | 四流 panel A/B | 不相交 seed halves |
| --- | --- | --- | --- | --- |
| OP | 0.704 / 0.690 / 0.686 | 0.898 / 0.935 / 0.908 | 0.900 / 0.776 / 0.820 | 0.912 / 0.914 / 0.820 |
| CVRP | 0.245 / 0.195 / 0.665 | 0.715 / 0.778 / 0.935 | 0.490 / 0.441 / 0.790 | 0.531 / 0.471 / 0.928 |

OP 的两个不相交随机流子集在三个重复中都超过 0.80，说明四流平均确实压低了 seed noise；四流 panel 也全面高于旧单流 panel。不过重复 2 的 panel 相关为 0.776，按冻结门槛仍判未通过。它更适合被描述为“接近可用，需要增加实例/随机流或扩大候选样本复核”。

CVRP 的重复 1、2 在 panel 与 seed-half 两项上都很低。多随机流改变了单流几何，却没有让不同 probe 或随机流子集收敛到同一排序。当前应暂停使用 CVRP BehaveSim 做区域、近邻或 Fuse 配对判断；继续堆 seed 之前，应检查 incumbent-only PSTraj 是否遗漏了 ACO 群体状态，以及 route edit distance 是否适合这一随机过程。

## 4. 群体 landscape sanity check

fitness gap 是 run 内标准化 fitness 的绝对差。`随机−kNN` 为正表示行为近邻的 fitness 更接近；`远−近` 为正表示远距离档的平均 fitness gap 更大。

| 任务 | 每 run n | distance–gap Spearman（三重复） | 随机−kNN（三重复） | 远−近（三重复） | 预注册群体命题 |
| --- | ---: | --- | --- | --- | --- |
| TSP | 48 | 0.600 / 0.724 / 0.275 | 0.814 / 0.838 / 0.774 | 1.009 / 1.414 / 0.402 | 支持 |
| OBP | 64 | 0.613 / 0.658 / 0.351 | 0.900 / 0.804 / 0.929 | 1.197 / 1.352 / 0.470 | 支持 |
| VRPTW | 64 | 0.723 / 0.745 / 0.150 | 0.539 / 0.765 / 0.329 | 1.659 / 1.518 / 0.406 | 支持 |
| OP | 12 | 0.559 / 0.847 / 0.726 | 0.517 / 0.403 / 0.512 | 1.528 / 1.826 / 2.020 | 数值支持，测量门槛未完全通过 |
| CVRP | 12 | -0.055 / 0.557 / 0.666 | -0.007 / 0.398 / 0.225 | 0.144 / 1.951 / 1.851 | 不支持 |

TSP、OBP、VRPTW 的三类统计在九个 task-run 中全部同向，复现了旧 landscape 实验的核心群体认识。它们支持“行为表型给出了 fitness 地形的第二视角”。近、中、远三档并非每次严格单调，例如 OBP 重复 3 的中档 gap 高于远档；所以这里存在的是粗粒度关联，不是一条可沿着爬升的平滑行为梯度。

OP 的群体关系很强，但 n=12 且测量稳定性门槛未完全通过，只能作为有希望的探索性证据。CVRP 重复 1 的 Spearman 为负、kNN gap 还略高于随机；结合其 seed/panel 不稳定性，不能通过另外两个重复的正结果将它平均成“有效”。

8 月 27 日的旧结果与本轮方向大体一致，但数据版本和抽样不同：旧实验分析 V9.16，本轮分析 V10.6 且对 OBP/ACO 使用校准协议。因此不能把两轮具体系数当成同一样本的前后提升。本轮把原先“15/15 Spearman 为正”修正为 V10.6 抽样上的 14/15，唯一反向项是 CVRP 重复 1。

## 5. 对 TraceAAD 的调整

后续保留的职责是宏观观测：archive 覆盖了多少行为区域、高质量候选形成一个峰还是多个岛、代码树分叉是否只是行为重访、Pivot 是否扩大群体跨度、Fuse 输入是否来自不同区域，以及搜索窗口整体是在收缩还是扩散。

几何可以离线描述随机碰撞分布，例如区域级预算流向或 Fuse 候选对覆盖的距离档。它不因此成为在线控制的默认输入。[在线可行性复审](../../../analysis/探索性分析/2026-09-07-BehaveSim在线可行性复审/结论.md)确认，历史评价内采集与增量缓存仍不能消除 OBP 长前缀成对比较和 ACO 多随机流成本。当前明确停止：用 BehaveSim kNN 预测某个节点的 Refine 成功率、把低距离直接判作停滞、把高距离直接判作有价值探索、要求通用 TraceAAD 在线维护完整行为几何，以及在 CVRP 上使用当前行为几何。

下一项可做的工作不再是 E1 类节点预测，而是一个很小的区域级离线诊断：逐窗口计算 archive 的行为覆盖、质量—区域分布和算子造成的群体扩散/收缩，用于解释已知搜索阶段。若另行研究轻量在线传感器，必须先给出成本—稳定性—保真曲线，再决定是否值得做等总资源的在线分布控制。
