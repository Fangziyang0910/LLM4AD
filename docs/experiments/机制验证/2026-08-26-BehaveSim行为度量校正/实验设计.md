# BehaveSim 行为度量校正

本实验校正 2026-08-26 生成的行为簇分析。实现前固定测量对象、抽样、稳定性检查和结论边界，结果只补实际完成的数字。

## 问题

1. 固定 evaluator 一致的探针后，候选程序的运行行为是否存在可重复的近邻与分散结构。
2. TraceAAD-V9.16 的 Explore 是否比 Refine 产生更大的父子行为距离。
3. TraceAAD 各版本及外部方法的已记录候选集合，在同任务、等样本量下呈现怎样的行为距离分布。

行为距离只测程序在给定探针上的求解过程。它不直接等于算法思想，不以簇占比判断停滞，也不据此归因完整方法的性能差异。

## PSTraj

- TSP、VRPTW：按正式 evaluator 的输入、候选排序、约束检查和状态更新执行，逐步记录当前部分路线。
- Online Bin Packing：预创建全部空箱，按正式 evaluator 向 `priority` 提供所有可行箱，逐步记录已处理物品的箱号序列。
- OP-ACO、CVRP-ACO：使用正式 evaluator 的 prior 预处理、蚂蚁数、迭代数、随机种子、概率采样和信息素更新；每轮记录截至该轮的 incumbent 路线。
- 构造式轨迹均匀保留 12 个中间解，ACO 轨迹均匀保留 5 个中间解。采样包含第一步和最终状态。
- 单步解之间使用编辑距离除以两份当前部分解的较长长度，与论文 AAD 开源实现一致；轨迹之间使用论文定义的 DTW，并除以两条轨迹的较短长度。四个探针上的距离取均值。

候选程序每次执行前重置 Python 与 NumPy 随机状态；ACO 使用与正式 evaluator 相同的独立 `Generator`。所有候选共享相同实例和随机数口径。

## Probe 与稳定性

面板 A、B 各含每任务 4 个固定探针，正式距离取两个面板距离矩阵的均值。路由任务规模为 50；OP/CVRP 的面板 A 使用训练实例，面板 B 使用 validation 实例，不读取正式 test split；TSP/VRPTW 使用两组不属于正式 held-out 工件的固定生成种子；OBP 每面板使用两条 256-item 序列并分别配对 capacity 100/500。

面板 B 使用独立实例种子。正式重跑前，在每任务一个 V9.16 重复的固定候选子集上检查：

- 同一候选重复画像完全一致；
- 两面板距离矩阵的 Spearman 相关；
- 阈值曲线方向是否稳定；
- profiler 得分与正式 evaluator 在相同实例上的结果是否一致。

若执行一致性或确定性失败，停止全量重跑。面板相关性只报告，不把单个阈值包装成任务固有簇边界。

## 抽样与独立重复

独立重复单位是一次完整搜索 run；候选及 probe 是 run 内嵌套观测，不作为额外重复。

- TSP、OBP、VRPTW：每 run 从全部已记录有效候选中按评价顺序分层确定性抽取 128 个。
- OP、CVRP：每 run 抽取 32 个。预跑确认每个候选均执行 4 实例的完整 ACO；两个面板合计 8 实例，因此在正式重跑前将样本数从 64 调整为 32。
- search best 作为审计候选额外画像，不进入多样性分布。
- V9.16 的构造式任务每 run 另抽取最多 32 条 Explore 和 32 条 Refine 父子边；ACO 任务各抽取最多 16 条，用于配对的算子行为距离。
- 版本与方法比较只在同任务内进行；V9.16、历史版本和完整搜索基线统一下采样到共同成功样本数。

CALM 历史工件只保存最终 archive，没有保存全部 1000 次评价的程序。CALM archive 单独画像并报告覆盖率，不进入“完整搜索候选分布”的方法比较。

## 指标

每个 run 报告：

- 成功画像数、失败类型和覆盖率；
- 平均两两距离；
- 中位最近邻距离；
- 最近邻距离为 0 的候选占比；
- `0.05` 至 `0.95` 阈值下 average-linkage 簇数占样本量的曲线及曲线面积。预跑显示真实 ACO 的距离主要高于 `0.50`，因此在正式重跑前扩展阈值范围；不改变连续距离定义。
- 按抽样顺序计算每个候选到此前候选的最近行为距离，并分别记录 sampled quality breakthrough、精确行为重访和无突破重访。行为重访与质量停滞分别报告，不设单一停滞阈值。

TraceAAD-V9.16 另按 run 报告 Explore 与 Refine 的父子距离分布。三重复先形成各自统计，再报告均值、范围和逐重复方向。

搜索 best 与 held-out 只读取正式结果工件，和行为指标分开呈现。版本差异、方法差异以及行为距离与质量的相关均为观察性结果。

## 运行与工件

原始 profiles、距离矩阵和逐 run summary 写入 `experiments/_logs/behavesim_v3/`。Git 只跟踪分析入口、协议和凝练结果。

批处理在画像前检查每路搜索的完成状态与正式预算。执行顺序：单元测试 -> 单候选 evaluator 一致性 -> 面板与重复稳定性 -> V9.16 -> TraceAAD 版本 -> 外部方法 -> 汇总与文档。
