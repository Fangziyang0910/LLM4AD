# BehaveSim 全 Archive 群体验证实验设计

## 1. 为什么还需要这一步

上一轮完成了测量校准，但它的 landscape 样本先要求节点已有 E1 合法画像，再按 fitness 四层取样。E1 画像主要覆盖历史 Refine parent，因此严格结论只适用于“覆盖多个 fitness 层级的 Refine-parent 子群体”，不能直接代表完整 TraceAAD archive。

本轮只修正 population sampling，不再改变距离、状态表示或统计量。目标是验证同一群体关系能否在**从全部有效 archive nodes 按搜索时间直接抽取的代表性样本**上复现。

## 2. 冻结样本

使用与上一轮相同的 V10.6 15 个冻结 run。每个 run 将所有有效 archive nodes 按 `evaluation_id` 排序，再以等间隔位置抽样：

| 任务 | 每 run 样本 | 角色 |
| --- | ---: | --- |
| TSP | 64 | 主结论 |
| OBP | 64 | 主结论 |
| VRPTW | 64 | 主结论 |
| OP | 32 | 探索性观察 |
| CVRP | 12 | 诊断性单列 |

抽样不读取 fitness，不要求节点曾作为 Refine parent，也不要求存在旧画像。首尾节点进入样本，保证覆盖整个搜索时间段。样本量差异只反映画像计算成本；不做跨任务合并效应。

## 3. 画像协议

- TSP、VRPTW：沿用已审计的双面板 probe。
- OBP：使用 1000/5000-item、capacity 100/500 的 scale-matched 双面板 probe，完整执行后均匀保存 12 个 prefix。
- OP：每 panel 4 个实例，每实例 4 个 common random streams，共 16 条 PSTraj。
- CVRP：使用同一四流口径，但只报告诊断结果，不参与“archive 几何有效”的结论。

完全相同协议的已有画像可以按代码哈希复用，其余样本重新画像。复用不改变节点选择条件，因为选择先从全 archive 独立完成。若正式 archive 中有效的程序不能在独立 behavior probe 上形成合法画像，则保留预选样本并把该节点记为画像缺失，不按结果另选替补；每个 run 的统计只使用预选样本中画像成功的节点，并报告实际覆盖率。

## 4. 固定统计量与门槛

每个 run 仍只计算：

1. 全体 pair 的行为距离与标准化 fitness gap 的 Spearman；
2. 行为 kNN 平均 fitness gap 与均匀随机 pair 期望之差；
3. 近、中、远三个等数量行为距离档的平均 fitness gap。

任务级支持要求三个重复同时满足：Spearman 为正、kNN gap 小于随机 pair、远档 gap 大于近档。TSP、OBP、VRPTW 三任务全部通过，才支持“BehaveSim 是当前 TraceAAD archive 的有效群体几何坐标”。OP 无论结果如何都保留“待再确认”的测量标签；CVRP 不参与该判断。

## 5. 解释边界

本实验验证的是时间代表性抽样上的群体结构，不是逐节点覆盖的完整 archive 精确地图。正结果允许下一步研究窗口覆盖、收缩/扩散和高质量区域数量，但仍不支持个体 Refine 潜力预测，也不直接证明任何几何控制策略能改善终局表现。
