# BehaveSim 全 Archive 群体验证结果

## 核心判断

在当前 V10.6 冻结数据和校准画像协议下，可以把 BehaveSim 视为 **TSP、OBP、VRPTW archive 的有效群体几何坐标**。这次证据来自全部有效 archive nodes 的时间均匀样本，不再依赖节点曾被选为 Refine parent，也没有按 fitness 分层。

OP 的 archive 群体关系同样在三个重复中稳定出现，而且每 run 样本已从上一轮的 12 个扩大到 32 个；但其 probe panel 稳定性曾以 0.776 略低于预注册门槛，因此仍标记为“基本可用、待测量复核”。CVRP 再次被重复 1 否证，继续停用当前 BehaveSim 几何。

这里的“有效坐标”只表示它能描述群体中行为位置与 fitness 差的统计结构。它不是个体收益坐标，不能预测某个节点下一次 Refine 是否成功。

## 1. 执行与覆盖

15 个 run 共预选 708 个节点—run 样本：TSP/OBP/VRPTW 每 run 64 个，OP 每 run 32 个，CVRP 每 run 12 个。选择只使用 `evaluation_id`，以等间隔位置覆盖搜索首尾和中间阶段；不读取 fitness，不检查历史画像，也不替换结果不理想的节点。

126 份完全同协议画像按代码哈希复用，新增生成 582 份。其中 581 份成功。唯一失败是 OBP rep2 的 node 332：它在正式训练 seed 上有效，但在两个独立 behavior panel 都返回错误长度的 priority。该节点保留为画像缺失，rep2 使用固定样本中的其余 63 个节点。最终画像覆盖 707/708，即 99.86%。

完整数值见[汇总 JSON](BehaveSim全Archive群体验证汇总.json)，冻结口径见[实验设计](实验设计.md)。

## 2. 三项群体统计

`随机−kNN` 为正表示行为近邻的 fitness gap 更小；`远−近` 为正表示远距离档的平均 gap 更大。

| 任务 | 每 run 有效 n | distance–gap Spearman | 随机−kNN | 远−近 | 三重复门槛 |
| --- | ---: | --- | --- | --- | --- |
| TSP | 64 / 64 / 64 | 0.565 / 0.471 / 0.373 | 0.365 / 0.396 / 0.541 | 1.090 / 1.001 / 0.915 | 通过 |
| OBP | 64 / 63 / 64 | 0.585 / 0.226 / 0.834 | 0.276 / 0.597 / 0.707 | 1.231 / 0.023 / 2.273 | 通过 |
| VRPTW | 64 / 64 / 64 | 0.599 / 0.806 / 0.675 | 0.686 / 0.468 / 0.571 | 1.114 / 1.590 / 1.464 | 通过 |
| OP | 32 / 32 / 32 | 0.762 / 0.847 / 0.520 | 0.443 / 0.474 / 0.279 | 1.630 / 1.764 / 1.240 | 数值通过，测量待确认 |
| CVRP | 12 / 12 / 12 | -0.208 / 0.721 / 0.563 | 0.106 / 0.370 / 0.511 | -0.358 / 1.553 / 1.485 | 不通过 |

TSP 和 VRPTW 的结果最整齐：三个重复中全体 pair 相关、局部 kNN 和距离档差异都留有明显余量。它们支持 BehaveSim 同时描述粗粒度 fitness 地形和局部行为邻域。

OBP 三个重复也通过冻结门槛，但 rep2 的 `远−近` 只有 0.023；其近/中/远平均 gap 实际为 0.040 / 1.964 / 0.063，并非单调梯度。结合 rep1/rep3 的强结果以及 rep2 的正 Spearman、显著 kNN 优势，更合理的解释是 OBP 存在离散、多簇的行为结构，距离近邻有意义，但离任意锚点越远并不保证 fitness gap 平滑增大。

OP 在更大的时间样本上三项统计全部同向，说明上一轮的正结果不是 fitness 分层或 12 节点小样本独有。当前限制来自测量校准中的跨 panel 门槛，而非本轮群体统计。下一步可以把它纳入宏观观察的敏感性版本，但在补充 probe 稳定性前不作为硬控制输入。

CVRP 重复 1 的 Spearman 为 -0.208，且远档 gap 比近档低 0.358。它与上一轮同样在 rep1 失败，和四随机流后仍不稳定的 panel/seed-half 结果一致。当前问题具有重复性，不宜再解释成偶然的小样本波动。

## 3. 相比上一轮改变了什么

上一轮的严格结论应收窄为：在覆盖多个 fitness 层级的历史 Refine-parent 子群体中，TSP、OBP、VRPTW 存在 behavior–fitness 群体结构。本轮去掉旧画像资格和 fitness 分层后，同一命题在完整搜索时间的代表性样本上再次成立，因此不再依赖“哪些节点曾被继续开发”这一选择机制。

两轮不是同一节点样本，具体相关系数不用于做前后提升比较。它们共同支持：

$$
\boxed{\text{fitness 描述质量，BehaveSim 描述算法群体的行为位置；二者相关但不等价。}}
$$

这仍然不蕴含：

$$
d_B(A,B)\text{ 小且 }A\text{ 的 Refine 成功}
\Rightarrow B\text{ 的下一次 Refine 更可能成功。}
$$

## 4. 使用方式与下一步研究入口

现在可以对代表性样本做离线群体态势分析。下一项分析可按搜索时间窗口计算四类宏观量：

1. archive 行为覆盖及其增量；
2. 群体是在收缩、维持还是扩散；
3. 高质量候选占据多少行为区域，各区域是否持续获得开发；
4. Refine、Pivot、Fuse 分别造成多大的区域内移动、跨区移动和新区域发现。

这些量用于解释已知搜索阶段和任务差异，不要求为完整在线 archive 持续维护精确距离图。历史[在线可行性复审](../../../analysis/探索性分析/2026-09-07-BehaveSim在线可行性复审/结论.md)表明，评价内采集和增量缓存仍不能消除 OBP 长前缀成对比较及 ACO 多随机流成本。因此完整 BehaveSim 当前停留在条件性离线分析，不作为通用 TraceAAD 的在线输入。

若以后研究低频、代表数受限或压缩后的在线行为传感器，先验证它与完整离线几何的一致性，并预注册额外墙钟、峰值内存和延迟上限；通过后才做等总资源的区域级控制实验。当前仍不训练个体潜力模型，不把距离阈值直接写成 Pivot/Refine 规则，也不在 CVRP 上启用行为几何。
