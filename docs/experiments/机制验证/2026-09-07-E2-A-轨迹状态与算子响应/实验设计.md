# E2-A：行为轨迹状态与 Refine/Pivot 响应

日期：2026-09-07。状态：协议及propensity overlap修订均在读取suffix outcome前冻结，E2-A已执行完成；结果见[结果](结果.md)。结果不得用于反改本页的特征、阈值或判断规则。

## 1. E1 之后的研究认识

E1-A 与 E1-A.1 构成一个完整的负机制研究：在当前五任务、V10.6 proposal kernel 和固定 BehaveSim 下，行为近邻没有提供可用的 Refine response sharing。E1-A.1 控制 fitness 后仍只得到0.05%的 Brier 改善，真实行为对应只优于64.9%的置乱，first-parent-use 也未改善。因此停止：

$$
\text{BehaveSim neighborhood}
\rightarrow\text{Refine evolvability sharing}
\rightarrow\text{Refine parent allocation}.
$$

这不意味着行为观测无用。前两轮暴露了两个原先连接过快的概念：

$$
\boxed{\text{behavioral similarity}\neq\text{variation-response similarity}}
$$

以及：

$$
\boxed{P(child>parent)\neq\text{budget value}}.
$$

BehaveSim 描述的是算法执行 phenotype；LLM Refine 的可修改空间还取决于代码结构、实现摘要、形成路径与上下文。相近 fitness 的 parent 容易被自身超过，也不等于它能推动全局前缘。Q_kernel 的 Brier 优势因此先命名为 **quality-conditioned parent-improvement calibration**，不能称为已识别的 evolvability。

新的主线是：

$$
\boxed{
Trajectory\rightarrow Transition\ Observables\rightarrow Search\ State
\rightarrow Operator/Continuation\ Decision
}
$$

BehaveSim 在其中充当 trajectory sensor：测量一次形成步实际移动了多远、当前节点是否落回已访问区域；fitness 则测量这些移动是否兑现。E2-A 不再问“两个静态节点能否共享潜力”，而问“形成轨迹处于何种状态时，应继续 Refine 或切换 Pivot”。

## 2. 研究问题与数据隔离

主问题：

> 当当前节点表现为低行为移动、行为重访和近期无 fitness 兑现时，Pivot 相对 Refine 的一步预算价值是否提高？

$$

## 3. Action 前的轨迹状态

对 suffix 中一次已选定 parent $n_t$ 的 Refine/Pivot 抽样，在 action 前构造：

### 3.1 实际形成移动

若 $n_t$ 非根节点，令 $p(n_t)$ 为其真实形成父节点：

$$
D_{move}(n_t)=d_B(p(n_t),n_t).
$$

根节点没有形成移动，不进入主行为交互样本，单列覆盖率。

### 3.2 行为重访

为避免 $D_{revisit}\le D_{move}$ 的机械重合，重访参考集排除当前节点及其直接形成父节点：

$$
D_{revisit}(n_t,t)=
\min_{x\in\mathcal A_{t^-}\setminus\{n_t,p(n_t)\}}d_B(n_t,x).
$$

$\mathcal A_{t^-}$ 是 action 前已经出生的完整有效 archive，而非只选过 Refine 的 parent 子集。它回答当前行为是否接近其他历史区域。参考集为空则记缺失，不填零。

### 3.3 最近 fitness 兑现

沿真实 parent_id 向上取最近最多三条形成边，定义：

$$
G_{recent}=\sum_{e}\frac{f(child_e)-f(parent_e)}{\max(|f(parent_e)|,10^{-8})}.
$$

同时保存每条 signed delta 和最近算子。主状态只使用 action 前已形成的路径，不读取当前 action 或后续子树。

### 3.4 固定的停滞状态

在 E1 prefix 的 TSP/OBP/VRPTW 可画像非根 action states 中，分别按 task 固定 $D_{move}$ 与 $D_{revisit}$ 的中位数。suffix 中每项满足记1分：

1. $D_{move}$ 不高于 prefix task median；
2. $D_{revisit}$ 不高于 prefix task median；
3. $G_{recent}\le0$。

定义 `stagnant = score >= 2`，严格三项同时满足作为敏感性子集。中位数和2/3规则在读取 suffix outcome 前固定，不根据结果寻找切点。

## 4. Refine/Pivot 的已知处理概率

V10.6 先按联合边际选 parent，再按保存的：

$$
P(o\mid n_t)
$$

随机选择 Refine/Pivot/Fuse。E2-A 只保留 requested=executed 且 action 属于 Refine/Pivot 的事件；requested Fuse 及 Fuse 无 donor 后回退 Refine 均排除。对二元子试验使用：

$$
e_P(s)=\frac{P(Pivot\mid n_t)}{P(Pivot\mid n_t)+P(Refine\mid n_t)},
\qquad e_R=1-e_P.
$$

主估计器为分层 Hájek inverse propensity weighting：

$$
\hat\tau_g=
\frac{\sum_{A=P}Y/e_P}{\sum_{A=P}1/e_P}
-
\frac{\sum_{A=R}Y/e_R}{\sum_{A=R}1/e_R},
$$

其中 $g\in\{stagnant,nonstagnant\}$。核心交互是：

$$
\Delta\tau=\hat\tau_{stagnant}-\hat\tau_{nonstagnant}.
$$

首次执行在读取 outcome 前的 propensity 断言处发现：部分极低基础质量权重的 parent 具有二元 $e_P=1$，因为它们实际只可能通过 Pivot 的均匀分量被选中，同一状态不存在 Refine 反事实。依据这一只涉及分配机制的诊断，主 estimand 固定为 overlap population：

$$
0.05\le e_P\le0.95.
$$

区间外样本在构造 outcome 统计前排除并单列覆盖；不外推到这些“仅 Pivot 可达”的低权重状态，也不根据结果调整界限。该修订是识别条件修复，不是结果后调参。

同时报告每个 action/stratum 的原始数量、IPW effective sample size、propensity 范围和逐 task 效应。区间以 run 为单位、在 task 内分层重采样 10000 次；15条正式 run 不是15个行为主实验重复，主实验实际只有3任务×3 run。

## 5. Outcome：从响应预测转向预算价值

所有 outcome 都按一次已请求 action 无条件计算，invalid/evaluation failure 不补样本：

- `valid`：是否得到有限 fitness；
- `parent_positive_gain`：$\max(0,f(child)-f(parent))/|f(parent)|$，失败与退步为0；
- `parent_signed_gain_valid`：给定有效候选的 signed relative parent delta；
- `frontier`：是否超过 action 前 `best_before`；
- `frontier_gain`：

$$
Q_1=\frac{\max(0,f(child)-f^\star_t)}{\max(|f^\star_t|,10^{-8})}.
$$

`frontier_gain` 是主决策指标；其他项用于解释它来自有效率、局部改进还是稀有突破。若 suffix 的 frontier event 太少，只能判未决，不能事后把 parent improvement 换成主目标。

## 6. E2-A 的固定判断规则

只有同时满足以下条件，才记为“观察到停滞状态下 Pivot 相对 Refine 的一步价值增量”：

1. `frontier_gain` 的 $\Delta\tau>0$，task-stratified run bootstrap 95%区间下界大于0；
2. 至少2/3个主任务的交互方向为正；
3. stagnant 层 Refine/Pivot 的 IPW ESS 均不低于20；
4. `frontier` 或 `parent_positive_gain` 至少一项方向一致，且不是由单一 run 的唯一事件决定。

未满足时不修改在线算子概率。若三任务可分析样本合计少于10个frontier event，或停滞层任一action的IPW ESS低于20，结论写“未决，现有suffix不足以作负判断”，而不是negative；样本达到这两个最低信息条件后，若效应接近零或跨任务反向，才关闭当前停滞定义。信息不足本身也不自动授权E2-B，仍需依据效应方向和锚点预算另作决定。

## 7. Q_kernel 独立 suffix audit

在五任务 suffix 的 requested=executed Refine 上，完全冻结 E1 的 $k=10$、Gaussian bandwidth、shrink=10、cold prior 和严格时间更新，比较 M0、M1、Q_kernel：

1. parent-improvement Brier 能否复制；
2. top-20% 的 `frontier_gain` 与 `parent_positive_gain` 是否同时优于 M1；
3. pooled AP、lift和各任务方向。

只有 Q_kernel 的 Brier 低于 M1、至少3/5任务同向，且两项 top-20% gain 均不低于 M1，才保留为 allocation candidate。若仍是“Brier好、budget ranking不好”，将其归类为 calibration phenomenon 并结束该支线。

## 8. 后续边界

E2-A 有可信 interaction 后，E2-B 才值得新增生成：在固定的 behavior-stagnant anchors 上随机 Refine/Pivot，然后对每个有效 child 统一再 Refine 一步，比较：

$$
Q_2=E[\max(f^\star,f(c_1),f(c_2))-f^\star].
$$

第二步必须恢复 Implementation Summary，真实测量 Pivot 的 continuation option value。E2-A 未通过前，不启动 E2-B、不修改 V10.6 调度器，也不把即时 Pivot 退步事后解释成 stepping stone。
