# TSP Construct 实验结果

## 实验设置与比较口径

本页比较 TSP Construct 方法在固定搜索协议下的测试 tour length。Qwen3.6-27B 使用 TSP50 × 16（`seed=2024`）作为搜索集；测试集为 TSP50/100/200 各 16 个实例（`seed=2025`），首档是同分布独立测试集，后两档是不同规模测试集。比较单位是某方法在一个测试设置上的一次完整搜索运行。每种方法独立运行 3 次，搜索预算均为 1000。指标为平均 tour length，越低越好。

表中每个数值为 3 次运行的测试均值 ± 样本标准差；± 仅描述运行间变异，不是置信区间，也不支持统计显著性判断。加粗表示该列的最佳均值。

### 结果解释与限制

TraceAAD V6 在 TSP50 的报告均值最低；TraceAAD V9.1 (Trajectory) 在 TSP100 与 TSP200 的报告均值最低（TSP100 与 V6 仅差 5.4e-5，视为持平；TSP200 首次由 TraceAAD 取得列最佳）。

大而一致的观察：V8.3 三规模均值一致弱于 V8 / V8.2；V9.1 Trajectory 三规模均值一致优于 MCTS-Aligned 与 V9，也一致优于其后的 V9.2–V9.6（差距约 3%–7%）。V9.4 的运行间标准差（0.488/0.744/1.084）明显大于其他版本，由 rep3 在搜索末尾的强 best（5.675/7.835/11.137）驱动；V9.6 的运行间标准差明显更小（0.066/0.292/0.751）。其余版本间的均值差在运行间波动量级内，读作无信号，不逐对叙述。

最佳均值不代表统计显著性。结论限于给定实例、随机种子、搜索预算和 3 次独立运行，不能据此推断对其他数据分布或预算的普遍优势。
