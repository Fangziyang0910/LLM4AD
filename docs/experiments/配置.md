# 实验配置

## 科学评价协议

### 集合名称

- **搜索集**：参与候选生成、评价、选择或停止判断，因而会影响搜索过程的实例。
- **同分布独立测试集**：与搜索集来自相同任务分布、规模相同，但独立采样且不参与搜索的实例。
- **不同规模测试集**：不参与搜索、问题规模与搜索集不同的实例，用于评价跨规模表现。

以下在首次说明具体划分时使用完整名称，后文按语境简写为“搜索集”“测试集”“同规模测试”或“跨规模测试”。

### 结果层级

正式版本比较以**同规模独立测试**为主：测试实例与搜索集来自相同任务规模，但不参与候选生成、选择或版本决策。它回答方法在同一任务上的实际质量，主排名只使用这一层。

搜索集上的最终 best 与 best-at-budget 曲线回答有限 evaluator 预算内的搜索能力，单独记录，不与同规模测试混成一个分数。不同规模测试只用于补充跨规模迁移，默认不进入主排名。四个正式任务均按这三层分别报告。

交付单工件的任务（科学发现类，如定形 kernel、数学构造）直接在任务本身上评价，不设实例测试层。界线：交付物作用于实例分布还是单一任务。

### 正式比较预算

正式方法对比与权威结果统一使用 **1000 次启发式/程序评估（eval）** 作为搜索预算。

依据：[AAD 方法实验设置汇总](../references/AAD方法实验设置汇总.md)。在可横向对比的 COP AHD 文献中，1000 eval 是最常见的对照口径（如 MCTS-AHD、CALM、RedAHD、MoH，以及 EoH/MEoH 的 TSP 侧）；100 eval 多为 ReEvo 式样本效率设定，200–500 为中等预算，2000 及以上偏大预算或 FunSearch 系大规模采样。本仓库选择与主流对照链对齐的 1000 eval。

约束：

- 预算单位是**成功计入搜索的候选评估次数**，不是 LLM 调用次数或 token。
- 最终曲线、结果页与测试只使用预算边界以内的候选；超出 1000 的历史运行须截断到边界内再聚合。
- 方法特有超参可保留论文默认，但公平比较时 `max_sample_nums` / 等价搜索预算必须为 1000。

### 正式对照方法

TraceAAD 主表外部对照固定为以下 **5** 个方法（代表性 + 机制近邻 + 后续微调轴）：

| 方法 | 角色 |
|------|------|
| EoH | 经典种群演化范式 |
| ReEvo | 反思 / 反馈与样本效率叙事 |
| MCTS-AHD | 当代强搜索与协议锚（1000 eval 对照链） |
| PathWise | 路径式搜索组织；与轨迹改进主张的机制近邻 |
| CALM (w/o GRPO) | 固定权重的搜索框架对照；完整 GRPO 版本另列 |

#### CALM 对照层级

当前主表使用 **CALM (w/o GRPO)**：固定模型权重，只保留 verbal 算子、池管理与 collapse 等搜索机制，并与其他方法共享 Qwen3.6-27B、任务协议和 1000 eval 预算。该对照检验搜索框架，不代表包含 GRPO 共演化的完整 CALM。

CALM (w/ GRPO) 同时改变搜索机制与模型权重，若后续评价，应作为单独的模型适应对照报告；不能用它与未微调的 TraceAAD 直接归因搜索机制优劣。GRPO 的训练算力和更新步数应与启发式评价预算分开报告。

主表保留 EoH、ReEvo、MCTS-AHD、PathWise 与 CALM (w/o GRPO) 五个外部对照，TraceAAD 侧保留 V4、V5、V8、V9、V9.7（父代来时路完整协议，批次 `20260814_150927`）与 V9.9；其余内部迭代与换生成模型批次的结果在[归档实验结果](归档实验结果.md)与[生成模型对比](生成模型对比.md)。其他方法用于 related work 或补充实验，不混入权威结果。

### 共用搜索配置

- LLM：Qwen3.6-27B；`temperature=1.0`，`max_tokens=16384`，单次请求 timeout 为 600 秒，关闭 thinking。
- 重复：每种方法 3 次独立运行。
- 搜索预算：上节规定的 **1000 eval**，适用于正式对照五方法与 TraceAAD。
- MCTS-AHD：4 个 evaluator。
- PathWise：4 个 evaluator。
- EoH：20 代、E1/E2 使用 5 个父代。
  OBP 使用种群 20，其余 task 使用种群 10。启用原始发布代码实际使用的
  `e1/e2/m1/m2`，`m3` 不启用；初始化沿用原始代码的 `2 × population` 候选池。
- ReEvo：`max_sample_nums=1000`；
  其余保持论文/`cfg/config.yaml`：`pop_size=10`、`init_pop_size=30`、
  `mutation_rate=0.5`、`temperature=1`，初始化温度 `+0.3`。
- TraceAAD V4 / V5：`n_init=30`，目标 active 轨迹 30，管理阈值 60；正式 V5 关闭在线全局经验。
- TraceAAD V6：`n_init=30`，目标 active 轨迹 30，管理频率 60。
- TraceAAD V7：Code 输出上限 16384 tokens，`n_init=30`，目标 active 30，管理阈值 60，质量精英 3，轨迹长度 8，使用 `0.8Q+0.2P` 与剩余预算衰减 UCB。
- TraceAAD V8：30 个根、两阶段生成、平方根渐进拓宽，探索系数 0.5。
- TraceAAD V8.2：`n_init=10`，每次扩展最多生成 2 个子代，Code 输出上限 8192 tokens，上下文上限 24576 tokens。
- TraceAAD V8.3：`n_init=10`，`rho=0.25`、`kappa=0.1`、`beta=1`、探索系数 0.1，Code 输出上限 8192 tokens，上下文上限 24576 tokens。

### 正式主实验任务

正式结果覆盖以下 **5** 个 task：

| Task | 问题族 | 嵌入 | 角色 |
|------|--------|------|------|
| `online_bin_packing` | 装箱 | 构造评分 | 同规模与跨规模、跨容量测试 |
| `tsp_construct` | 路由 | 构造 | 构造式路由与跨规模测试 |
| `cvrp_aco` | 路由 | ACO | 容量约束下的元启发式嵌入 |
| `op_aco` | 路由 | ACO | 路程预算与 prize 目标 |
| `vrptw_construct` | 路由 | 构造 | 时间窗约束下的构造式路由 |

依据见 [AAD 方法实验设置汇总](../references/AAD方法实验设置汇总.md)。任务覆盖装箱与路由、构造式启发式与 ACO 嵌入，VRPTW 补充时间窗约束下的构造决策。

所有方法在同一 LLM、1000 eval、数据划分和评价器下重新运行，不直接混用论文原表数字。

## 任务评价协议

### `tsp_construct`

#### 搜索集

- 数据：TSP50，16 个实例，`seed=2024`。
- 评估 timeout：20 秒。

#### 测试集

- 同规模：TSP50，16 个实例，`seed=2025`。
- 不同规模：TSP100、TSP200，各 16 个实例，`seed=2025`。
- 评估 timeout：20 秒。

#### 任务参数

- 指标：平均 tour length，越低越好；搜索 score 为其相反数。
- 与文献：MCTS-AHD / CALM 常用 64×TSP50 搜索、每档约 1000 个实例测试。本仓库将搜索与测试实例数分别降至 16，所有方法在同一协议下重跑比较；不直接引用各论文原表数字。规模轴 50/100/200 与对照链一致。

### `cvrp_aco`

#### 搜索集

- 数据：CVRP50，10 个实例，车辆容量 50，`seed=1234`。
- ACO：30 ants，100 iterations，`aco_seed=1234`。
- 评估 timeout：120 秒。

#### 测试集

- 同规模：`test_50`，64 个实例，`seed=1234`。
- 不同规模：`test_100`、`test_200`，各 64 个实例，`seed=1234`。
- ACO：30 ants，100 iterations，`aco_seed=1234`。
- 评估 timeout：120 秒。

#### 任务参数

- 指标：平均最优路径长度，越低越好；搜索 score 为其相反数。
- 与文献：对齐 MCTS-AHD / CALM（10×CVRP50 搜索；CALM 测 N=50/100/200）。本仓库正式测试含 CVRP200×64。

### `op_aco`

#### 搜索集

- 数据：OP50，5 个实例，`seed=1234`。
- ACO：20 ants，50 iterations，`aco_seed=1234`。
- 路程预算：OP50 的 `maxlen=3`。
- 评估 timeout：60 秒。

#### 测试集

- 独立验证：OP50、OP100、OP200，各 64 个实例，`seed=3456`，不进入正式结果。
- 同规模测试：OP50，64 个实例，`seed=4567`。
- 不同规模测试：OP100、OP200，各 64 个实例，`seed=4567`。
- 路程预算：OP50/100/200 的 `maxlen=3/4/5`。
- ACO：20 ants，50 iterations，`aco_seed=1234`。
- 评估 timeout：60 秒。

#### 任务参数

- Prize：相对 depot 距离离散化后归一化；depot 为实例第 0 点。
- 指标：平均 collected prize，越高越好。

### `online_bin_packing`

#### 协议依据

Online Bin Packing 文献存在两类协议。EoH/HSEvo 只在 $5k,C=100$ 上搜索，再把其他规模与容量作为外推；MCTS-AHD、CALM 和 PathWise 将 $1k/5k\times C=100/500$ 纳入搜索，只把 10k 视为未见规模。当前比较采用后一种多容量协议，以对齐主要搜索基线。测试集使用独立 item 序列，10k 用于跨规模评价。文献出处与差异见 [AAD 方法实验设置汇总](../references/AAD方法实验设置汇总.md)。

#### 搜索集

- 数据：4 个固定实例，`1k/5k × capacity=100/500` 各 1 个，`seed=2024`。
- 同一 item 规模下的 `capacity=100/500` 实例共享 item 序列，只改变 bin capacity。
- 物品尺寸：Weibull(3,45) 采样，裁剪上限 100。
- 评估 timeout：30 秒。

#### 测试集

- 同规模：`n_items=1000/5000`，`capacity=100/500`，每个组合 5 个实例，`seed=2025`。
- 不同规模：`n_items=10000`，`capacity=100/500`，每个组合 5 个实例，`seed=2025`。
- 测试 item 序列与搜索集不同且固定。
- 物品尺寸：Weibull(3,45) 采样，裁剪上限 100。
- 评估 timeout：30 秒。

#### 任务参数

- 指标：平均使用箱数，越低越好。

### `vrptw_construct`

#### 搜索集

- 16 个生成实例 × 50 节点（seed 2024），生成参数在 `generated_data_config.py`，与其它生成实例任务同一机制。
- 演化组件：`select_next_node`，模板骨架保证可行性；启发式中途返回 None 且未完成构造判为无效解。
- 评估 timeout：30 秒。

#### 测试集

- 16 个生成实例 × 50 节点（seed 2025），与搜索集同分布、仅 seed 不同。

#### 任务参数

- 指标：平均总距离，越低越好；搜索 score 为 objective 的相反数（越高越好）。
