# 实验配置

## 科学评价协议

### 正式比较预算

正式方法对比与权威结果统一使用 **1000 次启发式/程序评估（eval）** 作为搜索预算。

依据：[AAD 方法实验设置汇总](../references/AAD方法实验设置汇总.md)。在可横向对比的 COP AHD 文献中，1000 eval 是最常见的对照口径（如 MCTS-AHD、CALM、RedAHD、MoH，以及 EoH/MEoH 的 TSP 侧）；100 eval 多为 ReEvo 式样本效率设定，200–500 为中等预算，2000 及以上偏大预算或 FunSearch 系大规模采样。本仓库选择与主流对照链对齐的 1000 eval。

约束：

- 预算单位是**成功计入搜索的候选评估次数**，不是 LLM 调用次数或 token。
- 最终曲线、结果页与 held-out 测试只使用预算边界以内的候选；超出 1000 的历史运行须截断到边界内再聚合。
- 方法特有超参可保留论文默认，但公平比较时 `max_sample_nums` / 等价搜索预算必须为 1000。

### 正式对照方法

TraceAAD 主表外部对照固定为以下 **5** 个方法（代表性 + 机制近邻 + 后续微调轴）：

| 方法 | 角色 |
|------|------|
| EoH | 经典种群演化范式 |
| ReEvo | 反思 / 反馈与样本效率叙事 |
| MCTS-AHD | 当代强搜索与协议锚（1000 eval 对照链） |
| PathWise | 路径式搜索组织；与轨迹改进主张的机制近邻 |
| CALM | 分两档：当前跑框架（w/o GRPO）；微调阶段再跑完整共演化（w/ GRPO） |

#### CALM 分阶段对照

CALM 论文同时主张两件事，并分开报告两档结果：**(API / local, w/o GRPO)** 验证算子与搜索设计；**(local, w/ GRPO)** 为完整方法。对照必须与当前科学主张同档，不可混档。

**决定（当前阶段）**：尚未进入微调时，正式跑 **CALM 搜索框架单独版（w/o GRPO）**——冻结与主表相同的 LLM，关闭权重更新，保留其 verbal 算子 / 池管理 / collapse 等搜索机制，评估预算 **1000 eval**。结果在文档与表中记为 `CALM (w/o GRPO)`，不得写成完整 CALM。

| 阶段 | TraceAAD 侧 | CALM 侧 | 是否复现 GRPO |
|------|-------------|---------|---------------|
| 当前（仅搜索 / 轨迹机制） | 冻结 LLM 的 TraceAAD | **CALM (w/o GRPO)**：只跑搜索框架，与主表同 LLM、同 1000 eval | 否 |
| 进入 RL/微调后 | TraceAAD-FT（或搜索+FT） | **CALM (w/ GRPO)**：完整共演化，作为 FT 范式主锚 | **是** |

约束：

- 权威结果页与论文主表以上述五方法 + TraceAAD 为默认对照集；当前阶段 CALM 席位由 **w/o GRPO** 占据，进入微调后再补齐 **w/ GRPO**（可两行并存，拆开「算子」与「RL」）。
- 禁止用「未微调的 TraceAAD」直接对打「CALM w/ GRPO」作为搜索机制优劣的主证据；那是搜索与模型适应的混杂比较。
- 当前阶段不照搬 CALM 原文 API 变体的更大 query 预算；框架对照一律压到本仓库 **1000 eval** 协议。
- ShinkaEvolve、FunSearch、HSEvo、EvoTune、MoH、RedAHD 等不进入主表；需要时放附录或 related work。EvoTune 与 CALM 相关但预算与任务轴不同，RL 路线主锚为 CALM，不另加 EvoTune。ShinkaEvolve 四任务公平比较工件已迁入 [`archive/shinka-evolve-formal/`](../../archive/shinka-evolve-formal/)，正式结果与曲线不再统计。
- 手工启发式与 NCO（如 POMO、DeepACO）可作为领域水平参照另表列出，不占上述五席。
- 搜索公平比较统一 **1000 eval**、同一任务协议；CALM 的 GRPO 训练算力 / 更新步数另报，不与启发式 eval 混计。

### 正式主实验任务

论文主实验与权威结果固定在以下 **4** 个 task（与 CALM / 后 MCTS 对照链同构；主文不再扩展）：

| Task | 问题族 | 嵌入 | 角色 |
|------|--------|------|------|
| `online_bin_packing` | 装箱 | 构造评分 | 领域最熟锚点；ID/OOD 规模与容量 |
| `tsp_construct` | 路由 | 构造 | 高认知度路由；规模外推（实例数为 MCTS/CALM 的降采样，方法间同协议重跑） |
| `cvrp_aco` | 路由 | ACO | 容量约束 + 元启发嵌入；held-out 含 CVRP50/100/200 |
| `op_aco` | 路由 | ACO | 路程预算与 prize；方法区分度较好 |

依据：[AAD 方法实验设置汇总](../references/AAD方法实验设置汇总.md)。COP AHD 主文常见 3–4 个 task；本四题覆盖装箱与路由、构造与 ACO 两类嵌入，熟悉且具跨设定区分度。MKP、Offline BPP、FSSP、KP、MIS/FJSP 等不进入主实验；若需额外跨域，仅附录考虑 FSSP-GLS 或 KP-构造。

#### 主实验协议取舍（已定）

协议锚为 **MCTS-AHD / CALM** 对照链；本仓库在同一 LLM、同一 1000 eval、同一数据与评价器下**全员重跑**，不直接引用各论文原表数字。

| Task | 决定 | 说明 |
|------|------|------|
| `online_bin_packing` | **保持现状** | 采用多容量搜索协议（\(1k/5k×C=100/500\) 入 \(D\)；10k 为规模 OOD），对齐 MCTS-AHD/CALM，不退回 EoH 单容量协议 |
| `tsp_construct` | **保持降采样** | 训练/测试各 16 实例，规模轴 50/100/200；相对文献 64/1000 为同分布降采样。因方法间同协议重跑，可接受；论文需写明限制 |
| `cvrp_aco` | **held-out 增加 CVRP200×64** | 训练仍 10×CVRP50；测试 `test_50/100/200` 各 64，对齐 CALM 规模外推 |
| `op_aco` | **保持现状** | 5×OP50 训练；OP50/100/200×64 测试；与 CALM/ReEvo 系一致 |

实现注意：`test_200` 已加入 `llm4ad/task/optimization/cvrp_aco/dataset.py` 的 canonical 序列末尾（既有 train/test_50/test_100 指纹不变）。九方法训练 best 的 CVRP200 评测见各目录 `eval_best_20260804_test200/`。

### `online_bin_packing`

#### 协议选择

LLM-AAD 的 Online Bin Packing 存在两种成立但回答不同问题的协议：

- EoH/HSEvo 使用五个固定的 \(5k,C=100\) 实例搜索，再测试
  \(1k/5k/10k \times C=100/500\)。这里 \(C=500\) 是跨 capacity 的
  OOD，用来检验只见过 \(C=100\) 的 heuristic 能否泛化
  （`../../../papers/EoH/4-experiment.tex:5-7,65-86`；
  `../../../papers/HSEvo/appendix.tex:113-120,164-175`）。
- MCTS-AHD、CALM 和 PathWise 把 \(1k/5k \times C=100/500\) 四个尺度
  纳入搜索期，只把 10k 作为未见规模。MCTS-AHD 明确指出旧单容量协议
  经常产生在其它尺度完全失效的 heuristic
  （`../../../papers/MCTS-AHD/icml2025.tex:628-656`；
  `../../../papers/CALM/main.tex:289-321`；
  `../../../papers/PathWise/example_paper.tex:1200-1226,1350-1377`）。

当前仓库采用后一种多容量协议，用于在近期 MCTS-AHD/CALM/PathWise
口径下公平比较搜索方法。搜索集覆盖四个 ID 配置，测试集使用不同 item
序列；只有两个 10k 配置记为 OOD。**主实验决定：OBP 保持该协议不变。**

#### 训练

- 数据：4 个固定实例，`1k/5k × capacity=100/500` 各 1 个，`seed=2024`。
- 同一 item 规模下的 `capacity=100/500` 实例共享 item 序列，只改变 bin capacity。
- 物品尺寸：Weibull(3,45) 采样，裁剪上限 100。
- 评估 timeout：30 秒。

#### 测试

- 数据：`n_items=1000/5000/10000`，`capacity=100/500`，每个组合 5 个实例，`seed=2025`。
- 测试 item 序列与训练集不同且固定；`1k/5k` 为 ID，只有 `10k` 为 OOD。
- 物品尺寸：Weibull(3,45) 采样，裁剪上限 100。
- 评估 timeout：30 秒。

#### 任务参数

- 指标：平均使用箱数，越低越好。
