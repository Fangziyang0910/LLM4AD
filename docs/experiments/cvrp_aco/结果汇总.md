# CVRP-ACO 实验结果

## 实验设置与比较口径

本页比较 CVRP-ACO 方法在固定搜索协议下的测试最优路径长度。Qwen3.6-27B 使用 10 个 CVRP50 实例作为搜索集；测试集为 CVRP50/100/200 各 64 个实例，首档是同分布独立测试集，后两档是不同规模测试集。搜索和测试使用 30 ants、100 iterations、`aco_seed=1234`。每种方法独立运行 3 次，搜索预算均为 1000。指标为平均最优路径长度，越低越好。协议见 [实验配置](../配置.md)。

表中每个数值为 3 次运行的测试均值 ± 样本标准差；± 仅描述运行间变异，不是置信区间，也不支持统计显著性判断。加粗表示该列的最佳均值。

版本边界：表中的 **TraceAAD V9.7** 是仅父代来时路的完整协议（批次 `20260814_150927`）。**TraceAAD V9.8** 为 `q_u_c_m` 正式批次（`20260815_225000`），已纳入跨任务总体和单独排名。**TraceAAD V9.9** 批次 `20260816_154200` 的 CVRP 三次搜索仍在运行，尚未进行正式 held-out，因此当前不在本页主表和跨任务排名中；2026-08-17 已对三次运行的当前 best 做过一次中期快照测试，结果只记入下方诊断注，不进入主表。**TraceAAD V9.7-batch** 使用 V9.6 的 `formation + direct attempts` 历史上下文，只作同页对照，不进入跨任务代表性同场。另有本地 Qwen3.8 批次 `v9_7_qwen38_20260815_010107`，CVRP 搜索尚未完成，未形成 held-out 结果。

### 结果解释与限制

TraceAAD V8 在 CVRP50 的报告均值最低；正统 TraceAAD V9.7 在 CVRP100 与 CVRP200 的报告均值最低。

大而一致的观察：V8.2 与 V8.3 三规模均值均高于 V8，V8.3 差距更大；V9.1 Trajectory 三规模均值均低于 MCTS-Aligned（约 1.7%–4.0%），且运行间标准差更小；CALM (w/o GRPO) 三规模均值均高于 V9。V9.7 相对 V9.7-batch 为 −2.0%/−2.8%/−2.9%。相对 V8 为 +0.8%/−0.8%/−1.3%：同分布档 V8 更好，跨规模两档 V9.7 更好。V9.7 三次运行在 100/200 上并不齐，rep1 最强、rep2 最弱，跨规模标准差大于 V8。V9.7-batch 使用旧历史上下文，不能评价正统 V9.7。

均值排序不代表统计显著性。结论限于给定 CVRP 实例、`aco_seed=1234`、搜索预算、评估设置和 3 次独立运行，不能据此推断对其他实例或运行预算的普遍优势。
