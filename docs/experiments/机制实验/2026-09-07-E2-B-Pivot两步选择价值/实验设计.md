# E2-B'：Pivot 两步选择价值随机干预实验

## 核心判断

E2-A 没有发现实现错误，但它没有识别我们真正关心的 Pivot 价值。它的状态主要描述 parent 的**形成路径**，没有描述该位置出生后已经接受了多少开发；它的主要结果又是一步 frontier gain，而 Pivot 的理论职责恰恰可能是先退化、换到新的机理区域，再由后续 Refine 兑现。因此，一步收益不再作为两步实验的准入门槛。

这轮直接检验：

\[
Q_2(Pivot\rightarrow Refine)
\quad\text{是否高于}\quad
Q_2(Refine\rightarrow Refine).
\]

若在真正有开发经验的锚点上仍系统性不成立，才构成对“Pivot 是 stepping stone”的直接反证。

## 三类轨迹的职责

本实验正式区分：

1. **Formation trajectory**：当前代码如何沿祖先链形成；继续作为 V10.6 生成上下文。
2. **Development experience**：当前节点出生后被扩展多少次、近期是否产生超父/前缘、children 是否反复落在已访问区域；用于 controller state 和选锚。
3. **Behavior transition**：一次实际生成在行为上移动多远；只在干预后解释 Pivot 是否真的发生了大步移动。

“失败 sibling 不进入生成 Prompt”不等于“不进入 controller state”。本轮用历史 children 选择锚点，但不给模型展示这些 sibling。

## 固定样本与状态

只使用 E2-A 已冻结且行为画像完整的 TSP、OBP、VRPTW 三个任务，不读取正式运行后续结果。每个任务选择 3 个 experienced 和 3 个 fresh 锚点，共 18 个。

Experienced 必须同时满足：

- exact parent 此前已有至少 3 次 development attempts；
- 最近至多 5 次 attempt 均未超父、也未刷新当时前缘；
- 至少 2 个有效 child 可计算行为；
- children 的行为移动中位数不高于该 run 全部历史生成边中位数；
- children 落入近邻区域的比例至少 50%。近邻阈值固定为该 run 历史生成边的 revisit 中位数。

这里使用 exact parent，避免在看到干预结果后再调 behavior-local 半径。Formation state 只记录为辅助描述，不参与 experienced 判定。

Fresh 要求 exact parent 从未被扩展。每个 fresh 与一个 experienced 按同任务 fitness 相对差、fitness rank、深度依次最近匹配，且不重复使用。最终样本覆盖每个任务三个正式重复；匹配后的原始 fitness 在配置中完整保存。

## 随机干预

每个 anchor 是一个 block，完整接受两条路径：

\[
A: Refine\rightarrow Refine,
\]

\[
B: Pivot\rightarrow Refine.
\]

block 顺序及 block 内两臂顺序用预先固定的 2026090711 随机种子打乱。同一 anchor 的两臂固定到同一 backend，并对对应阶段使用同一 sampling seed，减少服务端与抽样差异。第一步只改变 V10.6 operator instruction。

第一步按 V10.6 正常流程执行：生成 Idea + 完整代码；语法和接口有效后生成独立 Implementation Summary；随后调用训练 evaluator。只要第一步评价有效，无论它相对 anchor 上升、持平或下降，都无条件获得恰好一次第二步 Refine。第二步 Prompt 包含 anchor 原有 formation history 以及新形成的 anchor→c1 边；不加入历史 sibling failures。

解析失败不调用 evaluator；评价失败计入已执行评价。第一步无效时无法构造真实的下一步算法，停止该路径并在主结果中记为没有获得改善，不补样本。

## 预算

- 18 anchors × 2 paths × 最多 2 步：最多 72 次 evaluator 调用；
- 36 次第一步生成 + 最多 36 次 Implementation Summary + 最多 36 次第二步生成：最多 108 次模型调用；
- 每个 anchor/arm 只做一次随机路径。本轮是小规模机制 pilot，目标是判断方向和值得否扩大，不把低样本量下的未显著差异写成等效。

## 结果量与估计

anchor fitness 为 \(f^*\)。主结果对所有随机路径定义：

\[
Q_2=\max\{f^*, f(c_1), f(c_2)\}-f^*.
\]

无效或缺失 descendant 不提供改善，因此仍可保留在 unconditional 估计中。跨任务汇总使用：

\[
\widetilde Q_2=Q_2/\max(|f^*|,10^{-8}).
\]

主要 estimand 是 experienced anchors 内，配对的：

\[
E[\widetilde Q_2(PR)-\widetilde Q_2(RR)].
\]

以 anchor 为重采样单位做 10,000 次 bootstrap。辅助报告：

- 一步 \(Q_1\)，确认 Pivot 是否付出即时代价；
- 两步均有效时的 \(f(c_2)-f(c_1)\)，回答 Pivot child 是否更可开发；
- 两步 validity；
- fresh anchors 的相同配对差，用于判断 development experience 是否产生效应差异；
- 三任务分别的方向，不跨任务混合原始 fitness。

Pilot 正向门槛预先固定为：experienced 的平均相对 \(Q_2\) 配对差大于 0、anchor bootstrap 95% 区间下界大于 0，且至少 2/3 任务方向为正。未过门槛时保留原定义报告 negative 或 inconclusive，不改阈值寻找信号。

## 行为传感器分析

只对实际生成的第一步 Pivot child 计算：

\[
d_B(parent,c_1).
\]

“large move”阈值在干预前固定为同一来源 run 的历史有效 Pivot 边移动中位数。随后报告移动距离与 continuation gain 的相关性，以及 large/small 两组的平均 continuation gain。这是 post-treatment 解释性分析，不是第三个随机 treatment，也不用于挽救主结果。

## 识别边界

本实验识别固定、已归档 parent 上两种 operator sequence 的短程 option value。它不包含 V10.6 Pivot 将预算路由到低 \(p_0\) parent 的整体作用，不估计完整搜索分配收益，也不直接证明未知实例泛化。若结果支持，下一步才扩大 anchor/repeat 并进入 allocation policy；若 experienced 与 fresh 都系统性不支持 PR，则停止把 Pivot 的 delayed value 当作既定机制。
