# BehaveSim 语义景观协议

本实验执行[BehaveSim 语义景观分析计划](../../../analysis/机制分析/2026-08-27-BehaveSim语义景观分析计划.md)的 P0 与 P1 阶段。分析完全离线：读取已有 BehaveSim v3 工件与 V9.16 checkpoint，不重放候选程序、不调用 LLM、不消耗正式评价预算。

## 问题

1. 同一批候选上，生成谱系图与 BehaveSim 语义邻域图的结构差异是什么。
2. fitness 在 BehaveSim 距离空间中是否具有局部结构（平滑性、到最优的 funnel、局部最优与高质量区域的分布）。
3. 搜索过程怎样访问、重访和跨越语义区域；Explore 与 Refine 的语义步幅差异。

## 数据来源

- 候选与距离：`experiments/_logs/behavesim_v3/` 中 `traceaad_v916` 战役的 15 个 run（5 任务 × 3 重复），每个 run 使用 combined（面板 A/B 均值）距离矩阵与按评价顺序分层抽取的候选序列；构造式任务 128 个（rep2 OBP 126），ACO 任务 32 个。
- 谱系与 fitness：各 run 的 `checkpoints/latest.json`，含全部已记录有效候选的 `parent_id`、`created_by` 与 fitness。combined 序列与 checkpoint 逐候选核对 fitness 完全一致后才构图。
- 记录的 fitness 已是"越大越好"的 evaluator 分数；run 内做 z 标准化用于跨候选比较，原始值同时保留。

## 图构造

同一批节点、同一 fitness，只改变边的定义。

1. **压缩谱系图 G_L**：对每个抽样候选沿 `parent_id` 上溯到最近的被抽样祖先连边，边记录 `lineage_hops`（跨越的真实生成步数）。构图前对全部候选做父链环检查。
2. **BehaveSim kNN 图 G_B**：每个候选连 BehaveSim 距离最近的前 k 个，k = max(2, ceil(5%(n-1)))；2.5% 与 10% 做稳定性对照。无向、无自环；每条边记录距离、两端 fitness、fitness 差、两端产生顺序、是否为谱系边。
3. **语义区域**：该 run 全部两两距离的 25% 分位数为阈值，距离不超过阈值的候选连边后的连通分量。阈值随 run 的距离分布浮动，区域数只在同规模 run 之间比较。谱系汇聚分析与时间覆盖使用语义区域；kNN 图只用于局部邻域、局部最优与高质量区域连通性。

## 指标

- 结构：两张图的连通分量数、平均聚类系数、密度（k 边数固定，密度只作对照）、邻域 Jaccard 与边 Jaccard；谱系-区域对齐（落入多谱系区域的候选占比、单谱系跨越的区域数）。
- 局部平滑性：kNN 邻居对与等量随机非邻居对的平均 |z 差|，报告 ΔL = L_R − L_B。
- 全局平滑性：全部候选对的 BehaveSim 距离与 |z 差| 的 Spearman。
- Funnel：每个候选到抽样最优候选的距离与其 z 差 gap 的 Spearman。run 级搜索最优从 checkpoint 单独记录，通常不在抽样内、无行为距离，只作审计字段。
- 语义局部最优：z 高于全部 kNN 邻居的候选；报告数量、占比、两两距离。
- 高质量区域：抽样 fitness 前 10% 候选在 kNN 图上的连通分量，及区域间最小距离。
- 时间事件：按抽样顺序，当前候选到此前抽样历史的最近行为距离；小/大步幅阈值取该 run 全对距离的 25%/75% 分位数。突破定义为 fitness 严格超过此前抽样最优。四类事件：小步-改善、小步-无改善、大步-改善、大步-无改善。
- 算子：读取 v3 的 operator_edges.json（构造式每 run 每算子至多 32 条，ACO 至多 16 条），报告 Explore 与 Refine 的父子行为距离。

## 口径

- 时间量在抽样序列上计算：到抽样历史的新颖度高于到完整历史的新颖度，重访占比因此是下界；ACO 任务抽样间隔约 30 次评价，构造式约 8 次。
- 突破对照的是此前抽样最优，弱于对真实 best-so-far 的判定。
- 到最优距离分析使用抽样最优；run 搜索最优单列。
- 所有阈值（k 比例、步幅分位、区域分位）是本分析的协议参数，随输出记录，不解释为任务固有边界。
- 全部结论为观察性结果，不改变任何在线机制。

## 工件

- 实现入口：`experiments/analysis/analyze_behavesim_landscape.py`；测试 `tests/analysis/test_behavesim_landscape.py`（8 项，含矩阵-候选对齐、kNN 对称性与 k、压缩谱系祖先与无环、局部最优方向、聚合）。
- 原始输出：`experiments/_logs/behavesim_landscape/<task>/rep<n>/`（run_metrics、nodes、lineage_edges、behavior_edges、local_optima、temporal_events 与四张图），汇总 `aggregate.json`。Git 只跟踪入口、测试与本文档。
- 执行顺序：P0（TSP、OBP 各 rep1）验证对齐与可解释性后，P1 跑全部 15 个 run。
