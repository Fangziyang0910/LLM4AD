# BehaveSim 语义景观结果

## 结果状态

P0（TSP、OBP rep1）与 P1（15 个 run）完成，全部离线。候选-矩阵对齐、fitness 一致性检查在 15/15 通过。时间部分与 v3 校正结果逐任务一致（无突破精确重访：OBP 均值 27.5% vs 校正 27.7%、TSP 18.6%、VRPTW 5.8%、OP/CVRP 1.1%），实现了两套独立入口对同一工件的复算互证。

## RQ1：生成谱系与语义结构的分离

同一批节点上，谱系邻域与 BehaveSim 邻域几乎不相交：边 Jaccard 五任务均值 0.016–0.037，邻域 Jaccard 0.010–0.029。生成上相邻的候选对，在行为距离上基本不是近邻。

| 任务 | 谱系分量数（3 重复） | 语义区域数 | 多谱系区域候选占比 |
| --- | --- | --- | --- |
| TSP | 8 / 34 / 8 | 15 / 8 / 16 | 0.00 / 0.95 / 0.88 |
| OBP | 31 / 105 / 5 | 17 / 12 / 6 | 0.87 / 0.91 / 0.85 |
| VRPTW | 28 / 40 / 13 | 1 / 6 / 4 | 1.00 / 0.96 / 0.98 |
| OP | 27 / 31 / 27 | 9 / 6 / 9 | 0 / 0 / 0 |
| CVRP | 12 / 31 / 23 | 2 / 1 / 10 | 0.97 / 1.00 / 0.00 |

两条规律按任务分野：

- **VRPTW、OBP（及 TSP 的 2/3 重复）**：抽样集只含少量语义区域，85%–100% 的候选落在多谱系共享的区域里。谱系在代码层面持续分支，实现的求解行为汇聚到少数区域。
- **OP（3/3）与 CVRP（1/3）**：语义区域与谱系一一对应，每条谱系占据自己的行为区域，没有跨谱系汇聚。

63 号论文的"低连通、碎片化"在谱系图上复现（32–128 节点上有 5–105 个分量）；语义图上是否碎片化取决于任务：VRPTW/OBP 汇聚，OP 分散。kNN 稳定性对照（2.5%/5%/10%）下聚类系数变化在 ±0.05 内，上述结论对 k 不敏感。

## RQ2：fitness 在语义空间的结构

**局部平滑性（ΔL = 随机对 − kNN 邻居对的平均 |z 差|）**：

| 任务 | 3 重复 ΔL | 方向 |
| --- | --- | --- |
| VRPTW | 0.62 / 0.62 / 0.53 | 三重复同向，最大 |
| OBP | 0.47 / 0.47 / 0.60 | 三重复同向 |
| TSP | 0.34 / 0.63 / 0.34 | 三重复同向 |
| CVRP | 0.006 / 0.298 / −0.024 | 方向不一致 |
| OP | −0.19 / 0.23 / 0.28 | 方向不一致 |

**全局平滑性**：全部两两距离与 |z 差| 的 Spearman 在 15/15 个 run 为正（0.27–0.72）：VRPTW 0.42–0.45、OBP 0.52–0.66、TSP 0.57–0.64、OP 0.66–0.72、CVRP 0.27–0.63。

**Funnel**：到抽样最优的行为距离与 fitness gap 的 Spearman 在 15/15 个 run 为正（0.13–0.89）。TSP 最弱（0.17 / 0.62 / 0.13），OP 与 CVRP rep3 最强（0.57–0.89）。

**局部最优与高质量区域**：局部最优占比 VRPTW 0.04–0.06 最低，TSP 0.09–0.12，OBP/OP/CVRP 0.15–0.28。前 10% 候选在 kNN 图上的区域数：VRPTW 三重复均为 1（单一高质量区域）；TSP 2/4/2、OP 2/4/2、CVRP 2/3/1、OBP 1/1/4。多区域任务的区域间最小距离很大（TSP 0.42–0.80、OP 0.54–0.79、CVRP ≈0.81），高质量候选形成相距较远的行为岛。

综合：**TSP、OBP、VRPTW 三任务三重复全部支持"行为近邻 fitness 更近 + 到最优距离与 gap 同向"，语义空间存在可利用的局部结构；两个 ACO 任务平滑性方向不一致**，与它们最低的面板稳定性（校正实验 panel Spearman 0.48–0.63）一致——距离几何本身噪声大，32 个抽样点上局部平滑性不可分辨。

## RQ3：搜索怎样穿过语义景观

**无突破事件的构成**（占全部转移比例，按 25%/75% 分位步幅阈值）：

| 任务 | 小步-无改善 | 其中精确重访 | 大步-无改善 |
| --- | --- | --- | --- |
| OBP | 0.80 / 0.84 / 0.90 | 0.31 / 0.34 / 0.17 | 0.06 / 0.05 / 0.02 |
| VRPTW | 0.83 / 0.84 / 0.87 | 0.02 / 0.06 / 0.09 | 0 / 0 / 0 |
| TSP | 0.77 / 0.87 / 0.80 | 0.14 / 0.24 / 0.18 | 0.03 / 0.03 / 0.03 |
| OP | 0.58 / 0.65 / 0.65 | 0 / 0 / 0.03 | 0.10 / 0.07 / 0.03 |
| CVRP | 0.48 / 0.81 / 0.45 | 0 / 0.03 / 0 | 0 / 0 / 0 |

抽样尺度上，停滞几乎全部是"小步重访"：五任务小步-无改善占比 0.45–0.90，大步-无改善（无效漂移）只在 OP 出现到 0.10，其余任务 ≤0.06。这与 65 号论文语义空间里"漂移是失败信号"的图像在行为空间里更强：V9.16 的 Explore 大步多数被质量筛选淘汰，存活下来的转移以近行为为主。

**突破发生在更远的行为距离**：突破时刻的中位新颖度高于无突破时刻，TSP 0.28/0.28/0.47 vs 0.21/0.10/0.18，OBP 0.26/0.17/0.23 vs 0.11/0.04/0.10，OP 0.65/0.61/0.57 vs 0.50/0.58/0.48；VRPTW 2/3 重复同向，CVRP 三重复两者相等（≈0.72–0.82，全距离都远）。

**算子**：Explore 的中位父子行为距离在 15/15 个 run 高于 Refine（任务级均值 Explore/Refine：TSP 0.712/0.453、OBP 0.339/0.155、VRPTW 0.740/0.525、OP 0.664/0.557、CVRP 0.830/0.749），与 v3 校正完全一致。

## 与 63 号论文结论的对照

- "低连通、碎片化"：谱系图上成立；语义图上任务分化——VRPTW/OBP 汇聚为少数区域，OP 保持分散。碎片化的相当部分是生成谱系的性质，抽象为"算法空间本身碎片化"会把任务差异抹平。
- 代码相似度与性能差的相关：换成行为距离后，全部 15 个 run 的距离-|z 差| Spearman 为正，TSP/OBP/VRPTW 上局部平滑性三重复同向；63 号论文中 OBP 上趋势弱或不一致的结论，在行为度量下改变。
- "多峰"：高质量区域数 1–4 且区域间距离接近全距上限，行为空间的多峰结构在 TSP/OP/CVRP 上可见，VRPTW 上单一区域。

## 认识与限制

1. 行为距离测的是固定 probe 上的执行行为；语义区域是阈值连通分量，不是算法思想簇。OP 的"谱系-区域一一对应"读作"不同谱系保持了不同执行行为"，不读作"不同算法思想"。
2. 时间量在抽样序列上计算，重访占比是下界，突破弱于真实 best-so-far 判定；ACO 任务每 run 仅 32 个抽样点，其几何指标噪声大，方向不一致的结论按"不可分辨"处理。
3. 到最优的 funnel 用抽样最优，run 搜索最优 14/15 不在抽样内（已从 checkpoint 单列审计）。
4. 全部为观察性结果；"行为近邻 fitness 更近"不蕴含"沿行为梯度改写可用"，后者需要生成侧实验。
