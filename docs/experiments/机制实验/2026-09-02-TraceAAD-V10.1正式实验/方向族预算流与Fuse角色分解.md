# 方向族预算流与 Fuse 角色分解（V10.1 批次 20260902）

口径与数据同[预算流向与兑现分析](预算流向与兑现分析.md)：15 路（10 完成 + 5 进行中），fitness 为训练集口径。本轮回答两个问题：**节点分配健康的前提下，设计方向层面的预算分配是否健康**；**Fuse 的高改进率到底是合成还是传播**。

方法：family（方向族）的操作定义——8 个 init root 各为一族，每个有效 Pivot 子代开启一个新族，Refine/Fuse 子代归入其父节点的族，Fuse 另记 donor 的族。族不是语义上的算法思想，但比节点身份更接近"设计方向"。每批的完整选择分布由 batches.jsonl 记录的 beta 与当时档案重建（与记录的 parent_probability / ess_actual 最大偏差 1e-15 / 1e-12 量级，与 `traceaad.py` 的 ESS-Boltzmann 实现一致），父节点概率质量按族聚合后计算族级 ESS。donor 按实现为跨 lineage 的 top-5 节点中均匀抽取。

## 核心判断

1. **节点 ESS 与族 ESS 的反差是本轮最硬的数字**：后期 node ESS 升到 60–90 的同时，12/15 路 run 的族 ESS ≤ 2.0，其中 9 路等于 1.0 附近；12/15 路 run 单一 family 拿走 ≥75% 的父节点选择（VRPTW r1 从 b200 起是 100%）。ESS=0.1N 维持的多样性绝大多数是**同族兄弟节点之间的分散**，不是设计方向之间的分散。
2. **发现频率不缺，缺的是存活**。全批次出生 4054 个 Pivot 族（每 run 约 270 个，出生速率全程恒定：每 200 预算 665–872 个），加上 120 个 init 族；但只有 150 个族（3.6%）得到过哪怕一次父节点机会。budget 300 之后出生且获得资助的族只有 29 个，其中产生实质影响的三个——VRPTW r3 的 P374（b394 出生、58 次选择）、OBP r1 的 P543（b555、53 次、该 run 最优所在族）、TSP r3 的 P453（b623、41 次、最终 best 所在族）——全部是出生当步即达到或接近前缘的 Pivot。当前分配把"出生即好"当作唯一存活条件。
3. **垄断本身不致命，垄断族的合成枯竭才致命，而分配层分辨不出这两种状态**。OP r2 单族 100% 预算仍然健康（7 个 Fuse 突破全部是同族 synth，最终 14.932 为 OP 最优训练值）；VRPTW r1 同样单族 100%，b200 后 donor 100% 同族，best lineage 的 10 个 Fuse 步 8 个 nogain，前缘从 b195 冻结到结束——同族传播还在发生（后期对中等子代仍有 22.7% 的改进率），但不再产生新全局最优。
4. **Fuse 的双重角色确认**。对 donor 比 target 好 2–10% 的中等父节点：Fuse 改进率 58.8%，但其中 53.9 个百分点是 transfer（子代落在父与 donor 之间，中位只关闭 51% 的差距）——这是**向 elite donor 的知识迁移**，撑起了 Fuse 高改进率的表象；而全部 128 个 Fuse 新全局最优 100% 是 synth（同时超过父节点与 donor）。传播改善族内中等节点，不推进前缘；合成推进前缘。synth 率随族垄断从 10.5%（b0–200）降到 3.5–4.9%（b400 之后），Fuse 突破率相应从 5.2% 降到 0.9–1.7%。
5. **赢家形态是多族竞争 + 跨族合成，输家形态是早期单族锁死**。CVRP r2 的 0–200 预算分散在至少 5 个族（P32 28%、P45 19%、P9 16%、P118 16%），决定性 Fuse 步（b43、b78、b84）是跨族 synth；TSP r3 全程 3–4 个族保有预算，最终 best 所在的 P453 在最后 200 预算拿 47%；VRPTW r3 的第二族 P374 后期拿 37–38%。这三个赢家恰是全批次仅有的族 ESS ≥ 2.4 的非 OBP run。

对"缺的是新 family 的发现频率，还是已有 family 之间的资源竞争方式"的回答：**两者都不是第一环——第一环是新方向的存活机制与停滞族的再定向机制**。发现以恒定速率持续发生（问题不在生成频率），但出生不在前缘附近的族概率质量 ≈0，一次性饿死；而当前缘族停滞时（VRPTW r1 自 b195），没有任何信号把 Fuse 的 donor 池重新多样化或把预算重新分给其他族——垄断族同时垄断了 donor 池（同族 donor 率从早期 50% 升到 ~78%，VRPTW r1 后期 100%），传播继续、合成枯竭。

## 2 family 生死

全批次出生 4054 个 Pivot 族（+120 个 init 族），出生速率全程恒定（每 200 预算 857/872/846/814/665 个）——**生成端的新方向供给从不枯竭**。但：

- 仅 150 个族（3.6%）曾获得 ≥1 次父节点选择；其余 96.4% 出生即零预算，多数是单节点族（那个 Pivot 子代本身）。
- budget ≥ 300 出生且获得资助的族仅 29 个。资助额前三名 P374/P543/P453 分别拿到 58/53/41 次选择，全部是出生当步 fitness 即进入前缘的 Pivot（P543 出生即该 run 最优，P453 出生即 −5.837 接近最终 best，P374 出生 −19.058 为当时次优）。
- 第一轮报告的"3712 个 Δq<0 Pivot 子代合计 32 次复选"在族语言下就是：绝大多数新族出生时的概率质量 ≈0，Boltzmann 分配对"方向"无感知。

## 3 垄断何时无害：OP r2 与 VRPTW r1 对照

| Fuse 突破 | 7 个，全部同族 synth，持续到 b319 | 2 个（b138、b661），b195 后前缘冻结 |

同族 donor 不是问题本身：OP r2 证明一个足够富的族内部可以持续 synth。VRPTW r1 的族在 b195 前后耗尽了合成潜力，之后 Fuse 对族内中等节点仍保持 22.7% 的"改进率"（向族内 elite 传播），但这只改善非前缘节点。**改进率指标在垄断+停滞状态下会持续给出虚假的健康信号；只有"前缘突破率"暴露停滞，而 V10.1 的分配层不读这个信号。**

## 4 Fuse 角色分解

对每个有 donor 的 Fuse 子代（n=4517），按 q_T（父）、q_D（donor）、q_C（子代）分类：synth = q_C > max(q_T, q_D)；transfer = q_T < q_C ≤ q_D；nogain = q_C ≤ q_T。

| 任务 | n | donor 优于 target | synth | transfer | nogain | 子代超过 donor | 跨族 donor |
|---|---:|---:|---:|---:|---:|---:|---:|
| TSP | 828 | 546 | 8.5% | 26.7% | 64.9% | 17.5% | 33.3% |
| CVRP | 816 | 577 | 11.4% | 30.0% | 58.6% | 20.2% | 10.4% |
| OP | 990 | 461 | 2.7% | 13.4% | 83.8% | 8.6% | 5.5% |
| VRPTW | 884 | 590 | 5.8% | 24.0% | 70.2% | 15.0% | 20.5% |
| OBP | 999 | 418 | 2.5% | 14.5% | 83.0% | 4.3% | 67.4% |

按 donor−target 相对差距分层（全任务合并；1105 例 donor 与 target 完全同分计入 <2% 档）：

| 差距 (q_D−q_T)/\|q_T\| | n | 改进率 | 其中 synth | 其中 transfer | 改进子代中位关闭差距 |
|---|---:|---:|---:|---:|---:|---:|
| < 2% | 3305 | 27.2% | 4.6% | 22.5% | 91% |
| 2–10% | 388 | 58.8% | 4.9% | 53.9% | 51% |
| > 10% | 4 | — | — | — | — |

- **"中等父节点 + elite donor → 子代向 donor 迁移"成立**：差距 2–10% 档的 58.8% 改进率里，53.9 个百分点是 transfer，子代中位落在父与 donor 的中点（关闭 51% 差距）。第一轮报告中"Fuse 对 5–20% 父节点改进率 28–60%"的相当部分是这个传播效应，不是组合创新。
- **但传播不推进前缘：全部 128 个 Fuse 新全局最优 100% 是 synth**（同时超过父与 donor；很多 synth 的 donor 甚至比父差——合成的是两个好而不同的机制，elite 迁移只是合成失败时的常见落点）。
- 跨族 vs 同族 Fuse（合并）：跨族 n=1269，改进 22.5%、synth 5.1%；同族 n=3248，改进 28.8%、synth 6.2%。跨族 Fuse 没有更高的成功率——赢家的跨族 synth（CVRP r2 的 b43/b78/b84，VRPTW r3 的 b58）价值在于**发生在多族竞争期、直接命中前缘**，而不是跨族本身更高效。OBP 的 67% 跨族率是并列适应度造成的族标签碎片化，参考意义有限。
- 时间维度：synth 率 10.5%（b0–200）→ 6.1% → 4.9% → 3.5% → 3.9%（b800+）；Fuse 突破率 5.2% → 3.0% → 2.8% → 0.9% → 1.7%；donor 同族率 50.5% → ~78%。族垄断通过 donor 池同族化，把 Fuse 从合成器逐步退化为族内传播器。

## 5 对第一轮报告的三处修正

1. "父节点分配不是瓶颈"限定为**节点层**结论。方向族层面，12/15 run 单族 ≥75%、末段族 ESS ≈1.0，节点层 ESS 的健康数字掩盖了方向层的垄断。
2. "Pivot 在 top5% 父节点上是纯损耗"改为：**单步期望为负、尾部价值真实存在**——23 个 Pivot 突破中 16 个来自 top5% 父节点。top 父节点上的 Pivot 是低命中率、重尾的发现动作，问题在于它与开发动作等量消耗预算，而非其没有价值；同时它的存活完全依赖出生即好（见 §2），anchor 分布过窄的问题在族层才可见。
3. delayed realization 的排除项收紧为：**在 V10.1 当前 policy 下，成功搜索路径不依赖大退步子代的 delayed realization**；大退退 Pivot 子代每子代仅 0.01 次复选，其 delayed value 基本未被观测，不构成普遍结论。
