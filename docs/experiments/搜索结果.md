## 工件口径

统计读取正式 held-out `results.json` 的 `run_records`，只使用其中记录的 `train_artifact_score` 或 `train_best_score`。held-out objective 不进入任何数值或排名。

| 任务 | 搜索指标 | 正式重复 |

| TSP Construct | TSP50 平均 tour length | 3 |
| CVRP-ACO | CVRP50 平均最优路径长度 | 3 |
| OP-ACO | OP50 平均 collected prize | 3 |
| Online Bin Packing | 训练实例平均箱数 | 3 |
