# 2026-W33

## 研究

- 完成 V9.3 批次 `20260809_134642` 与 V9.4 批次 `20260810_0024` 的四任务三重复、搜索过程和 held-out 联合审计，形成 [V9.3 / V9.4 机制与实验分析](../analysis/TraceAAD-V9.3-V9.4机制与实验分析.md)。
- 主要结论：V9.3 的正信号来自退步后的连续发展与代表筛选，不来自 rollout `Q`；V9.4 的一步联合生成和质量区覆盖分别具有运行效率与局部突破价值，但折扣信用几乎没有改变利用选择，两版均约 98.5% 单谱系集中。
- 冻结 V9.5 正式批次 `20260811_171029` 的运行中统一 evaluator 截点，形成 [V9.5 阶段性运行机制分析](../analysis/TraceAAD-V9.5阶段性运行机制分析.md)：不同 objective landscape 下出现 active optimism、near-greedy 与 pure-`q` tie diversification 等运行形态；这些过程统计用于理解机制，不足以在完整预算和消融前判定 `s` 缺陷或修改 V9.5。
- 定位 V9.5 两个未完成 repeat 为 tokenizer 暂时不可用后 UTF-8 字节回退造成的假 context overflow；将正式生成合同修正为 32768-token 总上下文、8192-token 最大输出，并改为按完整 chat template 精确计数。Tokenizer 连续三次失败现明确记为 infrastructure failure，不再参与上下文判定。
- 两个从头补跑的 `contextfix_*` 随后分别在 TSP 51 responses / 50 evaluator calls、CVRP 55 / 55 时触发 `tokenizer_retry_exhausted`，正确记录为 `infrastructure_failure`；这确认了新错误分类生效，但替代 repeat 仍未完成，不能进入正式三重复结果。
- 在已完成的 10/12 正式 run（TSP/CVRP 各缺 1）上完成 [V9.5 终局复盘](../analysis/TraceAAD-V9.5终局复盘.md)：TSP 搜索/held-out 强，OP 3/3 弱，三种 allocation regime 到预算终点仍在；V9.5 证明机制运行并改变搜索行为，尚未证明 Evidence 或 optimism 各自提高最终质量。
- 将终局认识回写 [研究认识](../knowledge/研究认识.md)：搜索机制分配机会而 LLM 决定兑现；最终优秀 lineage 可以高度非单调，但事后谱系价值不等于前瞻预算信用；changed-rate 不是优化目标；历史价值可能依赖任务的算法改进几何。下一阶段只优先做 History 与 Allocation 两个单变量消融，补跑完成前不修改 V9.5 核心机制。
- 完成 [V9 与 V9.5 生成接口审计](../analysis/TraceAAD-V9-V9.5生成接口审计.md)：纠正强参照为 V9（单版本固定基线 1.867；MCTS-AHD 1.933）。TSP/CVRP/OP 各随机抽取 20 条真实 prompt；V9 重建 token 误差为 0。V9.5 历史事件略少，但 actual diff 使 history token 从 V9 的约 1K 增至约 3.1--3.4K。该结果只确立 signal-to-noise 风险，不证明 prompt 导致性能差异；下一步改为固定 anchor 的生成接口配对，再做 allocation 消融。
- 将 V9.5 后的实验顺序收口到 [RQ-003](../research/RQ-003-轨迹上下文与搜索评分.md)：先以固定真实 anchor 做低成本生成接口识别，比较 code only、简洁历史、compact correction，并检查 history × simple generation intent 交互；识别后优先形成更强的下一版，再做语义自洽的正式消融。V9.5 方法规范保持冻结。
- 冻结并启动 [V9.5 简洁历史生成识别实验](../experiments/TraceAAD-V9.5简洁历史生成识别实验.md)：从正式 V9.5 当时 snapshot 按 task 内 directed-q 三等分抽取 72 个唯一 anchor，每个 anchor 配对比较 No History 与 Concise History 各3次，共 432 trials。A/B 逐字只差 History block，不含 actual diff 或 operator；24 个分片已使用 zhong/server3/server3b 的空闲容量启动。
- 上述识别实验已全部收口：432/432 唯一 trial，无缺失和重复行。Concise History 在 69 个可配对 conditional Δq 的 anchor 中 44 个方向更好、23 个更差、2 个持平；CVRP 的配对 Δq 有明确正信号，OP/TSP 正向但不确定，OBP 负向且不确定。History 在 CVRP/OP/TSP 稳定降低修改幅度，但 TSP valid rate 下降 16.7 个百分点。结论限于有至少两条局部历史的单步生成，不外推完整搜索或 held-out 效果。
- TSP 有 28 份候选在正式 probe 中触发 20 秒 evaluator timeout。空闲顺序复评显示 History 8/20、No History 3/8 恢复有效，但仍有 12 对 5 份稳定超时。这表明并发竞争放大了 invalid 数，但 History 条件更常生成慢候选的相对信号仍在；复评不替换主结果。
- 冻结并启动 [V9.5 紧凑实际修改识别实验](../experiments/TraceAAD-V9.5紧凑实际修改识别实验.md)：复用同一批 72 个 anchor，配对比较 Concise History 与增加确定性 Compact Actual Change 各3次，共 432 trials。A/B 只差 compact change block；生成使用空闲 GPU 容量并行，所有代码生成后再由单一本地 evaluator 进程顺序评价，避免并发 CPU 竞争混入 valid-rate。
- 紧凑实际修改识别实验已全部收口：432/432 次生成和评价，两条件各 19 个 invalid，无解析失败。CVRP 的 conditional \(\Delta q\) 配对差为 +0.237 [0.088, 0.409]，improvement rate 从 13.9% 升至 33.3%；OP/TSP 方向为正但不确定，OBP 方向为负。Compact change 的稳定行为影响是进一步收缩修改幅度；它有额外信息价值，但不是已证明的四任务通用默认接口。
