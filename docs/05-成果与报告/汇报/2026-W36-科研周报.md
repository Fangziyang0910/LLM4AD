# 科研周报｜2026 年第 36 周

## 1. 当前卡点

这两周，我主要围绕 TraceAAD 的预算分配和上下文提示进行调优，希望在相同评价预算下稳定超过现有方法，但尚未取得预期的 SOTA 突破。部分改动在个别任务上有效，却没有形成稳定的整体优势。当前的难点是：如何利用已有搜索经验，既继续改进较好的算法，又找到值得发展的新方向。

## 2. 主要尝试

预算分配方面，我尝试依据近期改善追加预算、为新方向保留探索机会，以及利用执行行为的相似性识别重复搜索，希望提高预算利用率。生成方面，我调整了形成历史的呈现方式，并比较局部改进、切换思路和算法融合，希望兼顾稳定改进与结构突破。围绕五个任务完成了多轮实现、消融和过程分析，但这些调整尚未带来稳定的最终收益：近期改善不足以预测后续潜力，单次生成的改进率也不能直接说明其对完整搜索的价值。

## 3. 新的研究认识

我之前更关注选父节点和单次生成质量，忽视了新方向产生后能否得到继续发展的机会。过程分析发现，选用了很多不同节点，预算仍可能集中在同一种思路上；新生成的切换思路分支中，仅约 3.6% 后来获得过继续发展的预算。这说明，节点分散不等于方向多样，提出新想法也不等于完成了有效探索。

现在我认为，需要联动考虑“从哪个算法出发、怎样修改、提供什么上下文、是否继续发展”。当前高分可以提供可靠起点，却不代表未来改进空间；新方向暂时退步，也不代表没有价值。尚未解决的关键问题是：如何借助轨迹证据识别值得继续尝试的方向，同时避免无差别追加预算。机制是否有效，最终仍要看它能否在有限预算内找到更好的算法。

## 4. 下一阶段安排

我准备先围绕生成与后续分配的衔接完善机制，通过相同预算下的完整搜索和未见实例测试验证，近期目标仍是取得可信的 SOTA 结果。同时凝练工作的核心贡献，明确轨迹信息帮助解决了什么仅靠当前代码和分数难以处理的决策。在此基础上，再将“什么状态下怎样修改有效、哪些方向值得继续”的反馈整理为可学习信号，探索学习生成或分配策略。
