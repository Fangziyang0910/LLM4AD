## 审计问题

首轮 v5 训练显示：TSP Construct 出现超过 v4 的最好单次结果，但三个重复的均值和稳定性没有超过 v4；CVRP-ACO 与 OP-ACO 的训练表现下降；Online Bin Packing 因更换协议暂时没有同口径 v4 对照。

本轮审计回答三个问题：

1. 当前运行实际执行了哪些 v5 机制，哪些机制没有真正工作；
2. 最终质量和重复稳定性下降时，搜索过程发生了什么；
3. 现有证据支持“机制原理失效”，还是更支持“机制落地和组合方式存在缺陷”。

## 结论书写边界

文档严格区分：

- **观察**：可以从配置、日志、checkpoint、程序和训练分数直接复查的事实；
- **推论**：多个观察共同支持的机制解释；
- **待验证**：仍需要受控消融或修复后重跑才能判断的竞争解释。

当前阶段判断是：现有缺陷足以解释 v5 的过早收敛和高方差，因此没有必要据此直接否定全局经验、双轨迹搜索或最小 anti-bloat 的原理价值；这些原理仍然是待验证假设，不能因为实现存在缺陷而自动视为已经成立。
