# TraceAAD V2：岛模型、多算子信用分配与精英课程的轨迹搜索

> 状态：历史版本记录，不定义当前方法。实验结局见[版本谱系与实验事实](../analysis/TraceAAD-版本实验事实与机制诊断.md)的 V2 条目。

## 1. 设计动机

V2 是 TraceAAD 把"算法改进历史指导下一步"这一主张落地的第一版完整实现。它的核心是：把每次修改的来时路组织成有界轨迹，让历史中的结果与失败进入下一步生成，并在轨迹之上叠加多套辅助机制来维持多样性、平衡探索与利用、为算子分配信用。

V2 的设计是多层的：改进历史本身有用；用岛模型分隔种群能维持差异；用一组语义不同的算子并按效果分配预算能平衡探索与利用；用一份由全局最优刷新事件凝练的精英课程能把已验证的成功路线作为生成参照；用一个多目标价值函数同时考虑质量、潜力、差异、新颖度、紧凑度与速度能选出更值得继续的路线。

V2 因此是一个机制叠加的设计：它在轨迹与派生图之上同时运行岛模型、新颖性搜索、五算子 portfolio 信用分配、精英课程、Elo 式对比反馈与多分量价值评估。

## 2. 搜索状态、轨迹与派生图

一次决策的状态为：

\[
s_t=(x,p_t,\tau_t,\eta_t,d_t,\kappa_t,b_t),
\]

其中 $x$ 为任务与目标函数接口，$p_t$ 为主锚点程序，$\tau_t$ 为含它的轨迹，$\eta_t$ 为选内部锚点时其后已测试的尝试，$d_t$ 为 crossover 使用的 donor 轨迹（单轨迹算子下为空），$\kappa_t$ 为本轮注入的精英课程包，$b_t$ 为预算与阶段状态。

派生图是单父有向无环图：每个新程序恰好一条入边，保存父子、修改说明、算子、定向 delta 与改进/停滞/退步。轨迹是图上的有界路径，最多 8 个节点；回溯或重组时截取到锚点的前缀再追加子节点，若超出上限从最早端截断。回溯与重组都只产生一条新边，donor 只通过提示文本传递思想，不成为第二父代。

## 3. 岛模型与迁移

active 种群按岛组织：默认 4 个岛，每岛上限 40 条轨迹，全局上限 160。新轨迹按"当前活跃最少的岛"分配，使各岛负载均衡。

迁移是环式的：仅当搜索出现停滞、且周期达到 `migration_interval`=20 时触发，每岛取标量值最高的轨迹迁入下一岛。迁移保留轨迹身份与访问计数，只改所属岛。这样在停滞时把各岛当前最强的路线交换一遍，避免各岛长期互不相关地漂移。

岛的职责是分隔而非隔离：父代抽样时先取全局 top-12，再为每岛补一条代表，保证低表现岛仍有参与机会。

## 4. 五个语义算子

| 算子 | 语义 | 锚点与写回 |
| --- | --- | --- |
| `endpoint_refine` | 在终点上继续强化最近有效的方向 | 终点；extend |
| `backtrack_branch` | 终点退步或停滞时回到更优的内部前缀换向分支 | 内部锚点（4 规则门控 + branch_score）；branch_from |
| `mechanism_crossover` | 从互补的 donor 轨迹移植一个算法思路到当前终点 | 终点 + donor；branch_from |
| `simplify` | 在不降 fitness 的前提下降低复杂度 | 终点；extend |
| `novelty_jump` | 从零生成与当前精英明显不同的新方案 | 无锚点（fresh start）；create_initial |

`backtrack_branch` 主动扫描全池寻找最值得回溯的目标，而非只在被选中的轨迹内操作。`mechanism_crossover` 按"互补度（1−相似度）加质量"选 donor。`simplify` 仅在终点复杂度高于池上四分位时触发。`novelty_jump` 列出当前最强的若干思想要求避开，并在搜索后期被限制概率。

## 5. 多分量价值与轨迹调度

路线价值由六个分量加权而成：

\[
V_i=0.42\,Q_i+0.18\,P_i+0.12\,D_i+0.12\,N_i+0.08\,C_i+0.08\,S_i,
\]

分别为质量、潜力、边际差异、新颖度、紧凑度与速度。质量由 fitness 经分位裁剪后归一化；潜力是路径上父子差分的折扣回报，并叠加正向比率奖励与下行惩罚，且以质量门控（质量过低时潜力置零）；差异与新颕度由代码 token 与轨迹行为指纹的 Jaccard 相似度算出；紧凑度与速度由复杂度与运行时相对池归一化。

父代调度在标量值上加 UCB：

\[
A_i=V_i+c_t\sqrt{\frac{\log(1+N)}{1+n_i}},
\]

其中 $c_t$ 随迭代衰减并随停滞增强。抽样时取全局 top-12 并为每岛补代表，以小概率直接采精英，否则按 softmax 采样。

## 6. 算子调度的信用分配

算子由一个 portfolio 选择，本质是带上下文 bonus 的折扣 UCB bandit 加贝叶斯先验。每个算子维护一组指数滑动平均统计（效用、下行、代价、是否产生全局最优、是否接近记录）。算子得分为：

\[
\text{score}=\mu-\lambda_d\,\text{downside}-\lambda_c\,\text{cost}+g_{\text{best}}+g_{\text{near}}+\text{ctx}+\text{prior}+\text{ucb},
\]

其中 $\mu$ 为折扣平均效用，$g_{\text{best}}$、$g_{\text{near}}$ 奖励产生全局最优或接近记录的算子，ctx 是依当前轨迹状态（退步、停滞、深度差等）给的上下文加成，prior 是带伪计数的冷启动先验，ucb 是基于折扣有效尝试数的探索项。选择按 softmax 采样并与 epsilon-greedy 混合，epsilon 与温度都随迭代衰减。

信用是逐步的：每条边只承担自己的 delta，后代不向上回传，以规避 MCTS 式最大化回溯造成的过度信用。

## 7. 精英课程、经验记忆与对比反馈

三套记忆在派生图之上提供额外上下文。

**精英课程**从真实图事件构造生成参照：最近若干次全局最优刷新事件、连续改进链、待修复的前缀、对比性成功/失败对，以及两条不同算子路线的重组。每条课程 trace 带证据类型、因果连贯性与置信度，按算子类型差异化组装（如 novelty 不给正例、backtrack 附带修复 trace、crossover 附带 donor trace），注入修改决策提示的专门段落。

**经验记忆**是图上边级的只读视图，按算子取若干成功与失败的修改示例，提示模型哪些方向已验证有效、哪些已失败。

**对比反馈**用一个 Elo 式排序模型给出当前池中最好与最差终点的对照，作为"应避免的退步"参照注入提示。

## 8. 生成、新颖性门与生存管理

生成分两阶段：先产出若干条自然语言修改意图，再对每条意图从主程序生成完整代码。修改决策提示含任务、轨迹近期的因果叙事、边级经验、精英课程、对比反馈、算子约束与目标程序。

新颖性门控在候选入池前检查：若与已有候选的最大相似度超过 `novelty_threshold`=0.92 且未刷新记录，则归档而不繁衍，控制种群冗余。

生存管理每轮执行：先按路径去重，再重算价值，按岛做 Pareto 非支配截断到每岛上限，再全局截断到 160，并保护当前全局最优所在路线。

## 9. 搜索流程

```text
1. 采样 n_init 个初始程序，分配到各岛建立单节点轨迹。
2. 重复至预算耗尽：
   a. 按 trajectory_ucb 选主轨迹（top-12 + 岛代表 + 精英保护 + softmax）；
   b. 预计算各算子可行性与上下文 bonus，portfolio 选一个算子；
   c. 算子解析锚点（backtrack 可能换目标轨迹，novelty 走 fresh start）；
   d. 构建精英课程包；
   e. 生成修改意图并据此生成候选代码；
   f. 评价、入图、写回（extend 或 branch_from）、新颖性门、更新最优；
   g. 课程记录教学效用，portfolio 批量更新算子统计；
   h. 停滞且达周期则环式迁移；去重与 Pareto 生存；
   i. 周期保存断点。
3. 返回全局最优程序。
```

## 11. 在版本谱系中的位置

V2 建立了"改进历史指导下一步"的骨架：有界轨迹、派生图、语义算子、新颖性门与边级经验记忆。这些结构在后续版本中保留。V2 同时叠加了岛模型、精英课程、Elo 对比反馈、多分量价值与 portfolio 信用分配；[V3](TraceAAD-v3完整机制设计.md) 移除这些附属层，只留轨迹主干。

实验事实与机制诊断见 [版本实验事实与机制诊断](../analysis/TraceAAD-版本实验事实与机制诊断.md)。
