# TraceAAD V3：去除附属层、回到轨迹主干的简化搜索

> 状态：历史版本记录，不定义当前方法。实验结局见[版本谱系与实验事实](../analysis/TraceAAD-版本实验事实与机制诊断.md)的 V3 条目。

## 1. 设计动机

V2 在轨迹之上叠加了岛模型、精英课程、Elo 对比反馈、多目标价值、复杂度与运行时度量、上下文 bonus 与 softmax/epsilon portfolio。这些层各自有动机，但共同造成两个问题：内部归因困难，且没有任何一层能被证明提供了独立于轨迹主干的信号。

V3 的判断是回归主张本身。TraceAAD 的核心是"用算法改进历史指导下一步"。这条主干只需要：有界轨迹记录来时路、轨迹之间的边级经验、一个能区分质量与潜力的价值函数、一个平衡探索与利用的算子选择，以及一个控制冗余的新颖性门。主干之外的层如果不能被证明提供独立信息，就应当移除，让机制主张与实现直接对齐、可审计。

V3 因此是一次系统性的删减：保留轨迹、派生图、四个语义算子、三维价值、固定 UCB、纯 UCB argmax 的算子调度、边级经验记忆与新颖性门；移除岛模型与迁移、精英课程、对比反馈、复杂度与运行时度量、上下文 bonus、softmax/epsilon portfolio、Pareto 生存与多线程评估。

## 2. 搜索状态与轨迹

状态从 V2 收窄：

\[
s_t=(x,p_t,\tau_t,\eta_t,d_t,b_t).
\]

不再有岛归属与精英课程包。轨迹、派生图、8 节点上限与单父写回规则不变：回溯与重组截取到锚点的前缀再追加子节点，donor 只通过提示文本传递思想，不成为第二父代。

## 3. 种群管理

V3 取消岛结构，使用单一活跃种群，上限 160 条轨迹，无每岛子限额。新轨迹直接进入种群。生存由路径去重与全局标量截断完成，保护当前全局最优所在路线，不再有 Pareto 非支配排序与按岛截断。迁移随之消失。

## 4. 四个语义算子

V3 保留 V2 五个算子中的四个，删除 `simplify`：

| 算子 | 语义 | 锚点与写回 |
| --- | --- | --- |
| `endpoint_refine` | 在终点上继续强化最近有效的方向 | 终点；extend |
| `backtrack_branch` | 终点退步或停滞时回到更优的内部前缀换向分支 | 内部锚点（4 规则门控 + branch_score）；branch_from |
| `mechanism_crossover` | 从互补的 donor 轨迹移植一个算法思路到当前终点 | 终点 + donor；branch_from |
| `novelty_jump` | 从零生成与当前精英明显不同的新方案 | 无锚点（fresh start）；create_initial |

各算子的语义、锚点选择与写回方式与 V2 一致。`simplify` 的删除是必然的：它依赖复杂度度量，而 V3 不再跟踪复杂度与运行时，价值函数也不再含紧凑度与速度分量。

## 5. 三分量价值与轨迹调度

V3 把价值从六分量降到三分量：

\[
V_i=0.55\,Q_i+0.25\,P_i+0.20\,D_i.
\]

质量、潜力与边际差异的计算与 V2 同源：质量由 fitness 归一化，潜力是路径上父子差分的折扣回报加正向比率奖励与下行惩罚，差异由代码与行为指纹的 Jaccard 相似度算出。删去的是新颖度、紧凑度与速度三个分量。质量归一化的分位裁剪也一并去掉，改用池内的直接最小最大值。

一个重要改动是潜力的质量门控被取消：V2 在质量过低时把潜力置零，V3 无论质量高低都计算潜力。

轨迹调度从随机采样改为确定性 argmax：

\[
i^*=\arg\max_i \bigl(V_i+0.4\sqrt{\tfrac{\log(1+N)}{1+n_i}}\bigr).
\]

UCB 系数固定为 0.4，不再随迭代衰减，也不再随停滞增强。没有 top-k、没有温度、没有精英直采、没有 softmax：每轮选标量值最高的轨迹。

## 6. 算子调度

算子选择退化为纯 UCB argmax。每个算子只维护尝试次数与累计奖励，得分为：

\[
\text{score}_o=
\begin{cases}
+\infty & \text{未尝试（冷启动）},\\
\bar r_o+0.5\sqrt{\tfrac{\log(1+T)}{1+t_o}} & \text{otherwise}.
\end{cases}
\]

每轮取得分最高的可行算子。没有指数滑动平均、没有上下文 bonus、没有贝叶斯先验、没有产生全局最优或接近记录的额外奖励、没有 epsilon-greedy、没有 softmax。算子选择与轨迹选择一样是确定性的；V3 保留的随机性只来自模型采样本身。

奖励由一批候选的 signed utility（$\tanh$ 归一化的定向 delta）取均值给出，空批次记为 −1。

## 7. 边级经验记忆

经验记忆是 V3 从 V2 完整保留的唯一上层记忆。它是派生图上的只读视图：按算子取若干成功与失败的修改示例（成功按 delta 降序、失败按 delta 升序，按修改文本去重），注入修改决策提示作为"哪些方向已验证有效、哪些已失败"的参照。它直接服务于"用历史指导下一步"的主张，不引入额外的调度状态。

精英课程、Elo 对比反馈与复杂度度量则全部移除，不再进入任何提示或决策。

## 8. 生成、新颖性门与生存管理

生成仍是两阶段：先产出自然语言修改意图，再对每条意图从主程序生成完整代码。修改决策提示精简为任务、轨迹近期因果叙事、边级经验、算子约束与目标程序五段；V2 的精英课程段与对比反馈段被删除。

新颖性门与 V2 一致：候选入池前若与已有候选的最大相似度超过 0.92 且未刷新记录，则归档而不繁衍。

生存管理每轮执行路径去重与全局标量截断到 160，保护全局最优路线。

## 9. 搜索流程

```text
1. 采样 n_init 个初始程序，建立单节点轨迹。
2. 重复至预算耗尽：
   a. 按三维价值 + 固定 UCB，argmax 选主轨迹；
   b. portfolio 在可行算子中 argmax 选一个（backtrack 可能换目标，novelty 走 fresh start）；
   c. 解析锚点；
   d. 生成修改意图并据此生成候选代码；
   e. 评价、入图、写回（extend 或 branch_from）、新颖性门、更新最优；
   f. 用候选效用更新该算子的累计奖励；
   g. 路径去重与全局标量截断；
   h. 周期保存断点。
3. 返回全局最优程序。
```

## 10. 运行参数

| 参数 | V3 |
| --- | ---: |
| 评估预算 | 1000 |
| 活跃轨迹上限 | 160（单一种群） |
| 每轮修改数 | 2 |
| 轨迹节点上限 | 8 |
| 价值分量 $(Q/P/D)$ | 0.55 / 0.25 / 0.20 |

| 算子数 | 4 |
| 记忆层 | 边级经验记忆 |
| 生存 | 去重 + 全局标量截断 |

## 11. 在版本谱系中的位置

V3 让机制主张与实现直接对齐：有界轨迹、派生图、四个语义算子、三分量价值、固定 UCB、边级经验与新颖性门构成一条主干。V3 之后的设计问题回到主干内部——轨迹长度、价值分量与 UCB 取值、算子调度方式、参考轨迹如何进入决策，由 [V4](TraceAAD-v4完整机制设计.md) 重构为单父代轨迹搜索逐一处理。

实验事实与机制诊断见 [版本实验事实与机制诊断](../analysis/TraceAAD-版本实验事实与机制诊断.md)。
