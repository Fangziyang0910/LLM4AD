## 1. 设计动机

V8.3 正式版的根锁定与 sibling 爆炸指向选择层信用失衡：`new_child` 质量含已有子代
回报使成功 sibling 持续抬高同一动作，`descend` 用子树历史最大值使一次幸运后代永久
代表整条祖先分支。V8.3-credit 保留正式版的树、局部探索脉络与五算子，只重写选择信用：
用轨迹先验（从节点自身及其来时路可观察的事实）作为无经验时的初值，用路线经验信用的
运行均值逐步替代先验，用概率 UCB 保持低访问路线的非零机会。

## 2. 与正式版的机制差异

| 环节 | V8.3 正式版 | V8.3-credit |
| --- | --- | --- |
| 已有子节点选择 | `descend(c)=B(c)+0.1r_t\sqrt{\log(1+N(n))/N(c)}`，子树最好值回传 | 轨迹先验 + 路线经验信用，`A(c)=Q(c)+0.25\sqrt{\log(1+N(n))/N(c)}`，取消剩余预算衰减，温度 0.2 softmax |
| 开新分支 | `new_child` 质量含已有直接子代回报，与 descend 价值竞争 | 宽度条件 `\|Children(n)\| < max(1, floor(N(n)^0.5))` 时无条件扩展，虚拟根同规则；不与 descend 竞争 |
| 深度上限 | `max_depth=10` | 无固定上限，深度由访问、宽化和预算自然形成 |
| 信用 | 冻结直接回报 + 子树 G 回传 | 直接回报写入本轮选择路径上全部程序节点，运行均值 |

保持不变：10 个有效初始化根、完整单父树、局部轨迹上下文（最近 3 条形成边 + 最多
3 个代表性直接子分支）、五算子等概率、crossover 参考不构成第二结构父代、每次扩展
一个候选、global best 只由原始 fitness 决定。

## 3. 信用公式要点

- **有向 fitness 与秩归一化**：最大化取原值、最小化取负，$y(n)$；全树中秩百分位
  $F(n)$（并列感知），全同分时 0.5；路径历史最好 $H(n)=\max_{v\in\tau(n)}F(v)$。
- **轨迹先验**：$Q_{history}(n)=0.7F(n)+0.3H(n)$；最近 8 条形成边按父子 fitness
  变化记改善 1 / 持平 0.5 / 退步 0，折扣 0.8 聚合为 $P(n)$（无形成边取 0.5）；
  $V_{prior}(n)=0.8Q_{history}(n)+0.2P(n)$。
- **单次扩展回报**：$R(n,c)=0.75F(c)+0.25[F(c)-F(n)]_+$，冻结创建时点的 $F$；
  失败记 0；后代不追溯改写。
- **路线经验信用**：回报写入从根到父节点的选择路径上全部程序节点（虚拟根不记）；
  利用值 $Q(n)=\frac{V_{prior}(n)+C_{sum}(n)}{1+C_{count}(n)}$，先验相当于一个伪样本。
- **选择**：达到宽度后按 $A(c\mid n)=Q(c)+0.25\sqrt{\log(1+N(n))/N(c)}$ 对同层
  softmax（温度 0.2）并用 seeded RNG 抽样。每步保存轨迹先验、经验均值、利用值、
  探索值、分数与抽样概率。

## 4. 提示词协议

两次 LLM 调用：Call 1 输出 `design_idea` + 完整代码，Call 2 只描述已有代码的实际
行为，不重复局部脉络、算子指令或参考算法。共享骨架：

```text
[Task]
[Current Algorithm]   Fitness / Description / Code
[Local Exploration Context]   最近的来时路和代表性已尝试分支
[Operator]           算子名与算子特定指令
[Reference Algorithm]  仅 trace_crossover
[Generation Requirements]
```

通用生成要求：以当前算法为直接修改基础做一次有算法意义的改动；利用局部脉络避免
重复已知尝试；允许必要的配套修改；输出完整可执行代码；`design_idea` 与实际代码
一致。算子特定指令（只作用于 Call 1）：

- `trace_refine`：聚焦于继续发展或修复当前机制。根据来时路中已经形成的有效思路、当前算法的薄弱点以及已尝试分支暴露的问题，选择一个最值得继续开发的方向，提出聚焦且完整的下一步改进。
- `trace_tune`：聚焦于校准当前机制的参数、阈值、尺度、触发条件或控制细节。判断哪些细节限制了当前算法，并为校准它们做出必要的配套修改；配套修改可以包含状态统计、归一化、自适应控制或局部结构调整。
- `trace_simplify`：聚焦于降低当前算法不必要的机制和实现复杂度。判断哪些部分可以删除、合并、重组，或用更简单的机制取代，同时保留当前算法的关键功能。简化应当减少真实概念或代码复杂度，不是只改名、压缩排版或隐藏相同逻辑。
- `trace_innovate`：聚焦于从当前节点探索一个明显不同的核心思路。利用局部探索脉络识别已经停滞或反复失败的方向，提出具有实质机制差异的新路线。可以保留当前算法中仍然有价值的组件，但不应将普通的局部调整当作换新方向。
- `trace_crossover`：以当前算法为主体，从参考算法中识别一项与当前机制互补的思想，将它选择性地适配并融入当前代码。判断两者的功能关系和冲突，完成必要的配套调整。不要机械拼接两份完整代码，也不要无选择地复制整个参考算法。

参考候选为除当前节点外的全树有效节点，按标准化有向 fitness softmax 抽取
（$\tau_{ref}=1.0$，全同分时均匀抽样）。

## 5. 信用特定不变量

与正式版共享的协议不变量（个体表示、两次调用、评估边界、初始化 10 根、单父代、
五算子、停止条件）不再重复。本设计特有的不变量：

1. 虚拟根同样参与 progressive widening；其扩展使用 `e1` 生成独立根方案，不使用五算子；
2. progressive-widening 触发即增加选择路径访问和扩展尝试数，上下文、生成、解析或
   评估失败均作为零回报写入选择路径信用；
3. 任意节点满足 $|\mathrm{Children}(n)|\le A(n)$，每个有效子节点恰好对应一次成功扩展；
4. 成功新节点以 $N=1$ 入树；子树最好 fitness 只用于局部脉络的代表性分支展示，
   不参与节点选择；
5. 每次成功扩展冻结 $F(c)$ 与 $F(n)$，回报只用这两个快照，后代或全局秩变化不追溯改写；
6. 失败尝试不建节点或边，但保留访问与扩展尝试，并以零回报更新选择路径信用；
7. 当 $|\mathrm{Children}(n)|<\max(1,\lfloor N(n)^\alpha\rfloor)$（$\alpha=0.5$）时
   无条件触发该节点扩展，达到宽度后才允许 descend。
