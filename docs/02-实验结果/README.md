# 02-实验结果：TraceAAD 与基线实验中心

本模块集中管理 TraceAAD 全系列版本及基线方法的**实验数据、跑榜结果、配置规范与核查记录**，提供统一、清晰的实验全景看板。

---

## 核心看板

### 1. [主实验结果汇总](主实验结果汇总.md)
五任务（TSP、CVRP、OP、OBP、VRPTW）× 五对比方法（EoH、ReEvo、MCTS-AHD、PathWise、CALM）与 TraceAAD 各代版本（V9 系列、V10.1 ~ V10.10）的统一横向入表对比、平均名次与 Held-out 泛化表现。

### 2. [主实验配置与冻结契约](主实验配置与冻结契约.md)
严格受 `tests/task/test_frozen_task_contract.py` 保护的五任务公共实验信息：
- 五任务公共 `task_description` 与 `template_program`（哈希严格锁定）
- 训练集与测试集规模划分、数据种子规范
- 三次独立重复实验种子约定（seed = 0, 1, 2）

### 3. [版本运行诊断与复盘](版本运行诊断与复盘/)
针对各代正式批次运行过程的实证核查、语义对账、错误分类统计与机理诊断（含 V10.6/V10.7 过程核查、V10.9 错误统计、V9 系列历史诊断等）。
