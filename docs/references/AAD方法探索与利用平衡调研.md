# AAD 方法探索与利用平衡调研

基于 `papers/` 库 54 篇论文原文（LaTeX 源码或整篇 PDF）的逐篇精读，覆盖 [LLM 自动算法设计方法汇总](LLM自动算法设计方法汇总.md)中结合进化机制的主要方法与机制分析文献。回答三个问题：各家如何认知"算法改进过程"；探索-利用被安放在哪些组件上；由此产生了哪些评分、种群与预算分配机制。逐篇机制细节见[阅读笔记](LLM自动算法设计方法阅读笔记/阅读笔记索引.md)（71 篇已按原文逐一核验），本文只保留跨方法判断与脉络；引用的公式与数字均经原文核对。

## 核心判断

1. **公共外环与三个可动接口**。几乎所有方法共享"生成—评价—选择"外环；创新集中在三个接口：**生成条件**（LLM 每次看到什么）、**选择信号**（谁被保留）、**预算分配**（下一次评价或调用投给谁）。探索-利用的安放位置沿这条轴单向迁移：生成算子的自然语言意图（EoH）→ 选择/评分公式（MEoH、QUBE）→ 树与 bandit（MCTS-AHD、Clade-AHD、BaSE）→ 上下文构成（AlphaEvolve、DeltaEvolve）→ 模型权重与训练数据（CALM、EvoTune、DAR）→ 控制搜索的策略本身（AHD Agent）。每一次迁移都把原先当作固定背景的东西（prompt 内容、数据库结构、模型档位、状态表示）变成被分配或被搜索的对象。

2. **LLM 变异算子结构性偏利用，探索由外部机制供给**。三条独立证据线收敛：无选择压力的 mutation chains 中 87% 的链唯一结构骨架少于 20 个，超过 93% 的变异在重访已见结构，而 GP 子树变异对照每链访问约 143 个骨架（[Mutation Without Variation](LLM作为进化算子的机制分析论文.md)）；轨迹分析称 LLM 变异是"被生成先验强烈偏置的定向变异"，漂移大的模型反而失败；经验适应度景观无漏斗、碎片化、低连通。方法设计因此形成主流分工：**利用交给生成**（精英进上下文、修改类意图、小步长变异），**探索交给结构**（岛屿、niche、类别、集合、树、bandit）。

3. **可靠局部精炼是性能主因，新颖性是条件性资产**。15 模型 × 8 任务的轨迹研究：严格父代改进率（LRR）对世代改进的回归系数 +0.528（p<0.001），新颖性主效应不显著，且新颖性×搜索局部化交互项显著为负——新颖性只在搜索已局部化在高性能区域时才转化为突破；把弱精炼模型的子代注入进化循环，性能随注入比例单调劣化（干预级因果证据）。EoH 的增量消融同样显示 thought 表示与 E2 交叉之后，M 组修改算子逐层累积正贡献。这裁决了"提高温度/奖励新颖性"式探索：无条件的新颖性最大化被数据否定。

4. **分配的价值是有条件的**。BaSE 的三重闸门：能力闸门（模型-任务格子必须跨过能力阈值且 best-of-N 之上仍有头部空间，1.7B 全不显著）、几何闸门（深度-广度交互系数决定最优配比，好算法族稀有的任务需要广度先锚定）、prompt 闸门（生成质量设定独立上界，"分配放大既有信号而不能创造信号"）。Relay 的经验规律补充：进步强前置（前 20 代贡献 76%–79% 的总改进），早期轨迹排名是有信息但含噪的信号（gen-10 与终局排名 Spearman 仅 0.28），因此单路线早承诺不可行，分配的单位应高于单次调用。

5. **两个再表述正在取代"调权衡参数"**。SMCEvolve 把探索-利用压进单一温度参数 $\beta_t$（重采样权重、接受率、停止规则三者由它统一驱动）；Back to the Beginning 把它改写为失真-压缩权衡（知识态搜索付表示代价 $\delta_P$ 换取自适应复杂度从 $I(\hat\theta;D)$ 降到 $I(\hat K;D)$）。两条线共同指向：探索-利用的实质是**状态在什么粒度、什么时机被压缩与切换**，而非选择公式里一个系数的大小。

## 1. 对算法改进过程的认知

### 1.1 五种世界观

| 世界观 | 代表方法 | 改进发生在哪 | 保留什么 |
| --- | --- | --- | --- |
| 搜索（EC 传统） | ELM、LMX、FunSearch、EoH、MEoH | 外层搜索循环对边际改进的累积 | 种群/岛屿/档案/精英 |
| 历史信息 | ReEvo 及其后继、DeltaEvolve、MEMOIR | 把轨迹信息转成下一代生成条件 | 反思摘要/经验池/差分/分层记忆 |
| 分配 | MCTS-AHD、Clade-AHD、BaSE、Relay | 有限评价在异质路线间与路线内的投放 | 树/谱系信念/bandit 统计/种群块 |
| 学习 | CALM、EvoTune、DAR、AHD Agent | 模型权重或控制策略吸收搜索经验 | 参数更新/训练数据集 |
| 知识 | Back to the Beginning | 知识态的假设-证据循环 | 可解释设计原则（代码只是实例化） |

各世界观对"好算法从哪来"的回答不同：FunSearch 最清醒地把 LLM 定位为"带偶尔有趣想法的多样程序源"，进步来自进化回路累积边际改进加低复杂度程序偏置；EoH 认为改进过程是人类专家启发式开发的自动化，"思想"层是因果主体；EvoTune 引 Bitter Lesson 表述为"搜索生成数据，学习蒸馏模式"；Back to the Beginning 把 bottom-up（先代码再归纳知识）倒转为 top-down（先假设再实例化）。世界观的分层不互斥——MeEvo 证明自然进化（表型）与元认知进化（基因型）必须交替，单侧各有崩坏域；dual 版本（知识种群与代码种群双向蒸馏）跨域平均排名最高。

### 1.2 对基线失败模式的诊断收敛为三条

- **保留性缺失**：种群准入规则（新个体须超过当前最差）使 worse-before-better 不可表达，垫脚石个体被扑杀（MCTS-AHD、Clade-AHD、PathWise 的共同动机）。
- **状态性缺失**：选择只保留"好结果"，丢弃"为什么好、为什么败"——HiFo 称之为 knowledge decay（设计原则纠缠在代码里随淘汰丢失），MeEvo 称之为缺乏 cognitive heritability（交叉继承代码片段却丢掉策略知识）。
- **信号贫乏**：标量分数只给成功幅度、不给改进机制。DeltaEvolve 的受控三臂实验最尖锐：在 AlphaEvolve 上遮蔽数值分数保留 Top-k 选择（Blind-Elite）几乎不损失性能，随机化上下文保留分数（Random-Context）则崩溃——标准进化框架真正起作用的通道是上下文构成（in-context 模仿被选程序），分数条件化的贡献有限。

第三条直接蕴含设计方向：既然起作用的通道是"给 LLM 看什么"，就应该显式设计这个通道（DeltaEvolve 的 M-step 形式化 $\mathcal{C}_{t+1}=\pi(\mathcal{H}_{t+1})$ retroactively 解释了整个反思-记忆谱系）。

## 2. 探索-利用的术语与安放位置

### 2.1 术语使用

多数方法明确使用 exploration/exploitation（FunSearch、EoH、QUBE、MCTS-AHD、Clade-AHD、BaSE、HiFo、MeEvo、ShinkaEvolve、SMCEvolve、RoCo、Relay、PartEvo、BehaveSim 等）；部分方法用等价对承担同一功能：diversity/convergence（MEoH、HSEvo、CDEoH）、质量-多样性 QD（ELM、AlphaEvolve）、深度-广度（BaSE）、novelty/complementarity（EoH-S、ShinkaEvolve）、bottom-up/top-down 与失真-压缩（Back to the Beginning）。ReEvo 与 MeLA 不机制化这对术语，平衡由结构隐式承担（ReEvo：交叉探索 + 精英变异利用；MeLA：元认知三任务中仅"创新假设"一项是探索成分）。

### 2.2 六个安放层面

| 层面 | 方法与机制 | 探索的实现 | 利用的实现 |
| --- | --- | --- | --- |
| 生成算子 | EoH E1/E2 vs M1–M3；RoCo explorer/exploiter/integrator 角色配温度 1.3/0.8；CogMCTS em/m 双轨；DyACE combine/mutate/explore 三模式 | 发散意图的指令与高温 | 修改/调参/简化指令与低温 |
| 生成步长 | ELM commit message 分档；Controlling-Mutation 行级百分比 + 幂律分布；PathWise $\varepsilon$ 扰动注入；SMC 四 kernel 混合 | 大步长、结构重写 | 小步长、参数微调 |
| 上下文构成 | FunSearch 精英 prompt；AlphaEvolve parent+inspirations+meta-prompt 进化；DeltaEvolve delta 金字塔动量；MEMOIR 全局否定约束 | 多样 inspirations、delta 的 diverse 注入、失败规避指令 | 精英代码、动量延续、已证组件保留 |
| 选择/评分 | MEoH dominance-dissimilarity；QUBE 进化质量 + UCB 项；ShinkaEvolve $\sigma(\lambda(F-\alpha_0))\cdot 1/(1+N)$；HiFo insight 效用（使用惩罚 + 新近奖励）；AutoSND $f(h)+\lambda/(1+c(h))$ | 不确定性/相异度/稀有度加成 | 质量项、支配关系 |
| 种群结构 | FunSearch 岛屿 + 签名聚类 + 定期重置；BehaveSim 行为聚类岛；PartEvo 特征投影 niche；CDEoH 类别精英；EoH-S 集合贪心；EvoPH MAP-Elites 岛 | 岛/niche/类别/集合保留异质区域 | 岛内精英、簇内温度退火 |
| 预算分配 | MCTS-AHD UCT；Clade-AHD Thompson；BaSE Improving Bandits；Relay Grow/Deepen + 交接；SMC 温度退火；TurboEvolve adaptive K；HiFo/MeEvo 的时间调度 | 探索常数、后验方差、Grow、新轨迹、高温 | 乐观项衰减、信念浓缩、Deepen、低温 |

时间维度上几乎全部方法都让探索随预算消耗衰减（FunSearch 岛内温度随程序数退火、MCTS-AHD $\lambda$ 线性衰减、Clade-AHD $\tau(p)=(1-p)^{-\omega}$ 退火、MeEvo $p_c$ 线性下降、PathWise $\varepsilon$ 0.5→0.25、SMC $\beta_t$ 上升）；反向调度（利用先行）在 MeEvo 的对照中更差。

## 3. 机制谱系与脉络

### 3.1 奠基：从质量-多样性到岛屿到思想-代码（2022–2025）

- **ELM**（2022）：diff 模型做语义变异 + MAP-Elites 行为网格（12³ niche）承载多样性；修改幅度由 commit message 语义分档（"Changed parameters" 40%/"Small change" 30% 等），是生成意图控制的雏形；4-Parity 实验证明单步变异能力对 GP 的指数优势。搜索产物反哺模型微调（搜索→生成的最早闭环）。
- **LMX**（2023）：few-shot 拼接父代即交叉，给出 EDA 解释；发现父代**排序**是显式选择压力旋钮、采样温度类比变异率、父代数控制分布建模宽度；同时承认算子层不解决早熟收敛——探索-利用留给种群层。
- **FunSearch**（2023.12）：骨架隔离收窄搜索空间；岛屿（每 4 小时重置一半，赢家岛克隆最优重启）+ 签名聚类 + 两级 Boltzmann 采样，簇温度 $T_{cluster}=T_0(1-(n\bmod N)/N)$ 随岛内程序数周期退火——**这批奠基工作中唯一真正的预算再分配机制**；短程序偏好是显式 parsimony 压力；LLM 被有意定位为多样程序源。代价是百万级样本。
- **EoH**（2024.01）：思想+代码双表示；五种算子显式分组 Exploration（E1 相异重组/E2 共同思想扩展）与 Modification（M1 结构修改/M2 调参/M3 删冗余），把探索-利用写进生成指令；父代按 $p_i\propto 1/(r_i+N)$ 秩反比软选择，种群纯截断 top-N。2000 次查询逼近 FunSearch 百万级样本（效率 3 个数量级）；消融显示 thought 表示 > E2 > M 组逐层累积。结构上无任何多样性维护——这是后续一整条线的靶子。
- **MEoH**（2025）：EoH 的 HV/IGD 随代数恶化被直接用作反例（单目标进化在多目标度量下退化）；dominance-dissimilarity 把 AST 相异度与 Pareto 支配相乘（$v_j=\sum_{i:P_i\prec P_j}(-\text{Sim}(P_i,P_j))$），同时改写父代采样与种群截断；输出从单点变为性能-效率前沿（相近 gap 下最多 10× 提速）。

### 3.2 选择信号：从纯分数到质量 + X（2024–2026）

这组方法共享一个诊断（纯分数选择要么早熟要么浪费预算）且几乎全部不动生成器，把主战场放在选择与种群管理——这是 54 篇中最一致的方法论结论。"X"的五个选项：

- **X = 访问不确定性（QUBE）**：簇的进化质量 $Q_t(C)$ 定义为**历史子代的平均分**（直接估计"当亲代的价值"，与自身分数区分），加 UCB 项 $k\sqrt{\ln t/N_t(C)}$；同时改写亲代选择与岛重置（按 UIQ 而非最高分决定岛的存亡）。三级消融同向（3.07%→2.98%→2.89%→2.76%）；过程证据显示探索量随时间自动衰减。代价：最优 k 跨任务差 5 个数量级，校准未解。
- **X = 类别稀有度（CDEoH）**：LLM 归纳算法类别，类别精英硬保留 + $S_i=$ 归一化分 $+\lambda/|C(i)|$ 稀有度加成；200 评价档即可起效；类别噪声无控制、λ 未扫描，10k 档反而略有害。
- **X = 集合增益（EoH-S）**：目标函数改为集合的实例级最优（CPI），超模性给出贪心 $(1-1/e)$ 保证；互补种群管理（CPM）消融贡献最大（0.0326 vs 0.0373）；父代按实例级性能向量 Manhattan 距离选最互补对，把互补性变成生成信号。实例分布单一时退化为精英选择（作者自证）。
- **X = 行为新颖度（BehaveSim）**：四个构造案例证明 token/AST/嵌入/输出/轨迹五类度量与"解题过程"错位（argmin/argmax 一字之差 AST 相似度=1.0）；行为相似度 = 实例与起点分布上 PSTraj 的 DTW 双重期望，嵌入 FunSearch 岛分配（替代亲代继承）与 MEoH 式支配矩阵两个位置。同骨架只换度量的对照（行为 > 代码 CodeBLEU > 随机）是"多样性操作化选择"最严格的现有证据。
- **X = 分区结构（PartEvo）**：CodeBLEU 相似度向量或思想嵌入投影后 K-means 分区，跨 niche 均匀分配采样资源；K=4 显著优于 K=1（无分区）与 K=6（过度分散），非单调；同初始化对照证明有意义特征分区 > 随机分区。

配套发现：机制必须**成对**出现——HSEvo 的消融显示和声搜索（参数利用）加进 ReEvo 无益，因为"利用机制需要探索机制配套"；PartEvo 的两组算子（prompt-centric 与 EC-inspired）缺一退化 450%–550%；BehaveSim 的 p_s1=0（纯岛内）退化。HSEvo 本身的贡献是度量（SWDI/CDI 嵌入熵）而非机制；Controlling-Mutation 证明行级百分比变异控制需要 GPT-4o 级遵从度（GPT-3.5 完全不遵从），动态率优于固定率只有单曲线证据。

### 3.3 从种群到树到 bandit：分配的数学化（2025–2026）

- **MCTS-AHD**：归一化 UCT + $\lambda$ 线性衰减 + progressive widening $\lfloor N^{0.5}\rfloor$；回传取 max（父价值=子树最优叶值）；六动作中 s1（树路径推理）是树特有生成。补上了 worse-before-better 的表达。自认弱点：黑箱任务退化（扩展次数有限时押注单次生成质量）。
- **Clade-AHD 的批评-修正链**：诊断 MCTS-AHD 在稀疏访问下"结构性过度开发"（点估计被噪声支配、max 回传永久抬高祖先）；修正为 clade 级 Beta 信念（后代证据按 $\lambda^{dist}$ 深度衰减聚合，$\lambda=0.8$；$\lambda=0$ 即节点级近视基线，最差）+ 伪计数稳定 + 温度退火 Thompson + 动态冻结。组件消融（冻结/退火/深度衰减各贡献 4.9%–7.8%）；但 TSP50 构造与 MKP-ACO 上 MCTS-AHD 仍反超——修正并非全域成立。
- **平行的树线**：PoH 把动作定义为"改进建议"（状态-动作 UCT，e=2.5），其 MC/Greedy/Beam/MCTS 同转移算子的受控对照（0.227% vs 0.530%/0.260%）是"只换搜索策略"的干净证据；CogMCTS 沿用 MCTS-AHD 全部选择机制，把认知（快慢反思、正负知识库）注入生成侧；PathWise 换掉整个选择机制（蕴含图 + 策略/世界模型/critic 多智能体），探索从统计量搬进采样分布（探索短语 $\varepsilon$ 注入 + 状态洗牌，SDR 从 75.8% 掉到 53.8% 当去掉时性能 8.79→11.43）；RefineEvo 留在种群内，把规划移到**算子维度**（MCTS-AHD 规划"扩展哪个节点"，RefineEvo 规划"调用哪个算子"），双向经验池消融显示负经验比正经验更重要（13.94% vs 12.92%）。
- **BaSE**（对 Evolve 系而非 AHD 树方法）：按 FLOPs 计价后模型规模与搜索预算是替代品（4B/8B/14B 包络重合 $R^2\ge 0.93$）；深度-广度规律 $\log(1-V)=\beta_0+a\log T+b\log N+c\log T\log N$，交互系数 $c$ 由"每个任务只有一个高适应度算法族、LLM 对其基率因任务而异"（asymmetric proposal mass）解释；Improving Bandits（奖励随分配步数提升的非平稳臂）上 Thompson 在高方差任务系统性优于 UCB/EXP3.P；臂池中等最好（K 太小探索不足、太大摊薄精炼）。
- **SMCEvolve**：把程序进化写成 KL 正则变分推断 $p^*\propto p_0 e^{\beta R}$，重采样权重 $e^{\Delta\beta_t R}$、MH 接受率 $\min\{1,e^{\beta_t(R(x')-R(x))}\}$、ESS 停止三件套由单一温度 $\beta_t$ 驱动，并将 AlphaEvolve/ShinkaEvolve 表述为"固定逆温度 + 无条件接受 + 固定迭代数"的退化特例。代价：reward-only 近似破坏不变性保证；ESS 只读 reward 离散度，区分不了"高质量收敛"与"同分低质停滞"。

树与 bandit 方法自己暴露的失败模式：过度开发（点估计 + max 回传）、信用错配（均匀回传把远代改进错记给祖先）、评价噪声（随机种子的瞬态高分成为永久锚点）、早熟剪枝（冻结与臂集中可能把预算交给"目前最改善"但整体病态的分支）。

### 3.4 历史与记忆：反思如何改写生成条件（2024–2026）

ReEvo 是枢纽基线：短期反思来自配对比较（"verbal gradient"），长期反思是 ≤50 词滚动压缩文本服务精英变异。其后继把 $\pi(\mathcal{H}_{t+1})$ 这个 M-step 做成各种形态：

- **HiFo-Prompt**：Foresight 是显式三态控制策略（停滞计数器与表型多样性触发 Explore/Exploit/Balance，翻译成指令注入 prompt；自适应 vs 固定 Balance 在 TSP200 差 8.9% vs 22.1%）；Hindsight insight 池有完整信用分配（分段效用 + EMA + 使用惩罚 + 新近奖励 + 淘汰，类比 SW-UCB）。关键对照：把同样 seed insight 注入 EoH/ReEvo 初始 prompt 收益可忽略——收益来自**池的管理机制**而非知识内容本身。
- **MeEvo**：自然进化（表型）与元认知进化（推理轨迹作为基因型）单种群交替，宏观节奏 + 微观 $p_c$ 从 0.7 线性降到 0.5 双层调控；(N,/) 与 (/,M) 消融各有崩坏域（纯 ME 在 ACS 上 1293 vs 578），组合必需；反向调度更差确认"探索先利用后"。
- **MEMOIR**：branch-local（分支内全部执行记录，约束修复）与 global（分支终止时压缩的三字段条目，含显式否定约束）分层；flat-memory 变体显著劣于分层（Avg −8.5），去掉失败节点 −8.4——**失败信息本身是必要记忆**；层级分离而非"有记忆"驱动增益。
- **DeltaEvolve**：只存"改了什么/为何/定性效果"的三层金字塔（L1 摘要/L2 计划/L3 全代码按新近性渐进渲染），token 省 37%；动量即利用（延续已证 delta），diverse delta 注入即探索。
- **PhyloEvolve**：谱系森林 + 精英轨迹跨树检索 + 修改统计（效果×一致性×置信度）；主张最系统（Warmup/Explore/Exploit 三模式）但无消融、无基线对照、无重复报告，证据最弱。

裁决：记忆机制双侧起作用——防重复失败/强制异质是探索侧（MEMOIR 的否定约束、HiFo 的使用惩罚、MeLA 的错误规避），复用已证组件/延续方向是利用侧（ReEvo 精英变异、DeltaEvolve 动量）；消融证据一致表明单侧缺失有具名失败模式（知识塌缩、约束违反重犯、mode collapse）。完整轨迹与压缩摘要的真正分歧在**压缩时机与粒度边界**（代边界/分支终止/时间窗），而非存哪种；所有八篇均无记忆条目真实性的验证机制。

### 3.5 大规模框架：上下文构成作为隐式分配（2024–2026）

AlphaEvolve 明说"数据库设计的核心挑战是平衡探索与利用"却不写公式——平衡由 MAP-Elites + 岛屿数据库、prompt 采样（parent + 多样 inspirations + meta-prompt 自身进化 + stochastic formatting）与静态双模型分工（Flash 吞吐 / Pro 突破）隐式承担；五个组件在 2 任务 × 3 种子上有受控消融。后续开源线把它逐步显式化：

- **ShinkaEvolve**：三个显式在线机制——父代加权采样 $s_i=\sigma(\lambda(F_i-\alpha_0))\cdot 1/(1+N_{child}(i))$（性能×反拥挤，对探索-利用最直接的框架级公式化）、embedding 新颖性拒绝（cosine>0.95 拒绝，LLM 复核仅边际增益）、UCB1 模型 bandit（奖励取相对父代/初始程序的改进并放大高风险变异）。作者自批评"对探索-利用平衡的自动控制跨域有限"。
- **TurboEvolve**：岛级 adaptive K（K∈{1,3,5,7}，以"archive 是否被替换"为分配信号，停滞加 K、全进展减 K）+ multi-offspring 单次生成多候选 + seed-pool 聚类注入；事件内分析发现 head 候选（自报 rank 1–2）供即时改进、tail 候选供 stepping stone 的角色分工，parent-inspiration 表示距离的**中间十分位**改进率最高（过近无新意、过远离落地）。
- **Relay**：批判 call-level 模型路由忽视搜索的状态耦合，把分配单位升到**种群块**：cheap 相位 Grow/Deepen 窗口 UCB 调度，Relay Gain（质量 top-r 均值 + 质量加权 facility-location 覆盖的次模组合）在耐心窗内饱和时把整个精选 bank 交接给强模型单一种群；贪心交接有 $(1-1/e)$ 保证。12 设置 11 个最佳，且 call-level bandit 对照不稳定——分配单位与奖励的升维是被消融支持的。
- **Back to the Beginning**：知识态为主要搜索对象（一次生成同时返回知识与代码，选择按代码实证分、变异常识在知识层）；稀疏评价实验（50% 候选不评价，未评价者仍以结构证据参与知识后验）显示一半评价预算取得最佳测试 gap——当评价稀缺时，把状态抬到可用文本证据更新的层级可部分绕开评价瓶颈。

### 3.6 学习与智能体：把平衡搬进权重、数据与策略（2025–2026）

对"固定 LLM + 外部进化"的诊断排成谱系：采样分布不随反馈改进（EvoTune/CALM）→ 上下文与操作是固定配方（AHD Agent：预实验显示把全部工具给固定工作流反而有害，问题在按状态取用信息的机制）→ 单角色混合发散与收敛（RoCo）→ 离散采样的搜索几何病态（LHS）。学习化的重构：

- **CALM**：每轮 GRPO 更新（G=4 rollouts，奖励=相对 prompt 最优基启发式的裁剪改进量，分层不可行罚 + 复现惩罚）；种群侧保留 diversity crossover（50% 概率第二亲本按 idea-token 差异从全池采样）与 collapse 重启。消融：纯性能奖励比不训练还差——奖励塑形即"教策略什么算真改进"。
- **EvoTune**：搜索是数据收集器、RL 是策略优化器；forward-KL DPO（mass-covering）防 mode collapse、训练数据覆盖全搜索历史、数据库采样百分位退火；与 FunSearch 同构去 RL 对照（10 seeds）是"学习带来样本效率"最干净的证据。
- **DAR**：探索-利用完全落在训练数据构造——τ 控制正样本从哪个质量档抽取、跳一档配负样本；对照证明 top-k（只用最优样本）训练出的模型更差。微调后的模型接入 EoH/FunSearch 再提升——学习与外部搜索叠加。
- **AHD Agent**：生成/调工具/评估/终止全部成为多轮动作，预算的花法由策略学习；11–15 次评估即具固定工作流 100 次评估的竞争力；模型规模扫描单调改善而固定工作流非单调——推理能力在 agentic 形态下才被兑现。
- **RoCo**（不动权重的对照组）：探索-利用实体化为角色与温度；白盒下与 EoH 持平、黑盒下 integrator 贡献最大——角色分工的价值集中在反馈受限场景。
- **LHS**：探索 = 种子 softmax + 流形约束下的保守步长，利用 = latent surrogate 梯度场；把"探索的风险"重定义为"离流形"（解码失败）。

共同模式：训练天然侵蚀探索（KL 方向、top-k、collapse、轮数收敛），每篇都需要专门机制把探索保回来；奖励信号三形态（GRPO 组归一标量 / DPO 成对偏好 / RankNet 代理梯度）与塑形深度、更新频率构成谱系；没有一篇的证据支持"学了权重可以扔掉外部搜索"。

### 3.7 改进信号的扩展：从终点分数到过程证据（2026）

第七条线把改进信号从"每候选一个标量"逐级加密，且**信号变密的位置决定探索方向的控制权从选择公式转移到生成引导**：

| 信号 | 方法 | 密度 | 控制权落点 |
| --- | --- | --- | --- |
| 结构-性能 surrogate | LLaMEA-SAGE（AST 特征 + XGBoost + SHAP→一句话变异指令） | 每候选一向量 | 变异 prompt 增广，选择保持精英制 |
| 程序图嵌入 + 元控制器 + 在线 GRPO | GAE（GNN surrogate、SAC 选编辑动作、GRPO 更新 LLM 全权重） | 每代一组 | prompt 结构提示 + 权重 |
| 教师动作偏好 | Teacher-Aware（on-policy top-1 一致率进 Pareto 第二轴 + analyzer 转译修订算子） | 每状态一个偏好 | 修订简报；对齐轴是保留侧的多样性 |
| 阶段中间反馈 | EvoStage（K 阶段，coordinator 每阶段反思定下一阶段目标） | 单次评价内 K 次 | 阶段目标 $g_i$；Pass Rate 78% vs EoH 23% |
| 求解轨迹特征 | DyACE（fitness 速度/加速度、多样性损失率、算子精度/影响） | 每决策步 | 求解过程内部的算子切换（控制权进入 solver 时间轴） |
| 执行证据 | AutoSND（质量+运行时+失败状态+代码操作编译为结构政策 Π） | 每候选一记录 | 政策全文进 prompt + 静态违规硬拒绝 |

三个裁决性观察：其一，DyACE 的 Blind 消融（保留在线适应、去掉特征提取）劣于 Static——**无感知的动态适应有害**，适应以可靠状态感知为前提；其二，SAGE 的合规性分析显示"random new"prompt 下 LLM 完全忽略结构引导、"refine"下大体服从——**探索型指令会冲掉方向引导**，生成意图与注入信号存在交互；其三，这组方法没有一个把新信号用于改选择公式（QUBE 的位置），全部投入生成条件化，其中 EvoStage 用 25 次评价、SAGE 用 50 次评价达到基线 200 次的水平——评价昂贵时生成侧引导的边际收益大于评分公式的统计精细化。学习组件只负责"读"（状态估计、证据压缩、安全边界），LLM 负责"写"，选择负责"留"；学习链越深消融越缺（GAE 无组件消融，Teacher-Aware 无学习组件消融最全）。

### 3.8 机制分析文献的裁决

| 机制 | 证据 | 判定 |
| --- | --- | --- |
| 最小保留-变异-选择循环 | (1+1)-EPS 500 次查询 > 独立采样 10000 次；约 2000 次评价后增益放缓 | 证实，数量级 |
| 精英保留/不丢最优 | Behaviour Space：只改选择（L3→L4）显著变好；Trajectory：局部化是新颖性兑现的前提 | 证实 |
| 精英进上下文 | (1+1)-EPS 即此构造，强基线；DeltaEvolve：上下文选择主导标量反馈 | 证实为强机制 |
| 双意图提示 + 精英 | L4（refine&random-new 双提示 + 1+1 精英）最好 | 支持（单框架单模型） |
| 失败计数式 bandit 分配 | REx：Beta 后验随失败衰减 + Thompson，跨域最鲁棒 | 证实（修复域，AAD 域未直接测试） |
| 岛屿、复杂种群结构 | 统一基准无一复杂方法跨任务一致超过 (1+1)-EPS；种群法偶尔丢最优 | 存疑 |
| 反思（ReEvo 式） | 无跨任务一致优势，AS 方差大；但 ReEvo 后继的组件消融均正贡献 | 存疑（作为整体）／正（组件层） |
| 自适应变异幅度提示 | L5/L6 不如 L4；Controlling-Mutation 需 GPT-4o 级遵从度 | 弱/条件性 |
| 无条件新颖性/多样性最大化 | 新颖性系数不显著；交互项显示仅局部化条件下有用 | 证伪（作为无条件目标） |
| 多 LLM 组合 | 代码指纹互不重叠；稠密/稀疏生成图互补；模型混合=精炼率干预 | 方向性支持，缺系统实验 |

跨层结论：搜索增益在任务×模型格间高度不均匀（OBP-OR 上几乎无增益），好解密度是任务属性（启发式任务约 80% 算法落在最低 20% fitness 区间，符号回归 98% 远离最优）——探索-利用的最优配比是任务可读出量，这为"从轨迹在线读出任务特性"提供了外部佐证。

## 4. 共识、分歧与开放问题

**共识**：(i) LLM 生成天然带先验偏置，单独的生成器不解决探索-利用，平衡必须由外部机制承载；(ii) 利用侧的通用载体是把高分个体放回生成上下文；(iii) 评价必须外部可执行，LLM 不承担 fitness；(iv) 探索应随预算消耗衰减，衰减形状多为线性或温度式。

**分歧**：(i) 多样性的操作化——文本/AST、嵌入、行为轨迹、语义类别、性能互补、评分不确定性六种，行为轨迹与性能互补有最严格的同骨架对照，类别标签无可靠性验证；(ii) 分配的自适应程度——从均匀轮转（多数）到按分数（FunSearch 重置）到 UCB/Thompson（QUBE/Clade/BaSE）到相位交接（Relay）到统一温度（SMC）；(iii) 探索-利用的时间轴——代际间（多数）vs 单次求解内部（EvoStage/DyACE）；(iv) 预算档位——200 评价档（CDEoH/MeEvo）、1000 评价档（MCTS-AHD 系、本仓库口径）、80K–2M 样本档（FunSearch/QUBE），跨档结论不能互推。

**开放问题**：(i) 探索-利用配比的任务可读出量尚未被任何方法在线使用（landscape 与 BaSE 的证据都是离线分析）；(ii) 生成与分配的耦合缺少直接实验——BaSE 证明了分配依赖提议异质性，但没有方法测量"分配公式对提议分布的反作用"；(iii) 记忆/反思条目的真实性无验证机制， misrepresented failure 可能排除有用的算法族；(iv) 报告口径混乱——best-of-N 与固定预算单 run 混杂（BaSE 的动机之一），多数方法 3–5 次重复无显著性检验。

## 5. 对本仓库研究问题的接口

以下为外部证据到可检验假设的映射，外部结果不能替代 TraceAAD 自身的受控实验。

- **生成决定可达、分配决定兑现**的外部版本：BaSE 的能力闸门与 asymmetric proposal mass 是"分配杠杆随分支间生成质量的方差增长"的实证表述；其"分配放大既有信号而不能创造信号"对应生成质量设定上界。Relay 的进步前置与含噪早期信号提示：路线级承诺的可行窗口在中后期，早期应维持多路线。
- **"当亲代的价值"作为选择信号**：QUBE 的 $Q_t(C)$（历史子代均值而非自身分数）与父代改进来时路的思路同构，其三级消融形状可作分配机制对照实验的参照。
- **路线/簇异质性的度量候选**：BehaveSim 的 PSTraj+DTW 与 EoH-S 的实例级性能向量互补性是两种有消融级证据的行为度量，可用于检验"路线是否是投资单位"。
- **意图与上下文的交互**：SAGE 的合规性发现（探索型指令忽略方向引导）与本仓库"上下文政策应写成 $h_t=\operatorname{Ctx}(a_t,o_t,\mathcal H_t)$"的判断一致，提示 Refine/Explore 应有不同上下文构成而非共享轨迹模板。
- **失败信息的价值**：MEMOIR（去掉失败节点 −8.4）与 RefineEvo（负经验 > 正经验）一致支持把失败尝试作为一等记忆，与本仓库"已有子代尝试作为搜索事实保存"的做法相容。
