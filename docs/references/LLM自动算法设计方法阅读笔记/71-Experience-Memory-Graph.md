# Experience Memory Graph

- 论文：*Experience Memory Graph: One-Shot Error Correction for Agents*；本地来源：LaTeX 源码目录 [`Experience_Memory_Graph_One-Shot_Error_Correction_for_Agents/`](../../../../papers/Experience_Memory_Graph_One-Shot_Error_Correction_for_Agents/)；研究对象：把 agent 失败恢复从在线反思-重放循环改为离线确定性图计算的记忆结构。

## 1. 核心问题与方法

训练侧把每条探索轨迹与专家轨迹（ETO 数据集提供）转为有向**动作决策图** $G=(V,E,q,r)$：节点 = 归一化动作元组（type, object, receptacle），边 = 归一化观测文本（动作前置条件）；同动作节点复用（多入边捕捉"同一动作在不同观测下出现"）、无效动作并行挂接在同一有效决策点，虚拟 INIT 节点携带初始观测；内容相同则标签相同，图匹配退化为标签相等比较。记忆图：节点 $\nu_i=(q_i, embed_i, I_i^{intra}, G_i, G_i^\*, r_i)$，边 $\epsilon_{ij}=(s_{ij}, I_{ij}^{cross})$，$s_{ij}=\cos(embed_i,embed_j)$，$s_{ij}\ge\tau$ 且 top-$k$ 近邻才连。**一次纠错**：Fused Gromov-Wasserstein 无监督图匹配（软匹配后线性指派离散化）——匹配的相同部分 = 公共子图（正确工作流），差异部分 = 最短图编辑路径（在哪个观测下应删除/添加/替换哪个动作），这是确定性的纠错计划；LLM 只负责把结构总结为自然语言洞见。相似任务专家图之间图匹配取公共子图得跨任务边洞见。测试时按 top-$K$ 节点 + 其 top-$T$ 邻边检索洞见进 prompt，单次执行无循环。

## 2. 论文宣称的机制贡献（逐项）

- 失败与参考的确定性结构 diff（公共子图 + 编辑路径）替代自由文本反思。
- 图记忆使一次纠错长期生效、跨任务迁移（边洞见）。
- 测试时无反思循环，推理时间显著低于迭代式基线。

## 4. 机制的底层逻辑（阅读分析，不是作者已证明结论）

把"这次怎么改"从生成问题（LLM 反思）转为结构问题（图编辑路径）：diff 的每一步绑定到具体观测（前置条件），因此一次生效且可迁移。算法设计没有专家轨迹，参照物只能是自身搜索产出的 best-so-far——diff 的"正确性"不再有外部保证，这是该机制迁移到 AAD 的根本缺口。

## 5. 对 LLM4AD / TraceAAD 可学习之处

- 可学习点：改进轨迹与参照（best-so-far）的**结构化编辑路径**（算子级、组件级）替代自由文本反思作为修改意图。前提：两版代码可对齐到共享表示。风险：无专家参照时编辑路径的正确性未定。最小验证：固定锚点上对比结构 diff 与文本反思作为上下文的一步改进率。
- 可学习点：相似任务/路线间用结构匹配提取公共子图作为簇级可复用模式。最小验证：对同簇路线两两取公共子图，检验其复现率与跨路线增益。

## 6. 证据边界

依赖每任务专家轨迹与单条探索轨迹；确定性只在结构对齐层，洞见生成仍经 LLM 总结；两个文本游戏环境；$K,T,\tau$ 取值原文未明确；泛化增益条件性强（小模型、未见任务）。
