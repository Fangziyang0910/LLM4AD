# MEoH

- 论文：MEoH；本地来源：[`papers/MEoH/MEoH.tex`](../../../../papers/MEoH/MEoH.tex)；设计对象：面向组合优化的启发式代码。

## 1. 核心问题与方法

MEoH 把启发式设计重构为**多目标优化**：目标向量为（最优 gap，运行时间），附录扩展三目标（加可读性）。五个生成算子（E1/E2/M1/M2/M3）明确标注 adapted from EoH，属继承；真正的机制贡献是 **dominance-dissimilarity 选择信号**：对种群两两计算 AST 相似度取负得相异度矩阵，与 Pareto 支配掩码逐元素相乘后按列求和（个体得分 $v_j=\sum_{i:P_i\prec P_j}(-\text{Sim}(P_i,P_j))$，被支配且与支配者代码雷同者受罚最重），该复合分同时用于父代采样（softmax）与种群截断（降序 top-N）两个位置。输出从单点最优变为非支配前沿。

## 2. 论文宣称的机制贡献（逐项）

- 把启发式设计多目标化，单次运行产出一组性能-效率权衡的启发式（相近 gap 下运行时间最多省 10×）。
- dominance-dissimilarity 把目标空间支配关系与代码空间相异度复合进同一评分，用于选择与种群管理两处。
- 收敛分析以 HV/IGD 显示 EoH 的多样性随代数塌缩（单目标进化在多目标度量下退化），MEoH 稳定上升。

## 4. 机制的底层逻辑

阅读分析：dominance-dissimilarity 把"不被支配"（目标空间）与"和支配者代码相异"（结构空间）乘在一起，是选择信号从纯质量扩展到质量+结构相异度的代表形式。它的风险面在 AST 相似度与行为差异的错位（BehaveSim 后来证明同类度量在部分任务上失效）；三目标与逐算子信用分配未做。

## 5. 对 LLM4AD / TraceAAD 可学习之处

- 可学习点：选择信号复合"质量 + 与支配者的结构相异度"。前提：相似度可计算且与行为相关。风险：AST 相似与行为相似错位。最小验证：分桶报告相异度与下一代真实改进率的关系。
- 可学习点：把效率（运行时间）作为第二目标而非约束。前提：评价时记录耗时。风险：前沿上时间维度退化为噪声。最小验证：报告 Pareto 前沿随代数的展开形态。
