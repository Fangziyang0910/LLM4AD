# MCTS-AHD

- 论文：MCTS-AHD；本地来源：[icml2025.tex](../../../../papers/MCTS-AHD/icml2025.tex)；设计对象是 ACO、GLS、构造式框架中的启发式函数。

## 1. 核心问题与方法

MCTS-AHD 将每个可执行启发式表示为树节点，在预算内循环选择、渐进扩展、模拟评价和回传。UCT 使用归一化质量值（在线 min-max）与访问数平衡利用/探索，探索系数线性衰减 $\lambda=\lambda_0(T-t)/T$（$\lambda_0=0.1$ 全任务统一）；渐进扩展条件 $\lfloor N^\alpha\rfloor\geq$子节点数（$\alpha=0.5$，根用 e1、非根用 e2 加宽）。**回传取 max 而非均值**：父节点价值 = 子树最优叶值（$Q(n_c)\leftarrow\max_c Q(c)$、$N(n_c)\leftarrow\sum_c N(c)$）。每次扩展产生 $2k+2=6$ 个子节点并全部评价；e2 的精英参考按 $p_i=1/(r_i+10)$ 采样。深度上限 H=10。动作是初始化（i1）、交叉（e1/e2）、变异（m1/m2）与树路径推理（s1，输入根到叶去重函数）六类 LLM 生成操作。附录优势范围分析：启发式空间越大（o1 估计的维数越高）、任务描述越充分（白箱），MCTS 相对 EoH 领先越大；黑箱设定下明显退化。

## 2. 论文宣称的机制贡献（逐项）

1. 以 MCTS 系统探索开放代码空间，而非平坦进化。
2. 渐进扩展和带衰减的探索控制动作分支数。
3. 通过路径回传把叶节点评价传播给决策祖先。

## 4. 机制的底层逻辑

阅读分析：MCTS 的价值在于把对下一次“生成操作”的选择变成路径信用分配：一次叶子改进可提高其祖先动作的吸引力。渐进扩展限定开放动作空间。但 LLM 每次生成的随机性、动作成本和 evaluator 噪声会破坏传统 MCTS 独立同分布回报假设，故 UCT 值应理解为启发式调度信号而非无偏价值估计。

## 5. 对 LLM4AD / TraceAAD 可学习之处

|可学习点|成立前提|主要风险|最小验证方式|
|---|---|---|---|
|把动作、路径、评价事件分别记录|真实执行路径可获得|只保留节点分数，丢失信用链|审计每次回传的节点、访问增量和评价来源。|
|按访问/不确定性渐进开放操作|候选操作可枚举|把访问数误作候选质量|同预算比较固定扩展与渐进扩展，报告有效调用。|

## 6. 证据边界

原论文中 TSP 搜索预算为 T=1000，T=2000 属在线 BPP，不可与测试实例数混淆。主表为三次平均（消融与 p 值实验 5–10 次），显著性：构造式 TSP50 p=0.0029、KP p=0.0275 等单尾 t 检验。max 回传使"子树曾出过一次高分"永久抬高祖先价值，是 Clade-AHD 批评的结构性过度开发来源之一；λ 敏感性显示 0.05 与 0.2 在不同任务上互有优劣（KP 偏好 0.2）。若比较方法具有不同原生预算或每次样本的 LLM 调用数不同，最终质量不能解释为纯树策略效应。
