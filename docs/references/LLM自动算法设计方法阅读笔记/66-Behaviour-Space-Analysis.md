# Behaviour Space Analysis of LLM-driven Meta-heuristic Discovery

- 论文：*Behaviour Space Analysis of LLM-driven Meta-heuristic Discovery*；本地来源：LaTeX 源码目录 [`Behaviour_Space_Analysis_of_LLM_driven_Meta_heuristic_Discovery/`](../../../../papers/Behaviour_Space_Analysis_of_LLM_driven_Meta_heuristic_Discovery/)；研究对象：被 LLM 生成的元启发式（而非 LLM 本身）在求解时的行为画像，及其与配置/性能的关系。

## 1. 核心问题与方法

LLaMEA + o4-mini-2025-04-16，10 个无噪 BBOB 函数（5D），5 训练 + 10 测试实例，每次运行 100 个算法预算，每配置 5 个种子，BLADE 框架记录全程 trace，AOCC 指标。六种配置 = 变异提示 × $\mu/\lambda$ × 精英的 2×2 组合扩展：

| 配置 | 提示 | $\mu/\lambda$ | 精英 |
|---|---|---|---|
| L1 | refine & simplify | 4/12 | 无 |
| L2 | 生成与之前尝试都不同的新算法（random-new） | 4/12 | 无 |
| L3 | 两者兼用 | 4/12 | 无 |
| L4 | 两者兼用 | 1+1 | 有 |
| L5 | 自适应变异幅度（长尾百分比提示，引 Controlling-Mutation） | 4/12 | 无 |
| L6 | 自适应 | 1+1 | 有 |

行为指标四组：探索（NN 距离、覆盖离散度、Expl%）、利用（到 best 距离、Eplt%）、收敛（几何平均收敛率、$\Delta$fitness、成功率）、停滞（最长无改进段、最后改进位置）。

## 2. 论文宣称的机制贡献（逐项）

- L4（双意图提示 + 1+1 精英）在 AOCC 均值与稳定性上最好；测试实例上同样更稳。
- 高性能被生成算法的行为画像 = 低最近邻距离（小步长）、利用导向、相对低的探索百分比、平均离散度、低成功率（约 0.1）；逐函数画像随函数变化，但"适度探索"跨函数一致。
- 失败可归因：L2（纯新算法）低成功率 + 高停滞（过度探索无效率）；L1（纯精炼简化）风险是过早收敛。

## 3. 实验究竟支持了什么

|主张|论文证据|证据等级|判断|
|---|---|---|---|
|双意图提示 + 精英保留最好|6 配置 × 5 种子的 AOCC 与方差|直接支持|单框架单模型证据；L5/L6（自适应幅度）不如 L4，自适应幅度提示弱于显式意图二分。|
|精英选择的作用可隔离|L3 与 L4 唯一区别是选择机制，差距显著|直接支持|种群法（4/12 无精英）偶尔丢失最优算法且评价昂贵难重进化；1+1 精英保证不丢最优——"利用需有记忆保证"。|
|行为指标可诊断探索-利用状态|四组指标与性能的关联、STN（行为空间 5 维分箱的搜索轨迹网络）|部分支持|种群配置呈灌木状、1+1 呈细长链；L2 网络最大（最探索）、L4 最紧凑；行为-性能是观察性关联。|

## 4. 机制的底层逻辑（阅读分析，不是作者已证明结论）

在提示层显式分化探索/利用意图（"refine & simplify" vs "生成全新算法"），配合精英保留，是被该实验支持的平衡方案——比单一 prompt 或纯自适应幅度更稳。被生成算法的行为量（步长、探索比、无改进段）可作为运行状态的可解释诊断信号，作者建议反馈进进化循环（检测过度利用时加探索压力）。

## 5. 对 LLM4AD / TraceAAD 可学习之处

- 可学习点：被生成算法自身的求解行为（而非代码文本）作为诊断层。前提：probe 实例与轨迹记录。风险：指标采集成本。最小验证：对停滞 run 与改进 run 画行为指标轨迹，检验区分度。
- 可学习点：显式双意图提示优于自适应幅度提示的证据可作意图设计的参照。最小验证：同预算对比意图二分、幅度自适应、单一提示三档。

## 6. 证据边界

单 LLM（o4-mini）、单框架（LLaMEA）、5D BBOB、每配置 5 次运行；配置比较未报告显著性检验；行为-性能关系为观察关联。注意该文 L4 的第二提示是"生成与之前都不同的新算法"（random-new），自适应幅度提示在 L5/L6——引用时勿混。
