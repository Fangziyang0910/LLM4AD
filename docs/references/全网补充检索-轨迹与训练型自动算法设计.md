# 全网补充检索：轨迹与训练型 LLM 自动算法设计

检索日期：2026-08-08。

本文核对现有 `papers/`、[论文库文献汇总](论文库文献汇总.md)和[41 篇方法阅读笔记](LLM自动算法设计方法阅读笔记/README.md)，寻找尚未收录、且满足以下至少一项的工作：

1. 用算法设计轨迹、谱系、分支历史、跨路线记忆或执行过程指导后续设计；
2. 训练 LLM、搜索控制器、surrogate、latent model 或其他直接参与算法设计的学习组件；
3. 对 LLM 程序进化轨迹、变异收敛或状态化预算分配给出机制分析。

纳入对象必须是可复用算法、启发式、solver、程序或科学计算规则。只逐实例输出解、只训练一般推理模型、或标题中出现 trajectory 但实际指应用数据轨迹的论文不纳入核心集合。

## 核心结论

确认存在 **12 篇高优先级漏收工作**，另有 **8 篇次优先级相关工作**。其中：

- **1 篇已正式发表于主流会议**：Self-Developing，NAACL 2025 Long Paper；
- **2 篇可确认的 2026 workshop 工作**：Mutation Without Variation（GECCO 2026 LLM+EC Workshop）和 GAE（ICML 2026 AI for Science Workshop）；
- 其余核心项当前按可核实页面应视为 arXiv 预印本、OpenReview 稿件或尚未确认正式 venue 的工作，不能写成顶会论文。

## 一、高优先级：建议补入 papers 库

| 论文 | 状态 | 轨迹／训练机制 | 为什么属于缺口 | 初步证据边界 |
| --- | --- | --- | --- | --- |
| [Can Large Language Models Invent Algorithms to Improve Themselves?](https://aclanthology.org/2025.naacl-long.519/) / Self-Developing（[arXiv:2410.15639](https://arxiv.org/abs/2410.15639)） | **NAACL 2025 Long Paper** | LLM 生成可执行的模型合并算法，并用 DPO 递归更新模型与改进策略 | 是“算法发现—模型训练—继续发现”的直接闭环，也是当前最明确的顶会漏项 | 实证集中于模型合并和数学推理；不能直接外推到组合优化启发式 |
| [AlgoPilot](https://arxiv.org/abs/2501.06423) | arXiv 2025 | RL 由 Trajectory Language Model 引导；TLM 训练于随机 Python 函数产生的执行轨迹 | 同时满足轨迹建模和参数训练，并以可复用排序程序为产物 | 主要是 sorting proof-of-concept；远未证明开放式通用算法发现 |
| [LLaMEA-SAGE](https://arxiv.org/abs/2601.21511) | arXiv 2026 | 在已评价算法 archive 上训练结构—性能 surrogate，再用 XAI 生成自然语言变异反馈 | 是“历史 archive → 学习辅助模型 → 指导 LLM 变异”的直接 AAD 方法 | surrogate 关系可能是任务特有相关性；结构反馈是否跨任务迁移仍需验证 |
| [Back to the Beginning of Heuristic Design](https://arxiv.org/abs/2605.06123) | 2026 preprint / OpenReview 稿件 | 把可解释知识作为主要搜索对象，使知识跨程序、跨轨迹复用；同时实例化于种群和树搜索 | 与 TraceAAD 的“历史中保存什么”高度直接相关，且显式研究跨 trajectory 价值 | 知识文本仍可能压缩失真；需要区分知识搜索增益与额外生成预算 |
| [Latent Heuristic Search](https://arxiv.org/abs/2605.17137) | arXiv 2026 | 训练 program encoder、性能 surrogate、normalizing flow 和 soft-prompt mapper；冻结 LLM 后在连续 latent manifold 做梯度搜索 | 是不同于 DPO/GRPO 的训练路线：把离散程序搜索转成学习的连续搜索空间 | 完整训练管线组件多，结果主要是与离散基线竞争而非显著全面领先 |
| [MEMOIR: Memory-Guided Tree Search with Cross-Branch Knowledge Transfer](https://arxiv.org/abs/2605.17539) | arXiv 2026 | branch-local memory 保存单路线执行细节；global memory 在分支终止时压缩算法与失败知识，实现跨分支迁移 | 是目前最直接的“局部轨迹 + 跨轨迹记忆”solver synthesis 工作 | 摘要报告 matched execution budget，但 memory、reflection、tree policy 的独立作用仍需读全文消融 |
| [SMCEvolve](https://arxiv.org/abs/2605.15308) | arXiv 2026 | 把程序进化表述为 reward-tilted 分布上的 Sequential Monte Carlo；包含父代重采样、mutation mixture、acceptance 和自动收敛控制 | 为程序搜索轨迹与终止提供概率推断视角和有限样本复杂度分析 | 理论目标分布与真实 LLM 条件采样的匹配假设需要核对；整法结果不能替代逐组件验证 |
| [Mutation Without Variation](https://arxiv.org/abs/2606.05408) | GECCO 2026 LLM+EC Workshop / arXiv | 在无选择压力下分析 LLM mutation chains，研究结构 attractor、重复访问、自环和短周期 | 是现有机制分析清单的明确缺口：直接隔离 LLM 变异算子的内在收敛偏置 | 使用受限 DSL 且只做 genotype 分析；不能直接推出 AAD 中行为或 fitness 必然坍缩 |
| [GAE: Graph-Augmented Evolution](https://arxiv.org/abs/2607.10127) | ICML 2026 AI for Science Workshop / arXiv | 训练程序图 GNN、RL meta-controller，并在 test-time 用 GRPO 在线更新 LLM mutation operator | 同时覆盖结构化轨迹、父代／变异方向信用和在线模型训练 | 当前任务是振子符号回归，属于广义程序／科学发现，不是组合优化 AHD；三组件高度耦合 |
| [DGA²D](https://arxiv.org/abs/2608.00700) | arXiv 2026 | 有向图节点表示功能算子、walk 表示完整算法 pipeline，以 path-dependent credit 评价同一代码在不同拓扑上下文中的贡献 | 直接把算法形成路径纳入信用分配，且设计对象扩展到完整多组件算法 | 截至检索日仅提交 7 天；需重点核查 path credit 的独立消融和预算公平性 |
| [AutoSND](https://arxiv.org/abs/2608.03653) | arXiv 2026 | 三阶段树搜索：广搜并记录执行证据 → 编译成 structural policies → 带策略继续搜索 | 是“真实执行历史 → 可解释结构知识 → 后续生成”的明确实例 | 单一网络拆解领域；结构策略是否由可靠因果证据支持尚未证明 |
| [Relay, Don't Route](https://arxiv.org/abs/2608.05651) | arXiv 2026 | 先实证分析进化轨迹的 front-loaded progress 和早期预测性，再按 population handoff 而非单 query 分配强弱模型预算 | 直接研究 stateful evolutionary trajectories 与预算调度，和路线级资源分配高度相关 | training-free；截至检索日仅提交 2 天，结论需要完整设置与独立复核 |

## 二、次优先级：相关，但要明确“轨迹”或“训练”的含义

## 三、顶会完整性补漏，但不属于轨迹／训练主线

[Partition to Evolve / PartEvo](https://proceedings.neurips.cc/paper_files/paper/2025/hash/e389b15166cf98966ba058965a8c17e3-Abstract-Conference.html) 是 **NeurIPS 2025 Main Conference** 的 LLM 自动算法发现论文，当前 `papers/` 中没有独立论文目录。它用 feature-assisted niche construction 和 niche collaborative search 改进语言空间中的多样化搜索，但摘要没有模型参数训练或显式轨迹记忆，因此不列入上述核心集合。尽管如此，从“自动算法设计论文库完整性”看应当补收。

[DesignX](https://openreview.net/forum?id=FAiIRMvIwy) 是 NeurIPS 2025 的训练型自动算法设计工作，但其公开摘要描述的是 dual-agent RL 和模块化优化器空间，没有把 LLM 作为必要设计器。它属于学习式 AAD 邻域，不应混入“LLM 自动算法设计”核心集合。

现有库中的 CALM（ICLR 2026）、Fine-tuning LLM for AAD（ICLR 2026）、MCTS-AHD（ICML 2025）、HSEvo（AAAI 2025）和 EvoTune（COLM 2025）均已收录，不是本次新发现。Helix、HASE、ReMiT 等训练／自进化工作也已经出现在[论文库文献汇总](论文库文献汇总.md)，只是此前的 41 篇“直接 AAD/AHD 与广义算法发现”阅读笔记没有全部覆盖它们。

## 四、检索中排除的易混淆论文

- **TrajEvo**：设计的是人类运动 trajectory prediction heuristic；虽然是 AHD 方法，但标题中的 trajectory 是应用数据，不是算法设计轨迹。
- **KCoEvo / CODESYNC**：研究第三方 API 和代码版本迁移，不是 evaluator 驱动的自动算法设计。
- **Discovering Multiagent Learning Algorithms with LLMs**：属于广义算法发现，但摘要中的训练主要是候选 MARL 算法的评价过程，没有训练算法设计 LLM，也未显式使用设计轨迹。
- **Semantics-Aware Bilevel Co-Evolution / STABLE**：是多组件 AAD 新方法，但公开摘要没有足够证据确认 semantic model 是否通过参数训练，也没有显式轨迹机制。
- **Beyond Algorithm Evolution**：进化算法和 prompt，但属于上下文／提示共同进化，不是模型参数训练。
- **PartEvo**：是重要顶会 AAD 漏项，但不是本次“轨迹或训练”机制的直接命中。

## 六、检索来源与可复现性

### arXiv API

使用 `https://export.arxiv.org/api/query`，按 `submittedDate` 降序，单次上限 100；五个查询分别返回 27、25、10、23、18 条，共 103 条、去重后 95 篇：

1. `all:"automated algorithm design" AND (all:"large language model" OR all:LLM)`；
2. `all:"automatic heuristic design" AND (all:"large language model" OR all:LLM)`；
3. `(all:"algorithm discovery" OR all:"algorithm evolution") AND all:"language model" AND (all:"reinforcement learning" OR all:"fine-tuning" OR all:training)`；
4. `(all:"algorithm design" OR all:"heuristic design") AND all:"language model" AND (all:trajectory OR all:lineage OR all:history)`；
5. `(all:"program search" OR all:"code evolution") AND all:"language model" AND (all:trajectory OR all:training OR all:"reinforcement learning")`。

检索结果使用 paper-lookup 的 `arxiv_atom.py` 检查 error feed、解析 Atom，并去除 arXiv 版本后缀。

### OpenAlex

使用 6 个关键词组合检索 2022-01-01 至 2026-08-08 的 works，每个查询只取相关性前 100 条。OpenAlex 报告的原始命中分别为 296,078、55,448、46,539、30,494、19,542、334,266；因此这部分明确是**有界高召回筛查**，不是完整遍历。由于宽泛全文搜索噪声很高，最终候选必须回到标题和摘要人工筛选。

### Semantic Scholar

针对 trajectory、RL、fine-tuning 和 memory 的四次搜索均返回 HTTP 429；当前环境没有 `S2_API_KEY`。本次没有把失败静默解释为“无结果”，而是改用 arXiv、OpenAlex、会议官方页面和 ACL Anthology 交叉核验。

### 会议与正式页面

补查 OpenReview、NeurIPS Proceedings、PMLR／ICML、ACL Anthology 和 arXiv 原始页面。venue 判断只采用会议官方 proceedings、OpenReview 状态或 ACL Anthology；博客、聚合站和搜索摘要不用于确认录用状态。

## 七、检索边界

本次是截至 2026-08-08 的高召回、人工筛选检索，不声称数学意义上的穷尽。arXiv 精确词组查询可能漏掉标题和摘要完全不用 AAD/AHD/algorithm discovery 术语的论文；OpenAlex 只读取每个查询前 100 条；Semantic Scholar 因共享池限流没有返回数据。新增论文大多非常新，机制有效性还需要下载原文后逐篇核对方法、主实验、消融和预算，不能仅凭摘要写入已有 41 篇阅读笔记的证据统计。
