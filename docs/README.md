# 科研文档导航

本项目以 **TraceAAD（大语言模型驱动的自动算法设计）** 为主线，探索算法几何、执行轨迹引导、算子动力学与搜索调度机制。

围绕研究问题按需查阅，文档采用**科研主体垂直自闭环（Vertical Slicing）**架构，保证一事一地、自包含呈现。

## 维护原则

1. **一事一地，垂直闭环**：属于特定 TraceAAD 版本的设计与诊断归入 `01-主线版本`；属于假说验证的归入 `02-机制验证`；属于高层认知与构想的归入 `03-研究认识与构想`。杜绝建立模糊的“分析垃圾箱”。
2. **自包含与低碎片化**：每个独立专题或版本优先通过自包含 `README.md` 完整闭环呈现目标、数据与结论，杜绝无必要的“详见 xxx 文档”碎片跳转。
3. **冻结契约保障**：五任务的问题说明、模板与种子/数据配置受 `tests/task/test_frozen_task_contract.py` 严格保护，不得改动，详见[主实验配置与冻结契约](01-主线版本/主实验配置与冻结契约.md)。
