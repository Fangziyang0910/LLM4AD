## 信息流

```text
research → knowledge / methods / experiments / results
               ↘ archive
```

- 一个研究问题在同一篇笔记中维护假设、设计、观察、分析和决定。
- 稳定认识进入 `knowledge/`，采用的机制进入 `methods/`，固定协议进入 `experiments/`，完成结果进入 `results/`。
- `worklog/` 只记录时间和链接；冻结材料进入 `archive/`。
- 各处链接结论，不复制论证。
