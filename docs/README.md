# 研究记录

当前只保留三类记录：

- `ideas/`：机制思想、方法设计和完整方法设计。文件名使用简短中文主题名。
- `worklog/`：唯一的过程记录入口，按周使用 `YYYY-Www.md` 命名。`Www` 使用 ISO 8601 周编号，每周从周一到周日；例如 2026-07-14 使用 `2026-W29.md`。实验、复现、代码改动、问题发现和阶段性判断都写在对应周文件中，每项一两句话即可。
- `results/`：完成后的权威结果汇总，按方法、模型和任务组织；只有重复实验和测试评估完成后才更新。

记录规则：新的机制想法写入 `ideas/`；开展实验或完成其他工作时，在当周 `worklog/` 增加一项，写清日期、做了什么以及简短结果；最终结果再整理到 `results/`。不单独创建 `docs/experiments/`。
