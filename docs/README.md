## 文档维护

构想进入 `ideas`，版本方案进入 `methods`，具体实验的设计与结果进入 `experiments`；跨实验探索和诊断进入 `analysis`，可复用认识沉淀到 `knowledge`。文献事实放在 `references`，对外表达与过程记录分别进入 `reports` 和 `worklog`。

一次性专题使用 `YYYY-MM-DD-主题`；版本设计使用 `TraceAAD-V版本-机制设计.md`；持续维护的知识页使用稳定主题名。专题目录内部使用 `实验设计.md`、`结果.md`、`结论.md` 等简短名称。只有多份材料需要共同阅读时才建目录，不为单篇文件增加层级。

历史文档保留当时的参数和判断，其中的“当前”“必须”只适用于对应版本与任务；已被替代的构想或讨论在页首标注状态并链接后续材料。提示词原文供实验中的生成模型使用，不约束科研协作者。重要认识优先更新已有页面，不为日常讨论额外建立登记表。

部分历史文档引用的旧脚本或运行工件已不在当前工作区，保留其来源记录，不将这些链接视为当前可运行入口；实际复现入口见对应实验运行说明。
