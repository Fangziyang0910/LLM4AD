# 科研文档导航

本项目以 **TraceAAD（大语言模型驱动的自动算法设计）** 为主线，探索算法几何、执行轨迹引导、算子动力学与搜索调度机制。

文档按照科研工作流清晰分为六大板块，自明、规范、避免过度索引与脆弱嵌套。

## 规范与原则

1. **结构清晰自明**：算法机制在 `01-主线版本`，实验数据在 `02-实验结果`，假说消融在 `03-机制验证`，理论认知在 `04-研究认识与构想`。
2. **正文自包含，消除脆弱死链接**：正文聚焦研究分析与核心结论，避免到处链接过度嵌套的局部过程碎片文件。
3. **冻结契约保障**：五任务的问题说明、模板与种子/数据配置受 `tests/task/test_frozen_task_contract.py` 严格保护，不得改动，详见[主实验配置与冻结契约](02-实验结果/主实验配置与冻结契约.md)。
