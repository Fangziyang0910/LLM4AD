# RQ-003 改进历史如何进入生成与预算分配

> 状态：持续研究中。历史上下文的单步作用已完成识别；路线分配和生成意图的独立作用仍未确定。当前方法见 [TraceAAD V9.7 完整机制设计](../methods/TraceAAD-v9.7完整机制设计.md)。

## 研究问题

TraceAAD 需要分别回答两个问题：

1. 与当前程序匹配的改进历史能否改善下一次生成？
2. 在有限评价预算下，哪些程序及其历史状态值得继续？

历史上下文改变给定锚点时的生成分布；预算分配改变哪些锚点获得生成机会。联合版本的最终结果同时受二者影响，不能识别任一机制的独立贡献。

## 已获得的证据

### 1. 父代改进来时路改善单步生成

前两轮固定锚点实验共包含 864 次生成。简洁的 `Idea + Result + Fitness transition` 历史在 CVRP 上得到配对差 +1.185，95% bootstrap 区间为 [0.452, 1.941]；其余任务的区间跨 0。加入紧凑实际修改摘要后，CVRP 的额外配对差为 +0.237，区间为 [0.088, 0.409]。跨任务最稳定的行为变化是修改幅度收缩。

第三轮三臂实验包含 648 次生成。在固定当前代码和采样条件下，加入父代改进来时路后，四个任务的配对 conditional $\Delta q$ 区间均不跨 0；72 个锚点中 58 个方向更好、14 个更差。在来时路之外加入已有子代尝试没有稳定额外收益，四个任务的区间均跨 0，方向为 35 好、34 差、3 平。

这些结果为“形成历史包含当前代码之外的单步决策信息”提供直接证据。它们不检验完整搜索收益。完整协议和结果见[固定锚点单步生成识别实验](../experiments/TraceAAD-固定锚点单步生成识别实验.md)。

### 2. 历史表示会改变搜索，但净收益依赖联合系统

V9.6 修正了 V9.5 在 OP/OBP 上的历史组成失真。修正后，OP/OBP 的单步 improve rate 和搜索过程指标改善，TSP 的完整搜索结果下降，其他任务呈混合结果。第三轮固定锚点实验随后表明，TSP 上的修改收缩与单步质量改善同时发生。因此，现有证据不支持“历史导致收缩，收缩导致 TSP 退化”的直接因果链。V9.5–V9.6 的逐层分析见[证据链对比](../analysis/TraceAAD-V9.5-V9.6证据链对比.md)。

### 3. V9.7-batch 的路线级乐观项几乎没有改变预算分配

V9.5 及 V9.2–V9.4 的多数运行将至少 98% 的预算集中在单一初始谱系。V9.7-batch 将分配拆为路线层和锚点层，但共享的一步变化尺度在两层产生不同强度：12,251 次决策中，路线乐观项仅改变 32 次选择（0.26%），锚点乐观项改变 7,418 次（60.6%）。路线层的干预全部发生在各运行的前 1/3。

该结果说明该正式批次中的路线公式近似未激活。批次仍使用 V9.6 的历史上下文，因此它不评价当前 parent-path 完整协议；它也不检验路线覆盖是否有价值，或不同初始路线是否具有语义多样性。详见[V9.7 路线级分配诊断](../analysis/TraceAAD-V9.7路线级分配诊断.md)。

## 当前解释

父代改进来时路是目前证据最明确的历史成分。它提高了固定锚点上的单步质量，并减少了极端偏离。已有子代尝试只在重访锚点时存在，当前实验没有显示其常驻上下文的净收益。

路线分配需要区分两个目标：

- **路线覆盖**：为欠投入的初始来源保留有限机会；
- **延续价值**：预测哪条路线更可能在剩余预算内产生最终突破。

`best q + count bonus` 同时使用当前质量和投入次数，但没有直接估计延续价值。V9.7-batch 只说明共享尺度在该批次中没有实现实质路线覆盖，尚不支持引入更复杂的路线价值代理。

Refine/Explore 的固定混合用于区分局部细化与结构变化。V9.7-batch 同时改变路线分配和生成意图，且使用旧历史上下文；其 held-out 结果不能识别两种意图的独立作用，也不能评价当前 V9.7 完整协议。

## 待检验假设

- **H1，路线覆盖**：在相同生成协议下，为欠投入路线保留固定比例的机会能否提高 best-at-budget 和 held-out 质量。
- **H2，生成意图**：在相同锚点和历史下，Refine 与 Explore 是否产生可区分的修改幅度、有效率、严格改进率和新 best 率。
- **H3，延续价值**：锚点或路线的哪些可重复证据能够预测剩余预算内的突破，而不把事后成功谱系误作前瞻信用。

## 解释边界

三重复比较只承认方向一致且幅度明显超过运行间抖动的差距；当前 held-out 噪声底约为 2%。干预率是机制是否改变选择的过程指标，不是优化目标。不能依据目标干预率反向调节 $s$，也不能把事后计算的 $\lambda_{\mathrm{crit}}$ 直接转化为参数建议。
