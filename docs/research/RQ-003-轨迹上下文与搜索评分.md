# RQ-003 改进历史如何进入生成与预算分配

> 状态：持续研究中。当前版本 V9.7 正式批次 `20260813_184519` 运行中（规范见
> [TraceAAD V9.7 完整机制设计](../methods/TraceAAD-v9.7完整机制设计.md)）。
> 历史上下文的机制定稿见 [RQ-009](RQ-009-锚点历史上下文.md)；V9-Core 至 V9.4
> 的分配演化见 [RQ-006](RQ-006-轨迹中心预算分配.md)、[RQ-007](RQ-007-V9.2锚点与局部轨迹窗口.md)。

## 问题

真实的算法改进历史应怎样进入下一步生成，又应怎样决定下一次搜索预算投向哪里？

这是 TraceAAD 核心主张的直接承载问题。上下文传递与预算分配是两个决策：历史负责传递可追溯证据，分配负责在有限资源下选择评价落点；两者通过同一个量耦合——给定锚点与上下文的单步改进分布。

## 已确立的证据

**历史有单步生成价值，并把生成推向保守。** 两轮固定锚点配对实验（共 864 次生成）：给历史确实改变生成分布；对已积累至少两条局部证据的锚点，简洁 `Idea + Result + Fitness transition` 历史有单步质量价值（CVRP 配对差 +1.185，95% bootstrap 区间 [0.452, 1.941]，其余任务方向为正但区间跨 0，OBP 为负方向），紧凑实际改动摘要有额外信息（CVRP +0.237，区间 [0.088, 0.409]）。跨任务最稳定的行为效应是修改收缩：历史越多，模型改得越贴近当前代码。协议与完整结果见[固定锚点单步生成识别实验](../experiments/TraceAAD-固定锚点单步生成识别实验.md)（第一、二轮）。

**历史失真修正兑现，搜索收益任务分化。** V9.6 按 RQ-009 重构挑法与写法后，单步生成在失真最重的 OP/OBP 大幅改善，收益集中在 direct 稀疏锚点；编辑收缩进一步加深；搜索与最终质量 OBP 全面受益、TSP 受损。四层证据链见 [V9.5-V9.6 证据链对比](../analysis/TraceAAD-V9.5-V9.6证据链对比.md)。

**来时路是历史价值的主体。** 三臂单步实验（648 次生成）：来时路的配对收益在全部四个任务上区间不跨 0——第一个在四任务同时确立单步价值的上下文成分，且修改收缩首次与质量收益同向；子代尝试在其之上无稳定额外价值（四任务区间全部跨 0，TSP/CVRP 偏负）。见[固定锚点单步生成识别实验](../experiments/TraceAAD-固定锚点单步生成识别实验.md)（第三轮）。

**预算长期集中于单一初始路线。** V9.5 多数 run 的正式预算在生成拓扑上 Top-1 root clade 占比 ≥ 98%（[V9.5 终局复盘](../analysis/TraceAAD-V9.5终局复盘.md)），与 V9.2–V9.4 的单谱系吞噬同型；锚点级 `q + s/√(n+1)` 没有防止路线级集中的机制。

## 当前判断

历史上下文已经有效，但它把生成行为推向局部改进；锚点级分配放大这种偏向；单一 generic 指令没有把"局部精修"和"结构性探索"区分开。V9.7 据此只做两处改动：路线→锚点两级分配（同一公式先在路线层用一次，防止预算长期集中），Refine 0.7 / Explore 0.3 固定混合意图（保证结构性探索机会不消失）；历史一字不动。

意图与状态无关是有意的：单步 plateau 等切换信号已被证明不可靠（[研究认识 §4](../knowledge/研究认识.md)），状态依赖的意图选择要等"意图 × 结局"证据积累后再设计。

## 可证伪假设（V9.7 批次回答）

- **H1**：路线级乐观项能显著改变路线预算分布，使搜索不再长期锁死单一初始分支（过程证据：按路线分列的预算占比与末次刷新位置）。
- **H2**：固定保留的 Explore 意图能缓解编辑收缩的害处，尤其在 TSP 类需要结构变化的任务上（结果证据：按意图分列的编辑幅度、improve rate、新 best 产生率；held-out）。

## 判读纪律与下一步

三重复只承认大而一致的差距：三个重复同向，幅度明显超过同方法批次间抖动（held-out 约 2%）。达不到读作无信号，不据此构造任务级叙事，也不微调 0.7/0.3 或 `s` 这类常数。

批次完成后：若 H1/H2 得到大而一致的支持，下一步研究状态依赖的意图选择与跨路线知识重组；若无信号，转向预期效应量更大的设计——从轨迹在线读出任务改进几何（有效修改幅度、突破稀疏程度）并据此调整生成行为，而不是继续在固定配置内做小幅变体。
