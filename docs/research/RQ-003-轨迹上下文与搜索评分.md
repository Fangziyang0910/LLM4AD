## 问题

真实的算法改进历史应怎样进入下一步生成，又应怎样决定下一次搜索预算投向哪里？

这是 TraceAAD 核心主张的直接承载问题。上下文传递与预算分配是两个决策：历史负责传递可追溯证据，分配负责在有限资源下选择评价落点；两者通过同一个量耦合——给定锚点与上下文的单步改进分布。

## 已确立的证据

**历史有单步生成价值，并把生成推向保守。** 两轮固定锚点配对实验（共 864 次生成）：给历史确实改变生成分布；对已积累至少两条局部证据的锚点，简洁 `Idea + Result + Fitness transition` 历史有单步质量价值（CVRP 配对差 +1.185，95% bootstrap 区间 [0.452, 1.941]，其余任务方向为正但区间跨 0，OBP 为负方向），紧凑实际改动摘要有额外信息（CVRP +0.237，区间 [0.088, 0.409]）。跨任务最稳定的行为效应是修改收缩：历史越多，模型改得越贴近当前代码。协议与完整结果见[固定锚点单步生成识别实验](../experiments/TraceAAD-固定锚点单步生成识别实验.md)（第一、二轮）。

**历史失真修正兑现，搜索收益任务分化。** V9.6 按 RQ-009 重构挑法与写法后，单步生成在失真最重的 OP/OBP 大幅改善，收益集中在 direct 稀疏锚点；编辑收缩进一步加深；搜索与最终质量 OBP 全面受益、TSP 受损。四层证据链见 [V9.5-V9.6 证据链对比](../analysis/TraceAAD-V9.5-V9.6证据链对比.md)。

**来时路是历史价值的主体。** 三臂单步实验（648 次生成）：来时路的配对收益在全部四个任务上区间不跨 0——第一个在四任务同时确立单步价值的上下文成分，且修改收缩首次与质量收益同向；子代尝试在其之上无稳定额外价值（四任务区间全部跨 0，TSP/CVRP 偏负）。见[固定锚点单步生成识别实验](../experiments/TraceAAD-固定锚点单步生成识别实验.md)（第三轮）。

**预算长期集中于单一初始路线。** V9.5 多数 run 的正式预算在生成拓扑上 Top-1 root clade 占比 ≥ 98%（[V9.5 终局复盘](../analysis/TraceAAD-V9.5终局复盘.md)），与 V9.2–V9.4 的单谱系吞噬同型；锚点级 `q + s/√(n+1)` 没有防止路线级集中的机制。

**V9.7 的共享尺度没有实质激活路线层。** 对批次 `20260813_184519` 每次决策当时的 snapshot 将 optimism 置零后重放：12,251 次路线选择只有 32 次（0.26%）被 route optimism 改变，而同一 $s$ 在锚点层改变 7,418 次（60.6%）。所有路线干预都发生在各 run 的 early 三分之一，middle / late 为零。典型决策的中位 $M_t$ 为负，中位 $\lambda_{\mathrm{crit}}$ 约为当前尺度的 3–11 倍。这是“机制运行、但几乎没有改变路线选择”的过程负结果，不是两级结构错误或 coverage 无价值的证据。完整数据与可复现脚本见 [V9.7 路线级分配诊断](../analysis/TraceAAD-V9.7路线级分配诊断.md)。

## 当前判断

来时路已经证明能够提高基于当前算法进行局部决策的质量；TSP 上修改变小与单步质量变好同向发生，因此修改收缩本身不能写成缺陷。完整搜索除高质量沿路发展外，还可能需要一定比例的结构性探索。V9.7 据此改变三处：路线→锚点两级分配；Refine 0.7 / Explore 0.3 固定混合意图（高质量沿路发展 + 保留跳出当前设计的机会）；默认历史收口为父代改进来时路。Explore 不是对“历史有害收缩”的修复。

路线层现需要把两个问题分开：**coverage** 只回答是否为其他欠投入的初始来源保留少量机会；**continuation value** 回答哪条路线未来更可能产生终局突破。`best q + count bonus` 并没有解决后者。当前证据支持的是“共享单步尺度未实现 coverage”，尚不支持为路线发明更复杂的价值分数。

意图与状态无关是有意的：本版先验证显式两种修改尺度能否改变搜索行为，不加入 plateau-trigger、adaptive intent 或 operator credit。单步 plateau 等切换信号已被证明不可靠（[研究认识 §4](../knowledge/研究认识.md)），状态依赖的意图选择要等"意图 × 结局"证据积累后再设计。

## 可证伪假设（V9.7 批次回答）

- **H1（过程层已回答：负结果）**：路线级乐观项未显著改变预算在不同初始来源之间的分布；0.26% 的 intervention rate 与 TSP/CVRP/OP 的 99.2%–100% Top-1 route share 表明当前实现基本未触及路线 coverage。这不解释为算法多样性未提高，也不能由此判断 hard route gate 的质量效果。
- **H2（尚未独立回答）**：显式区分 Refine / Explore 两种修改尺度能否改变搜索行为，仍需按意图分列编辑幅度、improve rate 与新 best 产生率。held-out 已完成，但联合版本结果不能识别该机制的独立贡献。该假设不把历史收缩写成已证实的损害。

## 判读纪律与下一步

三重复只承认大而一致的差距：三个重复同向，幅度明显超过同方法批次间抖动（held-out 约 2%）。达不到读作无信号，不据此构造任务级叙事，也不微调 0.7/0.3 或 `s` 这类常数。

对当前路线公式，不根据目标 intervention rate 调大 $s$，也不把 $\lambda_{\mathrm{crit}}$ 的事后分布直接变成下一版乘数。若后续研究仍要检验 route monopoly 是否需要干预，下一个可验证的 coverage 基线是显式固定的 route exploitation / coverage mixture：大部分选当前最强路线，少部分选投入最少的路线。它只检验 coverage 是否有价值，不伪称估计 continuation value；本轮不把这一假设实现进 V9.7。正式 held-out 已完成：联合版本在 TSP 改善、CVRP 无信号、OP 相对 V9 退化，OBP 差异主要在噪声底附近，没有形成跨任务大而一致的统一升级；H2 的独立过程贡献仍待分析。
