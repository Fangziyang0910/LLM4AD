# TraceAAD 研究问题

TraceAAD 的两个核心研究对象是：

- **轨迹条件生成** $P(x_{t+1}\mid x_t,h_t,o_t)$：轨迹上下文和搜索意图如何改变 LLM 在算法空间中的下一步提议。
- **轨迹感知的计算分配** $\mu(a_t\mid\mathcal H_t)$：有限预算下，下一份计算投给哪条路线、哪个历史状态。

二者实验上拆开、理论上耦合。有效分配建立在提议异质性上；好的跨族提议若不被维持，会被调度浪费。当前判断见[研究认识](../knowledge/研究认识.md)。方法规范见 [V9.7](../methods/TraceAAD-v9.7完整机制设计.md)。

控制层次是这两个对象的操作分解，不是第三套科学问题。层次顺序是运行顺序，不是研究优先级。下一步分析应先读出四任务的算法簇结构、路线异质性和提议不对称，再决定预算该分配什么。

## 层次

| 层次 | 服务哪个对象 | 当前状态 |
| --- | --- | --- |
| [L0 状态表示](L0-状态表示.md) | 两个对象的共同状态 | 程序 / 锚点 / 路线已固定；算法簇仍是诊断概念，不是在线对象 |
| [L1 初始化](L1-初始化.md) | 分配的投资单位 | 代码互异不等于簇互异；尚无独立实验 |
| [L2 预算分配](L2-预算分配.md) | 轨迹感知分配 | 路线层近似未激活；先问路线是不是投资单位 |
| [L3 单步生成](L3-单步生成.md) | 轨迹条件生成 | 来时路改变 $P(x'\mid x)$ 已有单步证据；跨族跃迁未测 |
| [L4 诊断](L4-诊断.md) | 任务几何与成本 | 好簇稀有度、族内可改进性、簇间方差待读出 |

## 开放问题

1. 现有路线到底是不是有意义的投资单位。
2. 来时路的完整搜索净贡献；Refine/Explore 是否提高跨族跃迁及随后的更好盆地概率。
3. 四个任务的簇稀有度、族内可改进性、簇间质量方差能否解释结果反差。
4. 在确认异质性之后，哪些证据能预测延续价值。
