# TraceAAD v4–v6 轨迹过程分析

日期：2026-08-02
状态：首轮过程分析；用于支撑 [RQ-005 LLM 局部改进与受控多样性](RQ-005-LLM局部改进与受控多样性.md) 的量化。

分析脚本：[experiments/analysis/analyze_traceaad_process.py](../../experiments/analysis/analyze_traceaad_process.py)
原始数据：36 个已完成 run（4 任务 × 3 版本 × 3 重复），见 `docs/research/traceaad_v4-v6_analysis/run_metrics.csv`。

## 一、现在能做什么、不能做什么

基于现有日志，**已经可以离线完成**：轨迹重建、样本级全局 best-so-far 严格突破统计、算子级局部精炼率（LRR）与父子距离（PCD）、代码距离新颖性、窗口级语义几何（空间熵/适应度熵）、窗口级回归、版本×任务聚合与绘图。本文档即修正统计口径后的首轮结果。

**暂时不能完成**：零样本能力对照（需要新的多温度采样）、温度敏感性实验（需要新 run）、论文口径的行为/嵌入语义距离（需要评估器或嵌入 API）、真正“代内种群分布”熵（日志没有保存每迭代的 active pool 快照，只有被接受节点）。

## 二、数据与口径

- 36 个 run：`tsp_construct`、`cvrp_aco`、`op_aco`、`online_bin_packing` × `version4/version5/version6` × 3 重复，全部 1000 次评估、状态 `finished`。
- 模型统一为 Qwen3.6-27B（NVFP4），temperature 1.0；同任务内评估配置一致（task_eval 字段相同），可视为受控的方法版本对比。
- 事件流：`method_events.jsonl` 提供 `program_evaluated`、`best_updated`、`child_accepted`、`operator_batch`、`trajectory_selection`、`population_management`；`samples/samples_*.json` 提供程序代码与分数。
- 节点—样本映射：v5/v6 用 `code_hash`（与样本程序逐一对上）；v4 用 `profiler_sample_order` 对应 `sample_order`（已验证），init 节点按成功样本顺序对应。

## 三、指标定义与代理假设

对照 [LLM优化器轨迹分析](../references/LLM优化器轨迹分析.md) 中的方法，逐项落地如下：

| 论文分析 | 本分析的落地方式 | 代理/差异 |
| --- | --- | --- |
| 突破率 | 按样本顺序重建全局 best-so-far，仅计分数严格超过历史最优的样本；首个有效样本不算突破 | 论文按代（10 offspring）计；本分析窗口=10 次评估，窗口突破率是“窗口内至少一次严格突破”的比例 |
| 局部精炼率 LRR | 被接受边中 `child.score > parent.score` 的比例 | 只覆盖被接受子代，失败的尝试未完整记录 |
| 父子距离 PCD | 子代与父代代码的 token Jaccard 距离（`1 - code_similarity`） | 代码距离是语义距离的代理，非行为/嵌入距离 |
| 新颖性 | 候选相对全部先前候选的最近代码距离，逐 run min-max 归一化 | 同上 |
| 空间熵/适应度熵 | 10 样本窗口内高斯核熵（均匀权重 / 适应度权重） | 窗口内节点数约 8–10，熵接近上界，区分度有限 |
| 代级混合效应 | 窗口级 OLS + 任务/版本固定效应 + run 聚类稳健标准误 | 论文用 GLMM（模型随机截距）；本分析用 LPM 近似，且“代”是窗口代理 |

所有过程指标均从现有日志事后计算，不改变任何运行。

## 四、结果

### 4.1 最终性能与突破统计

版本内任务均值（mean ± std，3 重复）：

| 任务 | version4 best | version5 best | version6 best | v4 BR | v5 BR | v6 BR |
| --- | --- | --- | --- | --- | --- | --- |
| cvrp_aco | -8.665 ± 0.064 | -8.717 ± 0.084 | -8.673 ± 0.096 | 0.183 | **0.200** | 0.197 |
| online_bin_packing | **-725.0 ± 1.7** | -733.3 ± 9.2 | -729.6 ± 7.8 | **0.113** | 0.067 | 0.073 |
| op_aco | 14.882 ± 0.066 | **14.896 ± 0.066** | 14.691 ± 0.204 | 0.147 | **0.153** | 0.113 |
| tsp_construct | **-5.976 ± 0.061** | -6.058 ± 0.059 | -5.980 ± 0.081 | **0.220** | 0.183 | 0.197 |

严格突破样本数（10 样本窗口突破率）：v4 平均 19.3（0.166），v5 18.2（0.151），v6 16.7（0.145）。作为日志审计，`best_updated` 中的等分更短代码事件另行计数：v4 0，v5 12.1/run，v6 5.4/run；它们不是适应度突破。

把最终分数按任务内归一化（z-score）后，版本均值：**v4 +0.44σ，v5 -0.33σ，v6 -0.11σ**。v4 同时拥有最高的严格突破率和最好的平均最终性能；v5 之前看似“突破更多”，是因为把等分简化也当成了突破。修正后的方向与论文的跨模型结论一致，但 36 个 run 不足以证明版本间的因果关系。

突破时机：v4 平均出现在窗口 31.8（82% 在前半程），v5 窗口 38.9（64% 在前半程），v6 窗口 35.7（73%）。v5/v6 的改进更多地延伸到后半程，但首次严格突破也更晚：v4/v5/v6 平均位于窗口 2.9/10.5/9.6。

### 4.2 算子级：LRR / PCD / 结果构成

| 指标 | version4 | version5 | version6 |
| --- | --- | --- | --- |
| LRR（严格优于父代的被接受子代占比） | 0.116 ± 0.032 | **0.136** ± 0.048 | 0.104 ± 0.035 |
| PCD（父子代码距离均值） | 0.086 ± 0.018 | 0.085 ± 0.035 | **0.151** ± 0.044 |
| improve 占比 | 11.6% | 13.6% | 10.3% |
| plateau 占比 | 20.1% | 24.8% | 15.6% |
| regress 占比 | 68.4% | 61.6% | **74.0%** |
| 算子构成 | ideate 49.6% / refine 50.4% | 四算子约各 25% | ideate 42.6% / refine 43.6% / synthesize 6.5% / transfer 7.3% |

v6 的特点是语义步长（PCD）显著大于 v4/v5（约 1.8 倍），同时 LRR 最低、regress 占比最高。这与论文“较大语义修改的负面效应主要由精炼可靠性解释”的方向一致。注意 v6 的双轨迹算子（synthesize/transfer）只占约 14%，步长增大主要来自 v6 的 ideate/refine 行为，不能归因于双轨迹算子。

### 4.3 新颖性与语义几何

| 指标 | version4 | version5 | version6 |
| --- | --- | --- | --- |
| 平均新颖性（归一化代码距离） | 0.081 ± 0.015 | 0.058 ± 0.027 | **0.107** ± 0.040 |
| 初始种群新颖性 | 0.284 ± 0.054 | 0.273 ± 0.054 | 0.278 ± 0.063 |
| 窗口空间熵 H_spatial | 2.229 ± 0.029 | **2.131** ± 0.149 | 2.210 ± 0.042 |
| 窗口适应度熵 H_fitness | 2.228 ± 0.029 | 2.129 ± 0.150 | 2.209 ± 0.042 |

v6 新颖性最高、局部精炼率最低；v5 代码空间最“集中”（H_spatial 最低）但最终性能仍低于 v4。H_fitness 与 H_spatial 几乎相同，说明窗口内高质量候选的分布与全体候选没有明显差别（也与窗口熵接近上界有关）。

曲线图：`traceaad_v4-v6_analysis/fig_best_sofar.png`（各任务 best-so-far 曲线）、`fig_h_spatial.png`（局部化动态）。

### 4.4 窗口级回归（并发 + 滞后）

因变量：窗口内是否发生突破；自变量：平均新颖性、H_spatial、H_fitness、窗口索引、新颖性×H_spatial 交互、任务与版本固定效应；标准误按 run 聚类（36 聚类）。并发 N=3600，滞后 N=3564。

| 变量 | 并发 coef | 并发 p | 滞后 coef | 滞后 p |
| --- | --- | --- | --- | --- |
| 窗口索引 | **-0.072** | <0.001 | **-0.067** | <0.001 |
| version5（相对 v4） | -0.000 | 0.986 | -0.013 | 0.474 |
| version6（相对 v4） | -0.027 | 0.067 | -0.028 | 0.055 |
| 平均新颖性 | **+0.020** | 0.033 | +0.016 | 0.138 |
| H_spatial | -0.230 | 0.208 | -0.012 | 0.949 |
| H_fitness | +0.246 | 0.179 | +0.007 | 0.972 |
| 新颖性 × H_spatial | +0.007 | 0.222 | +0.001 | 0.858 |

R²：并发 0.071，滞后 0.059。**论文的“新颖性×空间熵”负交互在 TraceAAD 窗口口径下未复现**；稳健模式是突破集中在早期。并发窗口中新颖性为弱正相关，滞后后不显著；修正口径后 v5/v6 相对 v4 都没有显著更高的突破概率。该结果不能作为论文机制在 TraceAAD 成立的证据，也不能作为反证（代理与窗口口径差异太大）。

### 4.5 run 级相关（任务内归一化）

36 个 run 按任务内 z-score 后与描述子的相关系数：突破率 +0.37、LRR +0.31、H_spatial +0.23、平均新颖性 +0.18、PCD +0.09。分任务看方向不一致：OBP 中突破率/LRR/PCD/新颖性均与最终性能较强正相关（r 0.62–0.79），OP 中 PCD/新颖性负相关（r ≈ -0.4）。包含任务和版本固定效应的 run 级回归中，突破率的系数为 +0.325（p=0.086），样本量不足以得出稳健因果结论。

## 五、对机制改进的观察与假设

以下“观察”是本节直接可复核的事实；“假设”是需要进一步实验验证的推断。

- 观察 1：v4 的严格突破率和最终性能都最高；v5 额外的 `best_updated` 主要来自等分简化，不是适应度突破。
- 观察 2：v6 步长最大、精炼可靠性最低、regress 最多，最终性能与 v4 持平或更差。步长增大没有带来收益。
- 观察 3：三个版本突破都集中在搜索早期；后半程改进停滞是共同模式。
- 观察 4：v5/v6 的首次严格突破明显晚于 v4，同时后半程突破占比更高；这是“启动慢、后程仍有少量进展”，不能解读为更有效。
- 假设 B（待验证）：v6 更大的语义步长是 ideate/refine 本身更激进造成的，降低父代精炼可靠性；双轨迹算子占比低，不能解释。验证方法：按算子分组重算 LRR/PCD（本分析已保存 edge 表，可直接分组）。
- 假设 C（待验证）：论文的“局部化条件下新颖性才有生产力”需要真正的代内种群快照才能检验；当前窗口口径无效。验证方法：日志补充 active pool 快照后重算熵与交互。

## 六、局限与下一步

局限：

- 语义距离是代码 token Jaccard 代理，未用行为距离或嵌入距离；
- 窗口=10 次评估不等价于论文的“代”，且窗口内节点少、熵接近上界；
- LRR 只统计被接受子代；
- 每版本只有 3 重复，回归功效有限；版本间比较受机制差异影响，不能与论文的 15 模型横评直接对比；
- v4 的 `llm_calls` 在 cvrp/tsp 部分 run 明显偏低（疑似缓存/计数口径差异），未用于效率比较。

下一步（按成本从低到高）：

1. 用当前的严格突破口径评估 2026-08-02 启动的 V6 局部精炼修订批次，对比突破率、LRR、PCD、回退率与强制精简触发频率；
2. 对 TSP/CVRP 实现论文口径的边集合/行为距离，替换代码距离代理，重跑新颖性与熵；
3. 为后续 run 增加 active pool 快照日志（每迭代的轨迹端点程序与分数），才能做真正的代级语义几何与混合效应；
4. 需要时补零样本基线与温度敏感性实验，补全论文对照。
