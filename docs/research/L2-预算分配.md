# L2 预算分配

> 层次：分配。对应核心对象：轨迹感知的计算分配 $\mu(a_t\mid\mathcal H_t)$。状态：持续。入口见 [README](README.md)。历史记录：[RQ-006](RQ-006-轨迹中心预算分配.md)、[RQ-007](RQ-007-V9.2锚点与局部轨迹窗口.md)。

## 当前判断

预算分配不改变给定锚点时会生成什么，只决定哪些 transition process 被启动、被观测并获得继续展开的计算。它至少包含 discovery-source selection、已有投资单位间的 development allocation，以及单位内部的 anchor selection。V9.7 把前两者折叠进已选 route/anchor；V9.8 才把 discovery source 与 development lane 显式分开。

正统 V9.7 的路线乐观项几乎不改写选择。进一步重放表明，现行分数具有不可恢复淘汰：若欠投入路线满足 $q^*(r)+s/\sqrt{N(r)+1}<\max_j q^*(j)$，它无法入选，也就无法更新自己。CVRP/OP 在第 1–2 次正式生成、TSP 最迟在第 40 次进入单路线吸收态。现有 route 只表示 provenance，被放弃路线又缺少可比较续段。BaSE 提供外部分配对照，但它的固定 trajectory arm 不直接对应 TraceAAD 的动态分支。

[V9.8 设计稿](../methods/TraceAAD-v9.8完整机制设计.md)据此采用 Explore-initiated development episode 作为操作性 hypothesis：Explore 创建新投资单位，先给予三次可内部重选锚点的 Refine probe；后续预算拆成 fixed discovery、recent-realized-gain continuation 和当前最好 exploitation。没有 ticket 时回退 exploitation，不设置 least-developed coverage。`1+3+2+2` 与 global-best discovery source 都是待验证 allocation prior。当前 continuation 是 development momentum allocator，不估计额外计算的长期边际价值；V9.8 的作用之一是主动积累等长 continuation observations，为后续估计建立数据条件。

## 现行协议

从哪里继续拆成两步：先选路线，再在该路线内选锚点。两层同形，质量对象和计数不同：

$$
S_t^{\mathrm{route}}(r)=q^*(r)+\frac{s}{\sqrt{N_t(r)+1}},\qquad
S_t^{\mathrm{anchor}}(a)=q(a)+\frac{s}{\sqrt{n_t(a)+1}}.
$$

$s$ 来自 [L1](L1-初始化.md)，正式搜索中不再更新。分数只使用已经达到的质量和已投入次数，不估计这条路线还有没有继续突破的可能。规范见 [V9.7 §4](../methods/TraceAAD-v9.7完整机制设计.md)。

## 已获得的证据

V9 起多数运行把至少约 98% 的预算集中在单一初始谱系。V9.1 用路线推进率做信用，偏爱低质量路线的局部恢复，自 V9.2 放弃。这些是历史诊断，见 RQ-006、RQ-007 与[版本谱系](../analysis/TraceAAD-版本实验事实与机制诊断.md)。

V9.7 把分配拆成路线层和锚点层后，两层强度不对称。正统批次 12,152 次决策中，路线乐观项改变 130 次（1.07%），锚点乐观项改变 7,877 次（64.8%）；路线干预全部发生在前 1/3。TSP/CVRP/OP 的顶路线份额为 99.4%–100%，OBP 为 85.9%–98.0%。96 条路线中有 64 条在 bootstrap 后没有任何正式生成；根到最终最好程序有 9/12 次改变静态机制宏簇，说明 route 是来源单位而非稳定 family。吸收态、路线异质性与右删失见[搜索几何诊断](../analysis/TraceAAD-V9.7搜索几何诊断.md)；早期 bonus 重放见[路线级分配诊断](../analysis/TraceAAD-V9.7路线级分配诊断.md)。

该过程负结果至少对应三种尚未分开的情况：路线确实异质且集中可能正确；八个根没有簇级差异，分配器无臂可分；有潜力差异但 $q^*$ 加访问补偿看不见延续价值。详见[研究认识 2.5](../knowledge/研究认识.md)。

## 待检验假设

- **投资单位**：现有四任务上，路线之间是否存在可利用的簇级或质量异质性。没有异质性，则覆盖实验没有对象。
- **最小观测机会**：仅当 hypothesis 是可利用投资单位时，Discovery 后的固定 probe 能否减少右删失并提高 best-at-budget；probe 后的访问不足本身不构成继续投资理由。
- **Discovery source**：global-best source 是否统一了实现基线却阻断多跳可达性；与 hypothesis-uniform、continuation-leader source 相比怎样改变发现森林。
- **延续信号**：recent realized development gain 能否支持一次额外 block；absolute gain 是否偏爱低质量、容易进步的 episode。
- **边际计算价值**：等长 continuation observations 积累后，哪些历史量能预测未来固定 horizon 的前沿增益或突破概率；当前 $g_j$ 不作为无偏估计。
- **Structured schedule**：`1+3+2+2` 的固定比例及 continuation/exploitation 配额是否稳健；它是可识别基线，不是最终 allocation solution。
- **局部截断**：hypothesis 内 $q+s_R/\sqrt{n_R+1}$ 是否让有延迟价值的 Refine regress child 得不到下一步。

成功 Explore 才触发 probe，因此名义 schedule 不等于实际计算份额。正式诊断必须把初始化单列，并同时报告 post-initialization 的 effective discovery-development response share、evaluator share、Explore validity 和 hypothesis creation rate。

干预率是过程指标，不能当成反向调 $s$ 的目标。分配消融必须固定 [L3](L3-单步生成.md) 的历史与意图。有效分配还依赖提议异质性：生成侧若不能制造可区分的簇，分配侧没有杠杆。
