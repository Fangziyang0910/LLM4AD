# 研究认识

本文件记录研究交流中形成的灵感、观点、经验和机制认识，作为持续生长的研究知识库。

- 新认识随讨论逐条写入，每条保持一两句话；前期不预设分类，让思维先自然迸发和积累，内容丰富后再归类整理。
- 只记录对后续研究具有复用价值的认识，不记录普通对话、临时任务、具体工作过程、实验配置或最终结果。
- 新认识修正已有观点时，直接修改原条目，保持文档呈现当前认识；观点的演变过程由 Git 历史保留。
- 尚未得到充分证据的研究判断标记为 `[待验证]`。
- 当一条认识发展为完整机制或方法设计时，将详细论述写入 `docs/ideas/`，本文件保留凝练结论。

- 最大化任务的评估必须返回正目标值（或与 profiler 的“更高更好”一致）；KP 曾误返回负平均价值，会把搜索推向更差启发式。
