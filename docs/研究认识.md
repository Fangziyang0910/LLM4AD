# 研究认识

本文记录研究过程中逐步形成的研究定位、问题认识与科学假设，并随着理论分析和实验结果持续修正。

## 研究定位：面向通用智能优化

研究主线是通用智能优化，涵盖优化问题建模、自动算法选择、自动参数设置和自动算法设计。当前工作聚焦大模型驱动的自动算法设计（LLM-AAD），希望利用大模型的生成能力与通用知识，提高算法设计与改进的自动化程度。

当前代表性 LLM-AAD 路线通常将 LLM 嵌入进化搜索过程，把算法代码视为个体，由 LLM 生成新的算法方案，再由搜索机制评估、筛选和持续改进。EoH、ReEvo、MCTS-AHD 等工作体现了这一基本范式：LLM 提供算法知识和生成能力，进化机制提供通过反馈不断改进个体的过程。

## 核心问题：算法设计与改进如何发生

本研究关注的核心科学问题是算法设计与改进的底层逻辑，以及如何据此构造能够学习通用算法设计模式的奖励信号。搜索得到更好的算法是检验这一认识的实验结果，搜索过程中呈现出的思想演化、成败原因和决策规律则是需要理解和学习的主要对象。

算法改进是一个连续过程。设计者从当前方案出发，逐步引入、修改或组合算法思想，再根据评估结果延续有效方向、修复失败尝试或切换路线。当前算法及其来时路共同描述决策状态，引入或修改算法思想构成 action，评估反馈形成状态转移的结果。一个 action 除了产生当前一步的效果，还可能改变后续可行的改进方向，因此具有跨步骤的延迟影响。

## 轨迹：连接搜索与学习

算法改进轨迹记录当前方案如何形成，包括每一步从什么算法出发、引入了什么思想、产生了什么结果，以及后续如何延续、回退、修复或重组。轨迹使搜索能够利用成功尝试、失败边界、停滞位置和仍可发展的方向来决定下一步行动。

轨迹同时是搜索与学习之间的桥梁。搜索机制利用已有轨迹选择下一条改进路线和 action，并在执行过程中产生带有逐步反馈和长期结果的新轨迹；学习机制从这些轨迹中进行多步信用分配，识别哪些 action 在什么状态下有效，以及早期思想怎样影响后续决策。

搜索机制与学习机制需要协同设计。搜索策略决定能够观察到哪些状态、action 和反馈，从而决定训练数据的分布与质量；学习得到的策略又会改变后续搜索的探索方向。两者共同构成持续生成经验、学习规律并改进搜索行为的闭环。

## 总体研究路线：从轨迹搜索到策略学习

总体思路是将算法设计理解为围绕算法思想展开的多步决策过程：先证明改进轨迹能够为下一步决策提供额外价值，再从轨迹中抽象长期信用信号，最后通过强化学习训练模型，使其学习具有迁移能力的算法设计策略。

### 第一阶段：构建基于轨迹的算法设计机制

TraceAAD 将算法改进轨迹作为路线选择和生成上下文，研究在当前算法相同的条件下，看到它的来时路能否帮助模型作出更好的下一步决策。轨迹提供已经引入的思想、有效修改、失败边界、停滞位置和可继续发展的方向；这一阶段需要通过受控消融检验轨迹信息能否提高下一步改进成功率、搜索样本效率和最终算法质量，并积累结构化的算法改进过程数据。

第一阶段应让轨迹历史保持为清晰的主要实验变量，避免同时叠加多套历史加工、复杂调度和额外优化目标。辅助机制只有在核心轨迹价值获得证据后再逐项引入和消融，才能明确性能变化来自什么。

科研代码的简洁性应针对搜索机制，而不应削弱长实验的基本可靠性。checkpoint 和断点恢复不参与算法决策，却能避免运行中断造成搜索状态与评估预算丢失，因此应作为独立于科学机制的最小实验保障保留。

### 第二阶段：构造可学习的多步决策信号

在搜索产生的轨迹上，把算法改进形式化为序列决策过程：任务、当前算法及其来时路构成状态，引入或修改算法思想构成 action，代码生成与评估形成状态转移。单步性能变化提供即时奖励，一个 action 对后续改进方向和最终结果的影响形成长期回报与信用；学习目标是估计某个算法设计 action 在给定状态下的长期价值。

搜索机制与信号设计需要协同迭代。搜索策略决定能够观察到哪些状态、action 和反馈，信号设计则要求搜索过程保留足以分析即时结果和延迟影响的轨迹结构。两者共同决定训练数据的覆盖范围、因果清晰度和学习价值。

### 第三阶段：强化学习算法设计策略

在轨迹结构和多步信用信号得到验证后，使用强化学习训练模型，使其根据任务、当前算法和改进历史选择下一步算法设计 action。目标是让模型减少重复和破坏性修改，更稳定地提出有效思想，并学习能够跨实例、跨任务迁移的算法设计模式。

三个阶段在研究叙事上依次推进为“轨迹搜索 → 轨迹信用 → 强化学习”，在实际研究中则表现为“轨迹搜索 ↔ 信号设计 → 强化学习”：前两个阶段反复协同修正，第三阶段建立在可靠轨迹数据和有效信用信号之上。

## 待验证的研究假设

**轨迹信息的搜索价值。** `[待验证]` 现有代表性 LLM-AAD 方法尚未系统地把完整算法改进轨迹同时作为生成上下文和学习对象。TraceAAD 需要通过过程分析与消融实验验证，完整来时路是否比当前程序、精英集合或局部父子关系提供更多有效决策信息。

**轨迹信号的学习价值。** `[待验证]` 相比 CALM 等基于正负样本对的 DPO 或组内优劣信号的 GRPO 路线，轨迹级强化学习有望同时利用 action 的即时结果、后续影响和跨步依赖，形成更贴近算法改进过程的奖励与信用分配信号。这一优势需要通过严格的学习基线、过程消融和跨任务泛化实验验证。

**算法设计策略的可学习性。** `[待验证]` 模型能够从跨轨迹的长期信用中学习具有迁移能力的算法设计模式，在相同数据、模型和训练预算下，比只利用局部或终局优劣信号的训练方法作出更有效的多步改进决策。
