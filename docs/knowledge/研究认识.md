# TraceAAD 研究认识

> 本文只保留跨版本可复用、且由现有证据支持的当前判断。两个核心对象是轨迹条件生成与轨迹感知的计算分配。当前可运行规范见 [TraceAAD V9.7](../methods/TraceAAD-v9.7完整机制设计.md)；[V9.8](../methods/TraceAAD-v9.8完整机制设计.md) 是尚未实现的机制设计稿，不构成新实验事实。正式结果以[实验总汇](../experiments/实验总汇.md)为准。研究问题入口见 [research 索引](../research/README.md)。

## 1. 当前证据

### 1.1 父代改进来时路具有单步生成价值

三轮固定锚点实验共完成 1,512 次生成与评价。第三轮固定当前代码、任务、输出契约和采样条件，覆盖 4 个任务、72 个锚点、3 个上下文臂和每臂 3 次重复，共 648 次生成。

- 加入父代改进来时路后，四个任务的配对 conditional $\Delta q$ 区间均不跨 0；72 个锚点中 58 个方向更好、14 个更差。
- 在来时路之外加入已有子代尝试，没有显示稳定额外价值；四个任务的区间均跨 0，方向为 35 好、34 差、3 平。
- 来时路使修改幅度收缩，并减少最差十分位的大幅改写；这一变化与单步质量改善同时出现，不能写成已证实的损害。

因此，当前默认生成上下文是“当前完整算法 + 与该锚点匹配的父代改进来时路”。已有子代尝试继续作为搜索事实保存，但不常驻默认提示。该结论只识别给定锚点时的单步作用，不能直接推出完整搜索或 held-out 收益。完整证据见[固定锚点单步生成识别实验](../experiments/TraceAAD-固定锚点单步生成识别实验.md)。

### 1.2 完整版本没有形成跨任务统一升级

正式比较使用 Qwen3.6-27B、每次运行 1000 次真实评价、每个方法每任务 3 次独立搜索，并在 4 个任务的 15 个测试设置上进行 held-out 评价。

代表性同场只放入 V8、V9、正统 V9.7 与 5 个外部对照，共 8 方法；描述性平均名次为 TraceAAD V9.7 2.900、TraceAAD V9 3.333、TraceAAD V8 3.467、MCTS-AHD 3.733。单版本上场为 1 个 TraceAAD 与 5 个外部对照共 6 方法；V9、V5、V9.7、V8.2、V8 的平均名次分别为 2.067、2.133、2.200、2.367、2.433。

这些排名用于压缩跨设置结果，不代表统计显著性。正统 V9.7 是父代来时路完整协议（批次 `20260814_150927`），四任务三重复已齐并进入代表性同场。V9.7-batch 在来时路实验收口前启动，仍使用 V9.6 的 `formation + direct attempts` 上下文，只留在任务页。正统 V9.7 相对 V9.7-batch：TSP 0.08%/0.08%/0.56%，CVRP −2.0%/−2.8%/−2.9%，OP +0.03%/−0.65%/−2.6%，OBP 六档均在 1% 以内。TSP 相对 V9.6 约 4% 的三规模改善与 V9.7-batch 同向，因此不能把该跳变归因于去掉子代尝试。CVRP50 的列最佳仍是 V8；CVRP100/200 的列最佳是正统 V9.7。V9.7-batch 也不是对 V9 或 V9.6 的跨任务统一升级。V9.5 只有 10/12 个计划运行完成，不进入正式排名。完整版本同时改变多个机制，其结果只能评价联合系统，不能归因到单一组件。过程拆解见[V9.7 机制有效性与任务异质性](../analysis/TraceAAD-V9.7机制有效性与任务异质性.md)。

### 1.3 两级分配在正统协议上仍然几乎不改变路线选择

V9.7-batch 与正统 V9.7 都把预算分成路线层和锚点层，并在两层共享初始化一步变化尺度。正统批次 12,152 次决策中，路线乐观项改变 130 次（1.07%），锚点乐观项改变 7,877 次（64.8%）；路线干预仍全部发生在前 1/3。TSP/CVRP/OP 的顶路线份额为 99.4%–100%，OBP 为 85.9%–98.0%。batch 上相应数字为路线 0.26%、锚点 60.6%。

这是“机制运行但在路线层近似未激活”的过程负结果。进一步重放显示现行分数有不可恢复淘汰：CVRP/OP 在第 1–2 次正式生成、TSP 最迟第 40 次进入单路线吸收态；96 条路线中有 64 条没有 bootstrap 后续段。它仍不证明路线覆盖无价值，也不否定两级结构，因为被放弃路线的 continuation value 没有被观测。干预率是诊断量，不是应反向调参追求的目标。详见[V9.7 搜索几何诊断](../analysis/TraceAAD-V9.7搜索几何诊断.md)、[路线级分配诊断](../analysis/TraceAAD-V9.7路线级分配诊断.md)与[机制有效性分析](../analysis/TraceAAD-V9.7机制有效性与任务异质性.md)。

### 1.4 评价预算与生成成本必须分开

1000 eval 只统一真实 evaluator 调用。解析失败、重复、缓存命中和模型调用方式会使 LLM 调用数、token 数和墙钟成本不同。正式性能比较、生成成本和搜索过程回答不同问题，不能相互替代。

## 2. 方法认识

### 2.1 两个核心研究对象

AAD 不是在平滑、同质的程序空间里做黑盒优化。更合理的抽象是：搜索空间由若干潜在算法簇构成；不同簇有不同的性能上限和局部可改进性，LLM 迁入各簇的概率高度不均匀。[待验证]

TraceAAD 因此只保留两个核心科学问题：

- **轨迹条件生成**（[L3](../research/L3-单步生成.md)）：给定当前算法 $x_t$、轨迹上下文 $h_t$ 和生成意图 $o_t$，如何改善下一步提议分布 $P(x_{t+1}\mid x_t,h_t,o_t)$，使搜索既能在族内 refinement，也能跨族 exploration。
- **轨迹感知的计算分配**（[L2](../research/L2-预算分配.md)）：面对当前路线、锚点和搜索历史 $\mathcal H_t$，如何把有限预算投到 $\mu(a_t\mid\mathcal H_t)$，在寻找算法簇、开发已有簇、以及不同潜力状态之间配置计算。

生成机制决定 transition kernel：哪些新算法及算法簇可达、以多大概率可达。预算分配决定这些潜在能力在有限预算下有多大概率被兑现。渐近上限主要由模型、提示、算子和评价反馈决定；有限预算可达前沿由生成与分配共同决定。不要把二者写成简单的上限 / 下限。

BaSE 的真正启发不是“应该上 bandit”，而是迫使我们把搜索空间看成异质算法簇，并把深度—广度权衡读成：花多少预算找正确的族，又花多少预算在已找到的族内部开发。它只解决轨迹投资，不建模轨迹内容。外部证据见 [BaSE 笔记](../references/LLM自动算法设计方法阅读笔记/28-Compute-Allocation-BaSE.md)。

操作上，每次评价仍回答三个问题：从哪里继续，怎样走到这里，这次怎样改。前一个属于分配，后两个属于生成。初始化划定最初可分开投入的起点；V9.7 还从 bootstrap 估计共享尺度 $s$，V9.8 设计不再跨 hypothesis 共享该尺度。树、信用和记忆是支撑机制。问题按层次存放，见 [research 索引](../research/README.md)。

### 2.2 实验上拆开，理论上耦合

识别贡献时，生成与分配必须分开做实验：固定锚点识别 $P(x'\mid x,h,o)$，固定生成协议识别 $\mu(a\mid\mathcal H)$。联合版本结果、访问统计或谱系图不能替代这种分离。

理论上二者不能当成彼此无关的旋钮。有效的分配建立在提议异质性上：若不同投资单位上的 LLM 生成分布相近，分配器没有可利用的差异。反过来，若 Explore 能制造不同算法区域，而分配器不给它们最低发展机会，提议多样性会被预算调度截断。V9.7 搜索几何已经读出 route 与静态 family 的错位；下一步需要用固定锚点、强制短续段和 Uniform 对照检验新的 hypothesis unit，而不是从选择性日志拟合长期价值。

### 2.3 轨迹事实与决策视图必须分层

轨迹事实至少包括当前代码、父子关系、声明的 Idea、实际修改、有效性、评价结果和发生顺序。模型实际看到的历史只是从这些事实中抽取的有限决策视图。

事实应完整、可追溯；决策视图允许有损压缩，但压缩规则必须明确。同一份代码可以沿不同路径形成，因此“代码相同”不意味着“下一次生成条件相同”。Idea 是语义标签，实际修改由父子 evaluator input 决定；两者不一致时，以代码事实为准。

### 2.4 非单调形成过程应保留，但不能奖励退步

优秀算法可能经过持平、退步、修复和重组后形成。保留 regression state 的理由是避免提前删除尚未完成的路线，不是给退步预设正信用。某个祖先事后位于成功谱系，只说明它属于来时路，不能证明当时重访它具有较高前瞻价值。

### 2.5 路线是投资单位，当且仅当存在可利用的异质性

根、分支、深度和访问集中只描述生成来源。不同根可能实现同一种算法思想，同一路线也可能在后续替换核心机制。代码不同不等于算法簇不同。路线覆盖若要成为科学变量，需要行为或语义证据。

正统 V9.7 的顶路线份额与路线乐观项干预率，只说明当前公式几乎不改写路线选择。它至少对应三种尚未分开的情况：[待验证]

- **路线确实异质**：某一根已进入高潜力簇，把预算集中给它可能正确；强行增加路线探索会变差。
- **路线没有语义差异**：八个根只是同一族的轻微变体，任何跨路线分配器都没有可利用的臂。
- **有潜力差异但分配器看不见**：现行 $q^*+s/\sqrt{N+1}$ 只看已经达到多高和已经投了多少，不估计这条路线还有没有继续突破的可能。

因此当前最重要的分配问题不是把乐观项从 1 调到 2，而是：现有路线到底是不是有意义的投资单位。正统 V9.7 的最终最好程序有 9/12 次改变所在根的静态机制宏簇，说明 route 是 provenance unit，尚不是稳定 family。覆盖与延续价值仍然是两个目标，但它们都以取得各路线可比较续段为前提。路线推进率、局部回弹、趋势、成熟度和事后谱系成功均不能在缺少独立证据时写入在线信用。

V9.8 据此提出 Explore-defined hypothesis 与固定短 probe。这是从证据导出的设计约束，不是已验证结论：intent boundary 可能错分真实 family，三步 horizon 也可能过短。完整定义与对照见[V9.8 设计稿](../methods/TraceAAD-v9.8完整机制设计.md)。

### 2.6 生成意图的理论含义是族内 refinement 与跨族跃迁

当前 V9.7 用固定 0.7/0.3 混合区分 Refine 与 Explore。除 Refine 改得更小、improve 更高外，静态代码机制代理还显示 Explore 的宏簇切换率为 37%–54%，高于 Refine 的 2%–12%，并贡献各任务 20%–36% 的搜索期全局增益。根到终局发生宏簇变化的 9 次运行中，6 次由 Explore 首次进入终局宏簇；12 个最终最好程序本身全部由 Refine 生成。这是“稀疏换簇后继续开发”的描述性证据，不是固定锚点意图消融或行为簇确认。

轨迹不只是程序序列 $x_0\to x_1\to\cdots$，更有价值的运动是算法簇之间的停留与切换。[待验证] Refine 应提高族内开发；Explore 应提高 $P(F_{t+1}\neq F_t)$，并提高随后进入更好盆地的概率。现行锚点分数会让 36%–87% 的 Explore child 出生即淘汰，因此完整搜索里的后代率同时混入 proposal 与 allocation。完整协议的 held-out 是联合系统评价，不能识别两种意图的独立作用。需要固定锚点和历史测量换族率，并给每个换族 child 相同短续段后再比较后代潜力。

### 2.7 程序复杂度目前只是诊断量

现有 run 级分析没有显示 LOC 与 held-out gap 的稳定关系。代码增长可能是必要复杂化、暂时退步或停滞后的无收益改写，单靠长度无法区分。LOC 不应进入任务分数、在线信用或硬拒绝规则；完全同分时择简只是一条确定性 tie-break。详见 [L4](../research/L4-诊断.md) 与 [RQ-001](../research/RQ-001-程序膨胀.md)。

## 3. 证据与写作纪律

研究结论需要区分五层证据：

1. **机制规范**：系统被设计成怎样运行；
2. **过程激活**：机制是否实际改变了选择、提示或候选分布；
3. **单步生成**：固定锚点时，历史或意图是否改变下一候选；
4. **完整搜索**：统一预算下是否改善 best-at-budget；
5. **held-out 与成本**：最终程序是否稳定泛化，以及代价是多少。

前一层不能替代后一层。完整联合版本只能支持整体系统判断；若没有固定其他条件的消融，不认领单组件贡献。实例级配对样本不能替代运行级独立重复。三重复比较按实际均值差与方向记录，包括约 1%–2% 的改进。

## 4. 当前开放问题

V9.7 的静态簇与搜索几何诊断已经完成；下一步转向验证 V9.8 的操作性投资单位、短续段和三通道分配。

1. **操作性 hypothesis 是否成立**（[L0](../research/L0-状态表示.md)、[L2](../research/L2-预算分配.md)）：Explore boundary 是否比 root route 更接近可利用算法区域，Refine 与 Explore 各自有多少边界错分。
2. **短续段价值**（[L3](../research/L3-单步生成.md)）：Explore child 在强制 0/3/5 步 Refine 后能否稳定产生内部发展与 parent recovery。
3. **分配价值**（[L2](../research/L2-预算分配.md)）：Single→Uniform 的 pool value、route→hypothesis 的单位效应、$H=0\to3$ 的 horizon 效应和 Uniform→三通道的 routing value。
4. **任务几何**（[L4](../research/L4-诊断.md)）：好簇稀有度、族内可改进性与簇间质量方差能否解释 V9.8 的任务依赖收益。

## 5. 外部证据的位置

现有文献支持三项背景判断：LLM 变异具有结构化先验；可靠局部改进通常比无条件扩大文本新颖性更重要；代码、行为和路线多样性不能混为一谈。BaSE 额外表明：有限预算下的可达前沿依赖算法簇的提议质量不对称，自适应分配只在轨迹间存在可利用异质性时有价值；它不证明 bandit 公式应当写入 TraceAAD。相关证据及边界见[LLM 作为进化算子的机制分析](../references/LLM作为进化算子的机制分析论文.md)、[AAD 方法汇总](../references/LLM自动算法设计方法汇总.md)、[BaSE 笔记](../references/LLM自动算法设计方法阅读笔记/28-Compute-Allocation-BaSE.md)和[逐篇阅读笔记](../references/LLM自动算法设计方法阅读笔记/README.md)。这些外部结果用于提出可检验假设，不能替代 TraceAAD 自身的受控实验。
