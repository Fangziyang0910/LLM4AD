# TraceAAD V7 分析

> 版本规范：[docs/methods/TraceAAD-v7完整机制设计.md](../methods/TraceAAD-v7完整机制设计.md)
> 状态：2026-08-07 冻结；历史版本，不定义当前方法。

## 1. 版本定位

V7（"可执行状态唯一的轨迹进化"）在 V6 简约骨架上引入三项设计：①active frontier 精确 `code_hash` endpoint 去重——在线不变量，重复 endpoint 只归档繁衍状态，不删除事实；②剩余预算衰减 UCB——探索项乘剩余预算比例 $r_b$，后期选择逐步回到 $V=0.8Q+0.2P$（Q 含近期趋势 P）；③生存简化——global best + 3 个质量精英 + Q/P softmax，不维护语义多样性 reserve。设计按四个可证伪假设组织：H1 去重提高真实路线覆盖、H2 衰减 UCB 改善后半程预算集中、H3 删除语义 reserve 不损害功能多样性、H4 缩小并反转对 MCTS-AHD 的差距。V7 是种群搜索路线的最后一版。

## 2. 实验事实

正式批次 `v7_20260804_001931`，协议 `traceaad-v7`，checkpoint schema 11。四任务 × 3 重复 + 完整测试（Qwen3.6-27B、1000 次搜索评估），测试结果弱于 V5/V6/V8（[实验总汇](../experiments/实验总汇.md)）。

- **名次**：十一方法同场 15 规模平均名次 7.533（第 8）；单版本上场 3.433（第 3），相对 MCTS-AHD 名次差 +2.000，相对四基线平均优势 −0.542（与 V8.3 相同）。
- **测试设置**：未在任一测试设置取得唯一最佳均值。
- **可分辨性**：P(行优于列)矩阵中 V4/V5/V8/V8.2 优于 V7 的概率均为 1.00，V7 相对这四者可分辨地更差（[消融基座选择](TraceAAD-版本迭代诊断与消融基座选择.md) 3.2 节）；15 规模整体效应量 −1.13（TSP −0.50、CVRP −3.21、OP −0.70、OBP −0.62），四任务全部落后，与 V8.3（−1.27）同属全面落后型，区别于 V4/V5/V6/V8/V8.2 的任务分化型（3.3 节）；Welch 检验 2 个 p<0.05 组合且方向均为更差。

## 3. 机制检验

正式实验只完成联合版本的完整测试，未单独检验各项假设（[版本实验事实与机制诊断](TraceAAD-版本实验事实与机制诊断.md)）：

| 假设/机制 | 检验状态 | 证据 | 证据级别 |
| --- | --- | --- | --- |
| H1 精确 endpoint 去重提高真实路线覆盖 | 未单独检验 | 联合批次完整测试，无单变量对照，不能归因 | A（联合） |
| H2 剩余预算衰减 UCB 改善后半程预算集中 | 未单独检验 | 同上 | A（联合） |
| H3 删除语义 reserve 不损害功能多样性 | 未单独检验 | 同上 | A（联合） |
| H4 缩小并反转对 MCTS-AHD 的差距 | 不成立 | V7 可分辨地更差：名次差 +2.000、效应量 −1.13、四任务全落后 | A |

## 4. 结论

1. **H4 反证成立但不可逆推。** 去重与衰减 UCB 联合引入的版本整体可分辨地更差；联合修改无法归因，H4 的反证不能逆推为 H1–H3 各自失败。
2. **状态卫生不等于性能机制。** 确定性去重与动态探索压力这类"状态卫生"不变量应保留，但不应被当作性能机制单独宣称价值。
3. **失败类型区分。** V7 与 V8.3 是仅有的四任务全面落后版本，与 V6 的任务分化型失败成因不同，不能用同一套修改处理。
4. **对 V8 的影响。** V7 是种群搜索路线最后一版；V8 以完整单父树替代 active 轨迹种群，把"保留哪些状态"从生存淘汰问题改为预算分配问题。
