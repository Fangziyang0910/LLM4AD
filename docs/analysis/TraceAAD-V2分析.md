## 1. 版本定位

V2(代码 `1f6c9ca`)是"改进历史指导下一步"主张落地的第一版完整实现:把每次修改的来时路组织成有界轨迹(上限 8 节点)与单父派生图,并在其上同时运行岛模型(4 岛/迁移周期 20)、新颖性搜索、五算子 portfolio 信用分配、精英课程、Elo 式对比反馈与六分量价值评估。设计意图是让历史本身、多样性维持、探索利用平衡与算子信用各由一层机制承担。

## 2. 实验事实

批次 TSP `20260718_174552`、CVRP `20260718_193305`,各三重复 + 测试,工件在 `archive/traceaad-v2-v3/<task>/version2/`。训练集 best:TSP 代表重复约 −6.36(rep1 −6.3576),CVRP −8.96 / −8.79 / −8.97。测试:TSP50 均值 6.3683(std 0.112)、TSP100 8.9617、TSP200 12.9386;CVRP test_50 均值 9.2129、test_100 15.8113。worklog 提及 V2 曾运行 OP/OBP,但无归档工件可核对。两任务搜索结果均低于 V3。

## 4. 结论

1. 确认轨迹主干可运行且数据一致(节点/边/轨迹与日志吻合),该结构成为后续所有版本的基础。
2. 每一层辅助机制都增加复杂度与归因难度,却不必然改善结果;没有任何一层被证明提供了独立于轨迹主干的信号。
3. 整体结果低于 V3 支持删减方向,但该对比是联合修改,不能归因到任何单一机制。
