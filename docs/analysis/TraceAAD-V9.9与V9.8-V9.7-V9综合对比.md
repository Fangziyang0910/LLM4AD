# TraceAAD V9.9、V9.8、V9.7 与 V9 综合对比

> 时点：2026-08-17。比较对象为 V9（`20260807_123753`）、正统 V9.7（`20260815_parentpath`）、完整 V9.8（`20260815_225000`）和 V9.9（`20260816_154200`）。V9.9 的 TSP、OP、Online Bin Packing 已完成三重复 held-out，CVRP 三次搜索仍在运行，因此本文不把 V9.9 写成四任务完整排名。

## 1. 核心判断

当前证据不支持“版本越新越好”的单调序列。

- **V9.7 是目前四任务完整版本中最稳定的综合基线。** 相对 V9，TSP 与 CVRP 三个规模均改善；OP 三个规模均退化；OBP 六档混合，说明它主要改善了 TSP/CVRP，而不是形成跨任务统一升级。
- **V9.8 没有兑现相对 V9.7 的统一升级。** CVRP 三档同向退化，OP 三档同向改善，TSP 混合，OBP 接近持平且方向混合。它的机制识别价值大于最终性能收益。
- **V9.9 的已完成结果呈现更强的任务分化。** TSP 暂时优于三个旧版本中的大多数规模，OP 接近 V9 且优于 V9.7，OBP 六档全部弱于 V9.8；CVRP 尚无结果，不能判断它的四任务位置。
- **V9.9 的当前优势伴随更高运行间变异。** TSP100/200 的样本标准差为 `0.378723/0.481041`，明显高于 V9.8 的 `0.103832/0.111750`；OBP `1k/100` 的标准差为 `9.865`，不能只看均值宣称稳定改善。

## 4. 机制层解释边界

四个版本都是联合版本，不能把下列性能变化单独归因给某一公式或提示字段：

- V9 到 V9.7 同时改变路线—锚点分配、父代来时路和 Refine/Explore 协议；TSP/CVRP 的改善不能单独归因给路线分配或 parent path。
- V9.7 到 V9.8 同时引入 hypothesis 分段、逐步 `q_u_c_m` 分配、边界宽限和历史发展项；CVRP 退化与 OP 改善只能归因于 V9.8 联合搜索行为。
- V9.8 到 V9.9 同时取消 route/hypothesis 在线信用，改为锚点—算子联合决策，并改用 8 根无 bootstrap 初始化、几何秩、距离衰减回撤宽限和动态算子概率；TSP/OP/OBP 的当前差异不能拆到其中某一项。

目前能支持的机制层判断是：不同任务对这些联合协议的响应确实不同；还不能把这种任务分化写成“方法已经在线读出了任务几何”。尤其 V9.9 缺少 CVRP held-out，完整泛化结论尚未闭合。

## 5. 结论与下一步

当前最稳妥的版本画像是：V9 是 OP 与部分 OBP 设置的强基线；V9.7 是 TSP/CVRP 和总体完整版本比较中最稳的版本；V9.8 没有统一超过 V9.7，但在 OP 和部分 OBP 设置保留竞争力；V9.9 暂时显示 TSP 方向有潜力、OP 接近旧版本、OBP 退化，不能在 CVRP 完成前评价其总体表现。

下一步只需完成 V9.9 CVRP 的三次 held-out，然后用同一脚本在 15 个设置上重算四版本排名。重算前不修改现有 V9/V9.7/V9.8 正式排名，也不把 V9.9 的 12 设置临时名次写入总体结论。
