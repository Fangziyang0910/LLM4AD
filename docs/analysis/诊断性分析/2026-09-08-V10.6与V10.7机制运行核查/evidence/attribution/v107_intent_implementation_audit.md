## 逐项证据

1. **轨迹语义与排序：符合原意。** 原文165–215行明确要求“按质量从弱到强排列，但不伪造修改过程”，不显示来源信息，不解释“不是父子”，并要求保留原 Refine 底座。`prompts.py:126–141` 按 `(fitness,id)` 排序，使用展示序号标识底座，标题 Algorithm Trajectory；没有前后版本或祖先链叙述。不能将未呈现真实时间演化判为实现错误，原意主动放弃这一信息。

2. **Pivot 探索目标：原方案忠实实现，但相对旧版变弱。** 原文241–251行要求“不绑定继承某个底座”，设计“替代性的主要决策方法”，且承认“不保证生成真正不同的算法簇”。`prompts.py:100–101` 的 “design an alternative main decision method” 基本直译。旧 `v10_6/prompts.py:17` 则明确 “different main idea from the current algorithm”。新版没有说明 alternative 相对于哪份材料，不能保证偏离当前最高分程序，也没有行为新颖性验收。该模糊性属于方法/提示设计，不能称为误译或漏实现既定硬约束。

3. **Fuse 目标与 donor：主要属于方法选择。** 原文253–267行明确从已采样参考中选质量较好者，取消 top5/血缘限制，指令只要求“形成一个连贯算法”。实现 `prompts.py:102–104,129` 忠实对应。V10.6 `prompts.py:18` 的 “Design an improved algorithm ... aiming to outperform both algorithms” 在新版丢失。注意 V10.6 本来就将所有有限有效 fitness 的候选入档，不存在被新版取消的超双亲准入门槛；“不要求超双亲才入档”不意味着应删除生成时的改进目标。可以独立恢复改善意图验证，但不能据此说 donor 选错或源码擅自改变原始 Fuse 规则。

4. **采样目的与层塌缩：符合原意，暴露方法边界。** 原文明确同分不拆层、精确代码去重而非行为去重、不引入语义聚类。`sampling.py:21–25,34–44,52–68` 均对应。大量不同代码拥有相同分数时只剩一层，是规则允许的结果；它保证机会而非行为差异。父代质量/次数基座不变也来自原文，不能将重复节点的独立次数完全归为本轮擅增机制。

5. **新增 100 words / 256 tokens：工程变体，不是原始核心 idea。** 附件只要求短 Idea，并多处要求完整 Idea+Code；没有100 words或256 tokens规定。`prompts.py:106–118` 给所有采样模式输出（包括Init）追加100 words，展示时超过256 tokens整段省略；143–148行组合超限还可省略全部Idea。当前设计第6节将其写入规范，但这不能消除相对原方案的差异。它可能改变最初根生成和后续思考表达；不能只解释为无语义成本的日志优化。此前快照97/26004块被省略，影响范围小但非零；输出限长本身的影响不限于被省略块。

6. **容量过滤顺序：有界工程变化，当前无失败证据支持其造成退化。** 原文候选池先包括“能够装入本次上下文”的程序，然后分层；当前先对全部去重候选分层，抽中才计数，每位置最多32次，同层重试。原文也要求有界重抽，因此这是节约计数成本的实现选择，但严格采样分布会在长代码多时不同。正式快照fit rejection/shortfall为0，当前不能把退化归于此变化。

## 对照实验能隔离什么

- `ancestor_history` 与采样模式共享 V10.7 单次生成/评价主循环，但会一起改变参考来源、数量、完整代码展示、排序、算子指令、donor规则、100-word输出约束与256-token视图。旧模式通过 `_code()` 去除注释，新模式完整原始代码；旧模式按祖先历史总预算移除整条事件，新模式按程序组合容量取舍。旧模式不追加100-word要求，因此连Init prompt都不同。这是“单调用历史基线 vs 整套采样方案”，不是纯采样分层对照，也不是纯去二次调用对照。
- `uniform_trajectory_v1` vs `sampled_trajectory_v1` 共享格式、算子、Idea视图、容量和单调用流程，主要隔离参考抽样分布（相同 seed 不代表后续随机选择严格配对）。
- V10.6 vs V10.7 `ancestor_history` 更接近独立校准流程消融，但仍同时改变历史字段内容：实现摘要→前置设计Idea；约500-word校准摘要/1024-token段落视图→单段设计Idea，无原摘要视图；校准失败、解析失败和耗时路径也被删除。可以比较整个两阶段流程的净价值，不能声称只隔离“模型解释是否纠错”。
- 若只验证新Idea长度规则，应保持采样/算子/种子和初始化条件，单独开关输出长度与展示限额；若只验证Fuse改进目标，应保持参考材料规则，仅改指令。当前历史结果不具有这些单因素识别能力。
