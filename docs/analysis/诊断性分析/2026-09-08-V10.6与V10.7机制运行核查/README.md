## 已确认事实、解释与未识别因素

| 类型 | 当前可支持的陈述 | 不能据此推出 |
| --- | --- | --- |
| 实现核查 | 采样、父代/算子分配、预算和入档主逻辑基本忠实原方案；未发现未来节点泄漏 | 方法设计有效，或所有表达都正确 |
| 表达缺陷 | 历史 Idea 的 Algorithm N 在重编号后错指；冻结快照48.3%的展示块对应不同代码 | 48.3%的模型误解率或性能损失率 |
| 设计风险 | Fuse donor 的质量分位下降；分数分层和完整代码去重不能保证行为差异 | 弱 donor 已被证明是长期主因，或分层一定劣于均匀抽样 |
| 行为反事实 | 三份 TSP 当时最佳程序，修数值错误后都更差；原程序与最近邻加原尾部精确同分 | 全档案取材被否定，或这个打分族所有参数无效 |
| 历史路线 | V10.6 有真实 rollout/2-opt 突破后持续开发的成功路线；V10.7 部分路线主要扩大精确尾部 | 第二次校准必然促成突破 |
| 局部对照 | 24次生成/评价均成功；去 Idea、祖先组合、更强 donor 没有跨场景稳定收益 | 每臂2样本能够估计总体效果，或证明某机制无效 |
| 干扰因素 | 任务/评价器核对一致，但格式过滤改变生成次数和入评程序分布 | 两版完全配对，或格式过滤收益方向已知 |

工作判断是具体方案存在效果短板并夹带表达缺陷，尚未识别各项变化的长期因果占比。OP 和 OBP rep1 的正面结果必须保留。请独立分析者优先检查：编号错指的语义影响；代码不同却行为相同的材料比例；有效突破是否被生成、得到开发；强 donor 是否具有行为互补性。不要仅凭相关比例判定主因。
