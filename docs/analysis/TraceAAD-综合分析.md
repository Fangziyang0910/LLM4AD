## 2. 机制有效性汇总

**已确认有效的机制(有受控或过程证据):**

- 自然语言 Action 决策(替代结构化 Action):格式合规率恢复,候选供给恢复(V5.1,B 级)。
- 概率调度组合 $0.8Q+0.2P$ + $0.7Q_{\mathrm{endpoint}}+0.3Q_{\mathrm{best}}$ + ucb_c=0.25 + 温度 0.2:单次选择最大概率 0.08–0.14、有效候选 19–27,能集中预算而不锁死(V5,B 级)。
- 删减未经验证的代理变量:V2→V3、V8.3→V9-Core 两次删减均未使搜索变差,V3 明确变好(A 级联合)。V6 的删减是例外方向:删代理本身并非处处失败(TSP 最好),但 V6 整体可分辨地更差,删减边界需单独标定。
- 完整单父代树骨架:V8 与 V8.2 共 24 个 run 重建成功、V8 变异系数全方法最低、成为最强 TraceAAD(V8,B 级)。

**已确认有害的机制(有证据):**

- 趋势权重 0.4:偏向噪声,调度被回退(V5.4,B 级)。
- new_child 扩展信用(含已有子代回报)+ descend 子树最大值 + 虚拟根无渐进拓宽:根锁定与 sibling 爆炸(V8.3,B 级)。

**退化责任候选(伴随观察,未单变量消融):**

- 删除精确 endpoint 去重:OBP capacity=100 明显退化(V6,A/B 级)。

**未运行(不等于已检验):**

- 全局反思 $g_t$(V5.0):预算估计超模型真实边界,16 次调用全失败。
- 结构化 Action(V5.0):39.9% 调用无合法 Action。

**未单独检验(联合修改无法归因,占大多数):**

- V1/V2 的叠加层、V4 的 UCB 与内部锚点、V5 的四算子与双轨迹参考、V7 的 H1–H3、V8/V8.2 的深度与生成协议、V8.3 的五算子与两次调用。

## 3. 跨版本科学结论

1. **联合版本结果无法归因到单个机制。** V2→V3、V6→V7、V8→V8.2、V8.3 每次同时改变 3–8 项;总体分数不能识别任何单一组件的独立效果。六次版本迭代产出的可靠信息全部是负面结论(V6/V7/V8.3 可分辨地更差),没有一项正面机制得到确认。
2. **未经验证的代理变量应当删除。** 成熟度、路线信用、语义差异是主观代理,删除符合举证责任;精确代码去重是可直接判断的事实,删除的举证责任不对称(V6、V8.3 教训)。
3. **趋势类信号存在噪声拐点。** 普通回弹不等于前沿推进(V5.2/V5.4);一次幸运结果不应永久抬高整条祖先分支(V8.3)。
4. **机制未运行、运行无效、运行有害必须分开判断。** V5.0 的两处失效属于第一类;解析通过不等于执行了目标代码。
5. **核心科学主张未被直接检验。** "算法改进历史为下一步提供信息"从未与 current-code-only 对照;V8/V8.2 深度对照(3 步 vs 35 步)是最接近的操纵,方向为无差异,且非单变量(差五项)。

## 4. 版本失败类型

| 类型 | 版本 | 特征 |
| --- | --- | --- |
| 任务分化型 | V4/V5/V6/V8/V8.2 | TSP 领先、CVRP 落后;整体效应量 −0.06 到 −0.92 |
| 四任务全落后型 | V7、V8.3 | 全部任务落后;效应量 −1.13/−1.27 |
| 机制未运行型 | V5.0 | 搜索空间失效,结果不进正式页 |

CVRP 上的尺度崩塌是全部非基线方法的共性(含 EoH/ReEvo/PathWise),不是 TraceAAD 机制缺陷;任务层问题与版本机制问题成因不同,不能用同一套修改处理。

## 5. 科学主张与下一步

TraceAAD 的主张是"保存改进轨迹并用它指导下一步"。当前证据状态:

- 树/轨迹作为**状态组织方式**是可行的(V8 是最好版本),但成绩与"多起点加浅层局部改进"相容,与"长历史指导"的因果未建立。
- 消融基座定为 V8 系列树骨架,配置待深度实验确定;后续单变量消融序列(深度、历史条件、预算缩放、上下文构成、算子集合、状态卫生、选择与信用)见[版本迭代诊断与消融基座选择](TraceAAD-版本迭代诊断与消融基座选择.md) 第 6 节。
- 协议层缺口(重复数 n=3、无配对设计、主指标为平均名次、生成预算未对齐)须先修复,否则后续实验无法读出信号(P1–P4)。
