# TraceAAD V9.16 算法执行行为动态与算子步长分析

## 核心判断

通过引入基于固定 probe 的执行行为轨迹距离（PSTraj DTW），能够深入刻画算法在解空间搜索中的动态特征。分析表明：
1. **探索与利用的步长分化显著**：Explore 算子引起的行为跃迁距离系统性大于 Refine 算子，验证了提示层面的意图引导有效传导至代码执行行为层；
2. **任务间解空间拓扑异质**：OBP 与 TSP 容易陷入局部重复行为停滞（无突破重访率高），而 OP 与 CVRP 展现出极强的持续扩散与高突破率；
3. **行为多样性需与有效兑现相统一**：高行为距离若不伴随目标突破，实质上是盲目无效探索，必须将行为新颖性与质量增益联合考量。

- **局部停滞区（OBP / TSP）**：OBP 的中位最近邻距离极低（0.047），且无突破精确重访高达 27.7%，表明搜索高度聚集在少数相似决策模式中；
- **广度发散区（OP / CVRP）**：平均两两距离与中位最近邻显著拉大，重访率极低（~1.1%），搜索保持着活跃的拓扑扩展与持续突破。

## 2. 算子诱导的行为步长

在全任务中，Explore 算子诱导的父子行为跃迁距离均显著高于 Refine 算子：

| 任务 | Explore 中位距离 | Refine 中位距离 | 步长差异特征 |
| --- | ---: | ---: | --- |
| TSP | 0.712 | 0.453 | 探索步长大，精炼步长适中 |
| OP | 0.664 | 0.557 | 整体步长偏大，发散性强 |
| OBP | 0.339 | 0.155 | 算子受限于问题结构，整体尺度偏紧 |
| CVRP | 0.830 | 0.749 | 决策空间高维发散 |
| VRPTW | 0.740 | 0.525 | 层次清晰的分步搜索 |

这一事实表明，不同搜索算子在 LLM 生成时确实形成了区分度良好的行为步长梯度，为自适应算子调度提供了物理支撑。

## 3. 机制启示

1. **停滞状态的精准感知**：通过将“历史最近邻行为距离”与“质量增益曲线”联合建模，能够及时识别重复利用停滞、无效发散与有效兑现三种典型状态；
2. **高质量交叉的先决条件**：行为空间的距离适度性应当作为父代选择的考量指标——过近则缺乏信息增益，过远则破坏解的局部结构，最佳候选应处于结构互补的适度距离带。
