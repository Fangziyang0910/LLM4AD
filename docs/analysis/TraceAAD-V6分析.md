# TraceAAD V6 分析

> 版本规范：[docs/methods/TraceAAD-v6完整机制设计.md](../methods/TraceAAD-v6完整机制设计.md)
> 状态：2026-08-07 冻结；历史版本，不定义当前方法。

## 1. 版本定位

V6（"简约的轨迹进化"）从 V5 大幅删减代理机制：移除成熟度门槛、路线差异门槛、固定算子比例、强制删减、路线信用、在线程序去重、多层精英与差异保留、按结果标签筛选历史、初始化新颖性指令，只保留真实历史、$Q$+UCB、四算子等概率、global-best route 与 Q-softmax 生存。设计意图：不靠手工代理指标预判哪条路线值得投入，把算法有效性判断全部交给 evaluator；保留 V5 中已明确有用的细节（四轨迹语义算子、双轨迹参考、Action 与 Code 共享上下文、同分择短）。

其中两类删除的地位不同：未经验证的质量门槛（成熟度/信用/语义差异）是主观代理，删除符合举证责任；精确 endpoint 去重是可直接判断的事实规则，删除的举证责任不对称。

## 2. 实验事实

正式批次 `20260802_170400`，简约协议重构提交 `fde9129`，协议 `traceaad-v6`，checkpoint schema 8。四任务 × 3 重复 + 完整测试，Qwen3.6-27B、1000 次搜索评估，与其余版本同口径（[实验总汇](../experiments/实验总汇.md)）。

- **名次**：十一方法同场 15 规模平均名次 6.533（第 6；诊断时点八方法同场为第 4）；单版本上场 3.033（第 3），相对 MCTS-AHD 名次差 +1.400，相对四基线平均优势 −0.042，弱于 V5（2.000、+1.250）与 V4（2.400、+0.750）。
- **TSP**：TSP50 5.956746、TSP100 8.285381 为全场均值最低；八方法同场口径下 TSP 三尺度测试均值最好——删代理并非处处失败。
- **OBP**：capacity=100 三尺度（1k/5k/10k = 422.133 / 2071.467 / 4131.067）明显差于 V4/V5；两个重复搜索 best 停在 seed，active 出现大量重复 endpoint；capacity=500 的 1k/500 与 V8/ReEvo 并列最佳（80.800）。
- **CVRP/OP**：均非最佳，OP100/200 明显落后于 V5。
- **可分辨性**：P(行优于列)矩阵中 V4/V5/V8/V8.2 优于 V6 的概率 0.97–1.00，V6 相对这四者可分辨地更差（[消融基座选择](TraceAAD-版本迭代诊断与消融基座选择.md) 3.2 节）；整体效应量 −0.92（TSP +1.23、CVRP −1.78、OP −1.95、OBP −1.05），属"任务分化"型——在 TSP 领先、其余落后，与 V7/V8.3 的全面落后型成因不同（3.3 节）。
- **口径修正**："搜索名次与测试名次倒挂"论断中 V6 的搜索分曾取自过程批次；改用与测试对应的正式批次后搜索 z = −0.003（第 6），位移从 −3 缩小到 −1（3.7 节）。

## 3. 机制检验

| 机制 | 检验状态 | 证据 | 证据级别 |

| 四算子等概率与双轨迹参考 | 未单独检验 | 过程批次中双轨迹算子仅占 14%（synthesize 6.5%、transfer 7.3%），不构成步长差异主因 | B |

## 4. 结论

1. **删代理并非处处失败。** 删除未经验证的质量门槛后 TSP 三尺度均值最好，与 V2→V3 的删减结论一致：未经验证的代理变量应删除，不作为 V6 整体退化的原因。
2. **删除精确 endpoint 去重是 OBP 退化的责任候选。** 相同代码是否重复是可直接判断的事实而非主观质量代理；后续最小消融应单独恢复精确去重，不恢复成熟度/信用/语义差异门槛。
3. **V6 整体相对 V4/V5/V8/V8.2 可分辨地更差**，属任务分化型失败；版本迭代的可靠信息之一是过度删减会造成损害，删减边界需要单独标定。
4. **过程观察不与机制反证混淆。** 双轨迹算子占比低、步长增大无收益、精炼可靠性最低均为描述性观察，不能单独归因；它们指向退化更可能来自去重缺失与调度简化，而非算子或步长本身。
