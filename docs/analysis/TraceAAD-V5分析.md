# TraceAAD V5 分析

> 版本规范:[docs/methods/TraceAAD-v5完整机制设计.md](../methods/TraceAAD-v5完整机制设计.md)
> 状态:2026-08-07 冻结;历史版本,不定义当前方法。

## 1. 版本定位

正式 V5(代码快照 `bb40ff0`,批次 `20260728_151736`)把"历史指导下一步"落实为轨迹种群搜索:四个轨迹语义算子(ideate/refine/synthesize/transfer)、主轨迹加参考轨迹双参考、修改决策与代码生成两阶段、同分择简,调度基础值由 V4 的多分量 $V_{\mathrm{search}}$ 改为 $V=0.8Q+0.2P$(质量 0.8、近期趋势 0.2,再加 UCB 与 softmax 概率选择),并关闭在线全局经验。开发谱系逐点收口:V5.0 的结构化 Action 与全局反思未运行;V5.1 恢复自然语言 Action;V5.2 引入趋势权重 0.2;V5.4 提高至 0.4 后因偏向噪声,经 `4105f34` 回退至 $0.8Q+0.2P$ 与 $10^{-12}$ 阈值定稿。

## 2. 实验事实

正式批次四任务 × 3 重复加完整测试。十五测试规模平均名次 5.100(十一方法同场第 5,与 V4 不可分辨);单版本上场口径平均名次 2.000(5 方法中第 2,为全部版本最好),相对四基线平均名次优势 +1.250。OP100/OP200 报告均值为全方法唯一最佳;OP instance 胜率随规模单调增强(53%/61%/86%,d=+0.74),但 run 级 p=0.444,方向稳定、强度不足以确立显著性。CVRP 随规模崩塌(34%/6%/0%)是全方法共性,不指向 V5 特有缺陷。过程审计:严格突破率 0.151、LRR 0.136±0.048、PCD 0.085±0.035;等分更短代码事件 12.1/run 曾被计入 `best_updated`,修正后不是适应度突破。

## 4. 结论

1. 确认:搜索空间正确性是机制检验的前提。结构化 Action 与超预算反思使 V5.0 两处机制完全未运行,机制未运行不等于已检验;自然语言 Action 恢复后才谈得上候选供给。
2. 确认(单变量对照):趋势权重存在噪声拐点,0.2 在边界内、0.4 偏向噪声一侧;普通回弹不等同于前沿推进。V5.2/V5.4 是 V5 开发中仅有的受控取点。
3. 否定/未确认:同分择简不能作为已确认的抗过拟合机制(LOC–gap 组内相关不成立);OP200 胜率 86% 与单版本名次 2.000 是方向稳定的描述,run 级检验未达显著;四算子、双轨迹参考、$0.8Q+0.2P$ 对总体成绩的贡献因联合修改无法归属。
4. 对后续版本:概率调度组合($0.8Q+0.2P$、$0.7Q_{\mathrm{endpoint}}+0.3Q_{\mathrm{best}}$、ucb_c=0.25、温度 0.2)被 V8.3 分析列为可迁移机制;全局自然语言经验、Elo/多维信用、语义相似度硬门槛等候选因 V5 教训未被采纳;V5 机制边界分析原文已删除,教训凝练入[版本实验事实与机制诊断](TraceAAD-版本实验事实与机制诊断.md)。
