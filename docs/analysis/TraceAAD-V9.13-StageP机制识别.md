# TraceAAD V9.13 Stage P 机制识别（三轮）

V9.13 的两阶段协议第一阶段共执行三轮识别，每轮在 V9.7 正式批次重放的真实 Explore 决策快照上比较候选上下文，六项候选门槛与阈值在每轮数据生成前原样冻结。三轮共 2,808 次响应（r1 五条件 1,080、r2/r3 四条件各 864），快照抽样协议相同、冻结 seed 不同（913101/913201/913301）。三轮均判定停止，V9.13 终止在机制识别阶段。

## 三轮处理

| 轮次 | 前沿表构造 | 快照/试验 | valid |
| --- | --- | --- | --- |
| r1 | 全区域标签+质量，成就式框架，质量降序 | 72 / 1,080 | 90.4% |
| r2 | 本区域完整，其它区域仅质量（无标签），地板框架 | 72 / 864 | 92.8% |
| r3 | 全区域标签+质量，地板框架，本区域置顶 | 72 / 864 | 93.2% |

r2 依 r1 的 CVRP −7.4pp 有效率损失修订；r3 解混 r2 捆绑修改的三个变量（标签/措辞/排序），只恢复标签。FC（完整参考代码）在 r1 后从候选集删除（OP 参考复制 5.6%、增量方向混合）。

## 三轮门槛结果

| 轮次 | 失败项 | 通过项 |
| --- | --- | --- |
| r1 | CVRP valid −7.4pp（>5pp） | 质量 4/4 提高、亚前沿 4/4 下降、重复零上升、next_selection 3/4 |
| r2 | 质量 2/4 提高、max drop 3.06（>0.5） | valid 最大降幅 3.7pp、重复 ≤1.9pp、next_selection 3/4、亚前沿 3/4 |
| r3 | CVRP 质量 −0.93（>0.5）、TSP valid −5.6pp（>5pp） | 质量 3/4、重复 1.9pp、next_selection 3/4、亚前沿 3/4 |

## 跨轮可复现的现象

按任务汇总三轮 `fp_explore − pp_explore`（每轮独立快照样本，方向计数为快照级）：

- **next_selection_rate 三轮都是 3/4 任务改善**（OBP/TSP/OP 为正，CVRP 平或负；OBP 最强，r1 +20.4pp、r3 +11.1pp）。前沿上下文稳定提高候选进入后续竞争的能力。
- **亚前沿重入**：r1 4/4 下降、r2/r3 3/4 下降；TSP 在 r3 下降 14.8pp。
- **archive duplicate** 三轮均无实质上升（0–1.9pp）。
- **TSP 单步质量三轮为正**（+0.65、+2.50、+0.25）；OBP 两轮大幅为正、一轮被单个 −109.6s 离群拖成均值负；OP 三轮温和为正（+0.31 至 +0.67）。
- **CVRP 每轮换一个方向**：质量 +1.30 / −0.52 / −0.93，valid −7.4pp / 0 / +7.4pp。无稳定符号。

## 分析

1. **机制的设计作用可复现，均值口径的质量作用不稳定**。减少亚前沿重入、提高 next_selection、不产生重复——三条在三轮全部或大部成立；`conditional_delta_q_over_s` 的任务内均值在 CVRP 上符号逐轮翻转，在 OBP 上被重尾离群主导（单点可移动约 2s 均值）。
2. **快照集抽样方差与处理效应同量级**。r1 与 r3 的处理只差框架措辞与排序，CVRP 质量配对均值却相差 2.2s。每任务 18 个快照的抽样对均值类指标的分辨力低于六项门槛要求的稳定性；三轮的"失败项"各不相同正是这一方差的表现。
3. **价值与风险共享载体，呈现方式不能拆开**。跨区域机制标签承载质量收益（去掉标签的 r2 在 CVRP/OBP 失去增益）也承载有效率风险（r1 的 CVRP 运行期失败）；改语义框架（r3）不改变这一点。
4. **判停是预注册规则的正确执行**。r3 前在修订设计里写明"若 r3 仍不通过,V9.13 以三轮识别证据终止"；对同一门槛继续换呈现形式重试属于事后选择。

## 补充：第四个独立样本（开发探针）

r1 之前启动的固定锚点开发探针（创建时快照、全表处理、独立 seed）在三轮结束后完成 1080/1080，作为不可合并的参照样本报告方向：`fp_explore − pp_explore` 的单步质量 OP +0.70、TSP +0.24、OBP 为正（原始口径），CVRP −1.58 且 valid −11.1pp。与三轮合并：CVRP 在两个全表样本中有效率均明显下降（−7.4pp、−11.1pp），OP/TSP 质量在全部四个样本为正——"价值与风险共享载体"与"OP/TSP 稳健受益"两条结论得到第四样本支持；CVRP 对该信息形式的负反应不是单轮噪声。

## 结论与边界

V9.13 终止于机制识别阶段：不冻结处理、不启动 Stage A、无 held-out。三轮支持的结论层级是**固定快照提议**：已访问区域前沿信息（任何呈现形式）稳定改善 Explore 候选的 next-selection 与亚前沿重入、不诱发重复；其单步均值质量效应任务依赖且受离群与快照抽样影响，不能支撑"全部任务安全"的冻结门槛。不支持的推断：完整搜索或 held-out 收益（未测试）、任何单一呈现形式的优劣排序（轮间方差过大）。

后续若重启此线，证据指向两个方向：把识别实验的分辨力提到效应量之上（每任务快照数 ×3 以上，或对均值类指标改用稳健统计并预先冻结）；或放弃单步均值门槛、以 next_selection 与亚前沿重入这类已复现指标作为主终点。分配侧（L2）不受影响，区域代理未进入任何选择分数。
