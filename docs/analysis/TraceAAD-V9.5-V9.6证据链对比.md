# TraceAAD V9.5 → V9.6 证据链对比

> 分析对象：V9.5 正式批次 `20260811_171029` 与 V9.6 正式批次 `20260812_191011`，
> 四任务（OP / OBP / TSP / CVRP）各 3 repeats，模型 Qwen3.6-27B。分析日期 2026-08-13。
> 分析沿四层证据链进行：**历史上下文是否被修正 → 单步生成是否变好 → 搜索过程是否
> 更高效 → 最终算法是否更好**，外加按锚点历史丰富度的条件化分析。
> 比较横轴统一为**真实 evaluator calls**；对齐截点取 E=900（全部完成 run 均达到）。
> 提取与绘图脚本：`experiments/analysis/extract_v95_v96_evidence_chain.py`、
> `experiments/analysis/plot_v95_v96_evidence_chain.py`；全部聚合数字见
> [tables.md](traceaad_v95_v96_evidence_chain/tables.md)。
>
> **2026-08-13 追加修正**：本文对 TSP 的解释（第 0.4 条与"含义"第 3 条：历史诱导
> 编辑收缩 → TSP 净有害）已被随后的
> [固定锚点单步生成识别实验](../experiments/TraceAAD-固定锚点单步生成识别实验.md)（第三轮）
> 削弱：固定同一批 TSP 锚点，加入来时路后单步质量显著改善（conditional Δq 配对差
> +1.233 [0.283, 2.375]，improve 0%→12%，valid 81.5%→98.1%）且同时伴随修改收缩。
> 单步层面"改得小"与质量改善同向发生，"历史 → 收缩 → TSP 变差"的直接因果不再被
> 证据支持；TSP 完整搜索受损的疑点转向预算分配与修改意图层。事实数据不受影响。

## 0. 核心判断

1. **第一层成立**：历史上下文的修正真实发生，方向与设计一致。formation 缺席率从
   OP 31.6% / OBP 30.8% 降到 0；OP 上"真实历史 improve 22.9% vs 模型看到 8.2%"的
   失真（RQ-009 原数据，本分析精确复现）缩小为 37.7% vs 25.0%；prompt 缩短 31–52%。
2. **第二层在 V9.5 失真最重的任务上大幅成立**：OP 单步 improve rate 1.6%→11.6%，
   OBP 0.5%→12.6%，中位 Δfitness 大幅收窄；TSP 小幅改善，CVRP 无变化。
3. **但条件化分析推翻了预期的作用位置**：单步收益几乎全部来自 **direct 历史稀疏
   的锚点**（formation 写法的收益）；在 direct≥3 的"历史丰富"锚点上，V9.6 没有任何
   单步改善。V9.5 的失真状态（direct 挤掉 formation）在 V9.6 中主要是**不再发生**
   （锚点重访率暴跌），而不是在该状态下被修好。
4. **第三层任务分化**：OP / OBP / CVRP 的搜索效率（AUC@900）与对齐终点全部改善；
   TSP 全面变差，且 V9.6 的编辑幅度在 TSP 上腰斩（中位改动 87→42 行），符合
   RQ-009 预警的"更懂历史 → 改得更小"收缩。
5. **第四层不能宣称统一升级**：held-out 上 OBP 一致改善（且方差大幅缩小）；CVRP
   50/100 档改善、200 档略差；OP 均值被 rep1 的泛化崩塌拖累（search 14.494 但
   OP200 只有 41.87）；TSP 三档全面变差。
6. 场景归类：**OBP ≈ A**（历史修好 → 生成好 → 搜索好 → 最终好）；**OP ≈ A 到 B 之间**
   （搜索层面改善成立，held-out 未证明）；**CVRP 偏 E**（单步生成无变化而搜索与
   50/100 档 held-out 变好，收益更可能来自 allocation 行为变化，混杂未排除）；
   **TSP 是 D 类反例**（历史修好、单步 improve rate 上升，但搜索和最终都变差，
   伴随编辑收缩）。

**对核心问题的回答**：锚点历史上下文的改进有真实效果，但效果的因果路径与设计叙事
不同——它不是"救回被失真历史误导的成熟锚点"，而是（a）紧凑 formation 写法让占多数
的历史稀疏锚点单步生成更好，（b）生成结局分布变化连同 optimism scale 上移改变了
allocation 行为，使搜索不再反复锤同一锚点，失真情形本身几乎消失。direct 部分的挑法
（improve/regress 各封顶 2）在其设计针对的状态上**尚未证明价值**。

## 1. 数据完整性与比较口径

| Task | V9.5 r1/r2/r3（真实评价数） | V9.6 r1/r2/r3（真实评价数） |
| --- | --- | --- |
| OP | 945 / 961 / 981，全部完成 | 1000 × 3，全部完成 |
| OBP | 934 / 942 / 917，全部完成 | 1000 × 3，全部完成 |
| TSP | **612（中断）** / 937 / 964 | 1000 × 3，全部完成 |
| CVRP | 959 / **545（中断）** / 962 | 1000 × 3，全部完成 |

已知混杂与处理方式：

- **预算单位**：V9.5 按 1000 个完成候选（实际评价 917–981 次），V9.6 按 1000 次真实
  评价。所有过程比较横轴用真实 evaluator calls，效率与终点比较在 **E=900** 截齐；
  原终点值另列并标注。
- **V9.5 两路中断**是 tokenizer 暂时不可用引发的假 context 溢出（基础设施故障，
  见 V9.5 终局复盘），不计入 V9.6 机制收益；中断 run 的曲线保留到中断点，
  不进入 E=900 对齐统计与 held-out。
- **context 上限**：V9.5 为 24576，V9.6 为 32768，随版本一起变更，无法从本批数据中
  与历史机制分离；token 计数模式亦略有差异（`llm_count_tokens` vs
  `llm_chat_template_tokens`），但观察到的 prompt 差异（−31%~−52%）远大于计数模式差。
- **optimism scale 系统性上移**（由 bootstrap |Δ| 中位数决定，是生成行为的下游量）：
  OP 0.035–0.194 → 0.374–0.613；OBP 0/0/0 → 9.13/0/11.25；CVRP 0.73–0.86 →
  1.03–2.45。OBP 两路从 pure-q 变成 active optimism，属于 allocation regime 级别的
  变化。这是机制改动的**中介后果**而非独立随机噪声，但意味着搜索层差异不能单独归因
  于"prompt 里的历史更好"。
- evaluator contract hash 与超时配置（30s）两版完全一致。

## 2. 第一层：历史上下文是否真的被修正——是

精确复现）：

判断：

- **修正方向与设计目标一致，且全部四项设计意图（formation 回归、direct 封顶、

## 3. 第二层：单步生成是否因此变好——任务强分化，且收益位置与预期不同

![生成结局分布](traceaad_v95_v96_evidence_chain/fig3_outcomes.png)
![Δfitness 分布](traceaad_v95_v96_evidence_chain/fig4_delta_cdf.png)

正式锚点步（全部 repeats 合并；Δ = q(child) − q(anchor)，对有分数的尝试统计）：

| 指标 | OP v9.5→v9.6 | OBP v9.5→v9.6 | TSP v9.5→v9.6 | CVRP v9.5→v9.6 |
| --- | --- | --- | --- | --- |
| improve rate | 1.6% → **11.6%** | 0.5% → **12.6%** | 20.5% → 25.4% | 39.1% → 39.3% |
| regress rate | 81.7% → 59.7% | 73.6% → 53.5% | 48.5% → 51.0% | 52.7% → 49.7% |
| invalid rate | 3.7% → 3.6% | 0.6% → **12.3%** | 11.5% → 9.6% | 0.7% → 1.9% |
| P(Δ>0) | 0.017 → **0.121** | 0.005 → **0.146** | 0.235 → 0.282 | 0.407 → 0.405 |
| median Δ | −0.50 → **−0.11** | −17.25 → **−1.25** | −0.010 → −0.024 | −0.008 → −0.003 |
| mean Δ | −1.12 → −0.26 | −355.8 → −102.3 | −0.60 → −0.61 | −0.10 → −0.31 |
| P(产生新 global best) | 1.2% → 1.2% | 0.5% → 1.1% | 1.5% → 1.7% | 4.2% → 2.6% |
| 中位改动行数 | 52 → 44 | 39 → **17** | 87 → **42** | 15 → 17 |

事实归纳：

- **OP/OBP——恰好是 V9.5 历史失真最重的两个任务——单步生成大幅改善**（improve rate
  7–25 倍，中位 Δ 收窄 4–14 倍）。TSP 小幅改善，CVRP 基本不变，且 CVRP 的
  平均退步深度反而变大、新 best 产生率下降。
- **OBP 的 invalid 激增全部是评估超时**（r2 一路 288/1027 次 timeout；超时配置与
  evaluator contract 两版一致），即 V9.6 在 OBP 上生成了更慢的启发式，这是真实
  行为副作用，消耗了真实评价预算。
- **编辑幅度整体收缩**（TSP 腰斩、OBP 减半），与两轮固定锚点实验"历史越多、改得越小"
  的结论方向一致。

### 3.1 条件化分析：收益在哪些锚点上发生

![条件化分析](traceaad_v95_v96_evidence_chain/fig5_conditional.png)

按锚点当时已有的 direct attempts 数分层（improve rate，v9.5 → v9.6）：

| direct 池大小 | OP | OBP | TSP | CVRP |
| --- | --- | --- | --- | --- |
| 0 | 4.3% → **20.3%** | 0.3% → **22.7%** | 25.9% → **32.4%** | 43.0% → 43.2% |
| 1–2 | 2.3% → 3.1% | 0.6% → 5.9% | 10.9% → 10.2% | 10.6% → 10.1% |
| 3–7 | 1.1% → 0.6% | 0.4% → 1.1% | （n<20） | （n<10） |
| ≥8 | 0.5% → 0.0%（n=26） | 0.55% → 0.6% | （n<5） | — |

同时锚点人群本身大幅转移：direct≥3 的生成占比 OP 65%→12%、OBP 56%→21%。

这推翻了一个预设的解释，也建立了一个新的解释：

- **预设解释不成立**：V9.6 的收益不在"direct 历史丰富、V9.5 会发生 direct=8 /
  formation=0 的锚点"上——在这些状态里两版单步表现同样差，V9.6 没有把它们救回来。
  direct 挑法（improve/regress 各封顶 2）在其针对的状态上尚未证明价值。
- **实际路径**：(a) 在占大头的 direct 稀疏锚点上，formation 恢复 + 紧凑写法带来
  显著单步收益（OP dir=0 的中位 Δ 从 −0.358 收窄到 −0.022）；(b) 单步结局分布变化
  （plateau/improve 增多）加上 optimism scale 上移，使 allocation 不再反复重选同一
  锚点，**失真情形在 V9.6 的搜索动力学里几乎不再出现**（OP 中 dir≥8 的生成从 32%
  降到 0.8%）。
- 注意分层内比较仍非随机对照：进入各层的锚点由搜索内生决定，V9.6 的 dir=0 锚点
  人群与 V9.5 不同。该数字只能支持"收益集中于历史稀疏侧"，不能给出严格因果强度。

## 4. 第三层：搜索过程是否更高效——OP/OBP/CVRP 是，TSP 否

事实归纳：

- **OP**：V9.6 早期显著更强（E100 高 0.5，E300 高 0.6），AUC 三路全部更高；但 2/3
  的 run 在 241/377 次评价后再未刷新（最长停滞 759 次评价）——**在更高水平上早熟**。

- **OBP**：全程占优且刷新持续更久（末次刷新 583–821 vs 221–531），

- **CVRP**：三路终点与 AUC 均改善。注意其单步统计并未改善（§3），改善更可能来自
  allocation 层的行为变化（optimism scale 上移、锚点更替更快），混杂未拆。
- **TSP**：V9.6 三路早期显著更差、终点全部落后于 V9.5 的强 run；V9.5 即使只算
  完成的 2 路（−6.106/−5.703）也在 E900 领先。结合 TSP 编辑幅度腰斩（87→42 行）
  与 V9.5 终局复盘"TSP 强 run 依赖大改动、深度非单调 lineage"的结构，
  这与 RQ-009 预警的**历史诱导保守化在需要大步探索的任务上有害**一致
  （相关性证据，非因果证明）。

## 6. 结论

**证据链逐层回答：**

| 层 | 回答 | 证据强度 |
| --- | --- | --- |
| 历史被修正了吗 | 是，四项设计意图全部兑现，失真缩小但未清零 | 强（全任务、全 repeats 一致） |
| 单步生成变好了吗 | OP/OBP 大幅变好；TSP 轻微；CVRP 无变化。收益集中在 direct 稀疏锚点，direct-rich 锚点无收益 | 强（样本量 2.3–3.1k/组），但分层比较有内生性 |
| 搜索更高效了吗 | OP/OBP/CVRP 的 AUC 与对齐终点改善；OP 早熟停滞；TSP 变差 | 中（n=3/任务，且 optimism regime 混杂未拆） |
| 最终更好了吗 | OBP 是；OP search 是、held-out 否；CVRP 50/100 是、200 否；TSP 否 | 弱-中（3 repeats，OP 方差翻倍） |

**对设计主张的含义：**

1. "把历史以模型容易理解的形式给进去"这一主张在**formation（来时路）侧**得到了
   最清晰的支持：formation 恢复 + 紧凑实际修改写法，是本轮所有单步收益的所在地。
2. **direct 侧的挑法改动尚未证明价值**：它针对的失真状态在新动力学下几乎不再出现，
   出现时也没有改善。它的实际作用是"消灭问题状态"而非"修复问题状态"——这仍是收益，
   但归因叙事必须改写。
3. **历史诱导的编辑收缩是真实且有代价的**：TSP 的反例说明，当任务的改进几何依赖
   大步重构时，更充分的历史上下文可能净有害。这与 V9.5 终局复盘的任务分型
   （TSP/CVRP 深链路大改动 vs OP/OBP 局部打磨）拼在一起，指向"历史用量应依任务
   改进几何调节"的后续研究问题（[待验证]，写入研究认识前需专门实验）。
4. OP r1 的搜索分数—泛化解耦提示：search best 单点选择在更快收敛的搜索形态下
   风险变大，held-out 前的候选选择机制值得单独审视。
5. V9.6 相对 V9.5 的净判断：**过程层面（第一、二层）是明确的机制升级；结果层面
   （第三、四层）是任务依赖的重新分配——OBP 全面受益，OP 过程受益、结果未证明，
   CVRP 轻微受益，TSP 明确受损。** 不构成"统一超越 V9.5"的证据。

**混杂声明**：预算单位差异已通过 E=900 对齐消除；context 上限（24576→32768）与
optimism scale 上移随版本绑定变更，无法在本批数据内与历史机制分离；OBP 的评估
超时消耗了 V9.6 的真实预算（对 V9.6 不利方向的混杂）；V9.5 的 TSP/CVRP 各缺一路
完成 repeat（基础设施故障）。以上不改变第一、二层结论，第三、四层结论以此为限。
