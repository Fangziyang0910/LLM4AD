# TraceAAD V8 与 V8.2 同期对比（中期快照）

## 一、研究问题

在正式预算尚未跑满时，V8.2 相对 V8 是否已经表现出可核对的过程差异？差异主要体现在最终质量，还是体现在早期发现速度与搜索树形态？

本笔记只回答**同期对齐 sample 预算**后的搜索 best-so-far 与树形态。它不是终局测试结论，也不替代正式结果页。

## 二、证据与协议

### 2.1 批次与口径

| 项目 | V8 | V8.2 |
| --- | --- | --- |
| 批次 | `20260804_173300` | `20260804_203128` |
| 协议 | TraceAAD V8 / V8.1 主体（direct-code） | `traceaad-v8.2-adaptive-expand` |
| 预算 | 1000 sample | 1000 sample |
| 任务 | TSP / OBP / OP / CVRP | 同左 |
| 重复 | 每任务 3 | 进行中：TSP/OP/CVRP 各 2，OBP 1；另有 pending |
| 证据时点 | 2026-08-04 约 22:50（checkpoint） | 同左 |

比较量是 checkpoint 树节点的 `fitness` best-so-far（`maximize=true`，越大越好）。对齐方式：取双方都已达到的 sample 数 `T`，比较 `creation_order ≤ T` 时的全局最优。工件路径：`experiments/<task>/traceaad_v8/<run>/checkpoints/latest.json`。

### 2.2 证据强度

- **A 级**：各 run 的 `total_samples`、best fitness、节点 depth，可由 checkpoint 直接核对。
- **B 级**：同任务多 repeat 在对齐 `T` 上方向一致的均值差；当前 V8.2 重复数不足，跨任务均值只能作中期描述。
- **C 级**：将深树 / 早期领先归因于 V8.2 自适应扩展信用机制；尚无单变量消融。

| 任务 @T | V8 max / mean depth | V8.2 max / mean depth |
| --- | --- | --- |

## 六、分析判断

1. **同期有效结论**：在约前 10%–40% 预算，V8.2 在 TSP、OP 和 CVRP 的强 repeat 上，best-so-far 均值更高，且更早锁定高质量解。
2. **任务异质性**：OBP 不支持“开局全面领先”；CVRP 存在强弱 repeat 分化。
3. **过程与质量的边界**：深树和早期 best 说明搜索行为已改变，但不能直接外推为 1000-sample 终局或测试优势。V8 多数 run 仍有大量剩余预算，已完成的 V8-OBP 终值仍高于 V8.2 当前值。
4. **样本不对称**：V8 每任务 3 完整/近完整 repeat，V8.2 多为 1–2 个早期 repeat，均值方差更大。
