# TraceAAD V3 分析

## 1. 版本定位

V3(代码 `e8e94f6`)是对 V2 的系统性删减:移除岛模型与迁移、精英课程、对比反馈、复杂度与运行时度量、上下文 bonus、softmax/epsilon portfolio、Pareto 生存与多线程评估,保留轨迹主干、四个语义算子、三分量价值(Q/P/D)、固定 UCB、确定性 argmax 的轨迹/算子调度、边级经验记忆与新颖性门。设计意图是让历史直接、完整地进入决策,使机制主张与实现对齐、可审计。

## 2. 实验事实

批次 `20260720_233339`,TSP Construct 与 CVRP-ACO 各三重复 + 测试,工件在 `archive/traceaad-v2-v3/<task>/version3/`。训练集代表最优:TSP 约 −6.07(rep −6.074 / −5.972 / −6.072),CVRP 约 −8.81(rep −8.813 / −8.699 / −8.762)。测试:TSP50 均值 6.0948(std 0.023)、TSP100 8.6217、TSP200 12.1275;CVRP test_50 均值 9.0424、test_100 15.3989。两任务搜索结果均优于 V2。

## 4. 结论

1. 确认:V2 叠加的附属层没有为轨迹主干提供独立有用信号,部分还在拖累搜索——删减后两任务结果均改善。
2. 确认:当主张是"用改进历史指导下一步"时,让历史直接、完整地进入决策,优于在历史之上再加一层调度。
3. 遗留代价:确定性 argmax 与固定 UCB 使搜索随机性大幅降低,探索依赖模型采样与新颖性门,成为后续版本的调参问题。
4. 影响:V3 之后设计问题回到主干内部(轨迹长度、价值分量与 UCB 取值、算子调度、参考轨迹如何进入决策),由 V4 重构为单父代轨迹搜索逐一处理;V3 结果不进入正式结果页。
