# LLM 局部改进与受控多样性

> 研究问题：LLM 作为进化算子时，怎样同时获得可靠改进与有效多样性？
>
> 状态：已有相关工作和本项目过程证据，动态机制待验证。
>
> 当前判断：先形成优质局部解，再在这些解之间引入互补变化，比无条件扩大
> 全局差异更有效。

优秀的 LLM 进化算子首先应能围绕高质量父代持续产生可靠的小步改进。这里的
“小步”指保留已经验证的结构，围绕一个明确弱点或新思想做可归因修改，不等于
限制代码行数，也不排斥必要的新机制。

多样性的作用取决于所在区域。搜索尚未形成可靠局部解时扩大差异，容易造成
语义漂移；当多条优质路线已经分别积累成功和失败证据时，迁移与重组才更可能
产生突破。因此 TraceAAD 应让质量先确定搜索区域，再让互补性避免该区域内部
过早收缩。

正式 V5 保留四个轨迹算子并均匀调度，作为清楚、可复现的基线。下一步检验：
单轨迹算子的连续路线推进率、参考路线质量与互补性的联合影响，以及基于路线
成熟度动态提高双轨迹算子概率是否改善三重复下限和后半程突破。
