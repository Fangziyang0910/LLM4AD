# 算子调度

> 研究问题：四个轨迹算子的预算是否应随搜索状态变化？
>
> 状态：正式 V5 使用可用算子等概率选择；动态调度待受控实验。
>
> 当前判断：调度应由优质路线是否成熟决定，不能只按固定轮数切阶段。

`ideate/refine` 沿一条主轨迹产生有方向的变化，`synthesize/transfer` 在两条
轨迹之间重组或迁移知识。四个算子都经过轨迹语义适配，不能简化成普通交叉和
变异；但其底层预算问题仍符合种群进化逻辑。

双轨迹算子在开发实验中多次表现出较好的路线推进能力，说明直接参考有价值。
固定等概率的风险是：搜索早期尚未形成优质、互补路线时，跨轨迹操作会在较弱
区域之间交换噪声；参考程序高度相似时，也可能只生成表面变化。

待验证方案是：

1. 前期以可靠的单轨迹改进为主，同时保留最低探索概率；
2. 当 active 中至少出现两条质量较高、彼此有差异且有成功改进证据的路线后，
   提高 `transfer/synthesize` 概率；
3. 调度信用优先使用路线最好推进与全局前沿贡献，不直接使用容易被低质量父代
   放大的普通父子改善率。
