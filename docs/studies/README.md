## 单篇文档的最小入口

每个议题开头只维护四项：

```text
研究问题：
状态：
当前判断：
影响设计或关联证据：
```

正文自然组织为问题、观察事实、相关工作、机制推断、当前判断和未决问题。观察事实与推断必须分开；完整机制参数和执行流程不在这里维护。
