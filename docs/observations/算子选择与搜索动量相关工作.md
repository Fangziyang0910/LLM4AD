# 算子选择与搜索动量相关工作

## 核心结论

进化计算中已经存在根据在线表现或搜索状态调整算子概率的研究，通常称为自适应算子选择（Adaptive Operator Selection, AOS）、策略自适应或参数控制。现有工作说明算子效果可能随搜索过程变化，因此可以使用近期成功、变化检测或种群状态调整选择概率；这些结果不直接证明 TraceAAD 需要算子 UCB，也不证明任何固定的“前期探索、后期利用”阶段表能够跨任务成立。

## 代表性工作

1. Thierens 的 Adaptive Pursuit 根据算子质量估计持续提高当前较优算子的概率，同时保留最低选择概率。这是在线概率分配，不是按固定代数切换阶段。[论文 DOI](https://doi.org/10.1145/1068009.1068251)
2. Da Costa 等把 AOS 表述为动态多臂赌博机问题，并使用变化检测应对搜索过程中算子收益的非平稳性。其出发点正是“同一算子的有效性会随搜索状态变化”。[论文 DOI](https://doi.org/10.1145/1389095.1389272)
3. Fialho 等系统比较了 bandit-based AOS 的 credit assignment 与 operator selection 组合，说明 reward 定义、时间窗口和选择规则共同决定结果，不能只把累计平均收益当成算子固有能力。[论文 DOI](https://doi.org/10.1007/s10472-010-9213-y)
4. SaDE 根据一段学习期内不同差分进化策略的成功经验调整策略选择概率和参数。它属于近期表现驱动的策略自适应，而非预设搜索阶段。[论文 DOI](https://doi.org/10.1109/TEVC.2008.927706)
5. Adaptive Large Neighborhood Search 让多个 destroy/repair 子启发式按历史表现对应的频率竞争使用。这证明固定概率之外存在成功的自适应调度，但其算子具有可比较的邻域搜索语义，不能直接类比 TraceAAD 中 parent-based 与 fresh-start 混合的四种动作。[论文 DOI](https://doi.org/10.1287/trsc.1050.0135)
6. Adaptive PSO 根据种群分布与适应度信息估计 exploration、exploitation、convergence 和 jumping-out 等演化状态，再据此调整搜索参数。它支持“由种群状态识别搜索阶段”的思想，但调整对象主要是 PSO 参数，不是 TraceAAD 式 LLM 搜索算子。[论文 DOI](https://doi.org/10.1109/TSMCB.2009.2015956)
7. Extreme Compass 同时观察算子引起的种群平均质量变化、种群多样性变化和运行时间，并在滑动窗口中汇总后管理算子。它与“种群动量”最接近，但原工作使用的是多维群体状态与变化度量，而不是单一 momentum 标量。[论文 DOI](https://doi.org/10.1109/CEC.2009.4982970)

## 对 TraceAAD 的启示

- 均匀随机、固定非均匀概率和轮换都是不学习历史收益的简单基线；AOS、SaDE 和 ALNS 才根据在线结果更新概率。
- 固定按预算比例划分“早期/中期/后期”会假设不同任务同步进入相同搜索状态。状态驱动方法使用近期改善、种群分布或变化检测，更能容纳任务难度和收敛速度差异。
- TraceAAD 当前四个算子不是同质 bandit arms：继续与回退改变父节点，交叉额外引入供体历史，novelty 则无父节点并重新初始化。不同 reward 参照和调用上下文使全局平均 reward 严重混杂。
- “动量”可以作为搜索状态的描述：轨迹近期改善趋势、全局 best 的多窗口推进速度、种群质量分布和多样性的变化趋势。它比累计调用次数更能描述搜索处境；调用次数仍只表示覆盖程度或估计不确定性。
- 在没有受控证据前，较清晰的起点是让同质、可用的局部算子均匀选择，把 fresh restart 作为独立预算或低频机制；先记录动量状态和条件结果，再检验是否需要状态驱动调度。

## 证据边界

以上文献表明自适应算子调度和搜索状态识别在进化计算中有成熟先例。它们没有回答 TraceAAD 的四种动作是否设计合理，也没有证明轨迹、整体或种群动量能够可靠预测下一种 LLM 搜索动作。后者仍需要在固定模型、轨迹选择和评估预算下做均匀基线与状态驱动策略的对照实验。
