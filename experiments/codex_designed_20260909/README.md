2026-09-09。用户要求科研协作者直接为现有五个任务设计算法并评价。本轮每个任务写一个程序，完成一次现有训练评价与一次独立实例面板评价，共 10 次 evaluator 调用。所有调用成功返回有效评分。程序在训练结果出来前已全部写好，本轮保持原始版本，没有按训练或验证结果调参筛选。

## 五个设计

- **[TSP](tsp_construct_v1.py)：多起点最近邻 + 最佳改进 2-opt。** 首次调用通过完整距离矩阵构造最多 16 条初始巡回路径，各自进行至多 100 轮 2-opt，选成本最小的一条并旋转至起点。后续调用使用与当前距离矩阵、剩余节点集合匹配的内存路径缓存返回下一节点。利用了接口提供的全局距离信息，在选下一节点之前完成完整路径优化。16 个训练实例合计评价约 0.72 秒。
- **[CVRP](cvrp_aco_v1.py)：距离与仓库节约量先验。** 边权结合距离的 −2.5 次幂、连接两客户相对分别往返仓库的节约比例，以及温和的需求偏好；降低过早回仓边权。原 ACO 的蚂蚁数、迭代数与随机种子保持现有配置。该组合本次得到的结果弱于 V10.7R 的三个终点。
- **[OP](op_aco_v1.py)：收益效率与邻域价值先验。** 综合目的节点收益、边长、附近高收益节点密度与往返预算，鼓励进入能够连续收集收益的区域。原 ACO 负责可行性和路线搜索。
- **[OBP](online_bin_packing_v1.py)：紧凑填充与碎片惩罚。** 用残余容量相对当前物品大小的比例衡量紧凑程度，奖励精确填满，并对很小的非零残余作平滑惩罚。将最大剩余容量作为空箱候选的代理，降低开新箱优先级。本轮未达到搜索得到的最好规则，说明这一具体碎片惩罚尚需改进。
- **[VRPTW](vrptw_construct_v1.py)：时间感知选择与一步衔接。** 综合行驶、等待、客户距仓库距离及截止时间，并估计访问该客户后能够衔接其他客户的节约量。窗口宽度用作接口未提供的服务时长的代理；实际每一步的可行客户仍由原评价器确定。本次训练结果处于 V10.7R 三个终点的范围内。

## 评价口径与成本

训练评价直接调用 `experiments.infra.base.build_task` 与 `SecureEvaluator`：TSP50/VRPTW50 各 16 个实例，CVRP50 为 10 个实例、30 蚂蚁 × 100 轮，OP50 为 5 个实例、20 蚂蚁 × 50 轮；OBP 使用现有 1000/5000 物品与 100/500 容量的四设置面板。ACO 使用 4 个评价 worker、固定 aco_seed=1234，两个 ACO 评价依次执行。

独立面板保持规模和计算配置：TSP/VRPTW/OBP 改用 seed=2025；CVRP 取标准 test_50 的前 10 个实例，OP 取 test_50 的前 5 个实例。这是有限规模的独立检查，并非完整 64 实例测试或跨规模实验。面板没有用于选择或修改本轮程序。

训练评价耗时约：TSP 0.72 秒，CVRP 40.50 秒，OP 12.96 秒，OBP 2.43 秒，VRPTW 0.25 秒；时间包含当时机器负载与进程启动开销。首次训练共约 56.87 秒，独立面板另约 42.72 秒。评价次数不是程序内部计算量：TSP 的每次评价包含多起点与局部优化。

作者为本次对话中的 Codex 科研协作者，已有 TraceAAD 讨论和历史结果背景，并读取了公开任务接口与评价配置。本轮没有调用实验用 Qwen 生成服务。这是直接设计的候选算法参照，生成模型、设计过程和历史上下文均与 Qwen 搜索不同，不能据此单独归因于搜索机制或模型能力。

## 研究用途

TSP 的结果提供了一个具体线索：接口允许的全局规划与局部优化，能够在较低单次运行成本下达到较好质量，值得作为后续初始化候选或直接算法基线。其他四项也显示，合理的设计直觉并不自动胜过搜索产生的规则。后续可以围绕这些程序做明确的改进尝试，同时保留本轮原始结果作为起点。

## 工件与复现

- [训练收据](results_v1_train.jsonl)、[独立面板收据](results_v1_heldout_panel.jsonl)：记录分数、失败类型、耗时、配置、时间戳与程序 SHA-256。

- `programs/` 为可直接使用的实现；同目录的 `*_v1.py` 为本轮评价源码快照。

```bash
.venv/bin/python -m experiments.codex_designed_20260909.run --tag reproduction --program-tag v1
.venv/bin/python -m experiments.codex_designed_20260909.run --tag reproduction --program-tag v1 --split heldout_panel
```
