# TraceAAD V10.11

LLM 每次返回一个不超过 200 词的最终 Idea 和模板中指定目标函数的完整定义。函数内部实现自由；代码块外不包含 imports、外部 helper、变量、示例或其他模块内容。Idea 缺失、超长、代码形状不符或模板重建失败都会进入一次修复。

搜索使用四个等概率算子、质量分布父代选择、Pivot 均匀混合和 Fuse donor 混合。上下文只包含当前函数、最近形成记录和 donor。模块独立实现搜索、提示、解析、模板重建、持久化与修复。
